# `setRelationshipDefinition`
The `setRelationshipDefinition` method lets you set the definition of a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).

```
setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)(
  relationshipId: string,
  localTableId: string,
  remoteTableId: string,
  getRemoteRowId: string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), localRowId: string) => string,
): Relationships[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `relationshipId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) to define.  |  
| `localTableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the local [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) for the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).  |  
| `remoteTableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the remote [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) for the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) (or the same as the `localTableId` in the case of a linked list).  |  
| `getRemoteRowId`  | `string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), localRowId: string) => string`  | Either the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) containing, or a function that produces, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) that is used to indicate which [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the remote [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) a local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is related to.  |  
| returns  | `Relationships[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/)`  | A reference to the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object.  |  
Every [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) definition is identified by a unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and if you re-use an existing [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) with this method, the previous definition is overwritten.
An [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) is based on connections between [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects, often in two different [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) objects. Therefore the definition requires the `localTableId` parameter to specify the 'local' [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to create the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) from, and the `remoteTableId` parameter to specify the 'remote' [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to create [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) to.
A linked list [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) is one that has the same [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) specified as both local [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and remote [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), allowing you to create a sequence of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects within that one [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).
A local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is related to a remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) by specifying which of its (local) [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values contains the (remote) [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), using the `getRemoteRowId` parameter. Alternatively, a custom function can be provided that produces your own remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) from the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) as a whole.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and defines a simple [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) based on the values in the `species` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) of the `pets` [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that relates a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to another in the `species` [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createRelationships, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog'},
    felix: {species: 'cat'},
    cujo: {species: 'dog'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    dog: {price: 5},
    cat: {price: 4},
  });

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store);
relationships.setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)(
  'petSpecies', // relationshipId
  'pets', //       localTableId to link from
  'species', //    remoteTableId to link to
  'species', //    cellId containing remote key
);

console.log(relationships.getRemoteRowId[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getremoterowid/)('petSpecies', 'fido'));
// -> 'dog'
console.log(relationships.getLocalRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlocalrowids/)('petSpecies', 'dog'));
// -> ['fido', 'cujo']

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and defines a linked list [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) based on the values in the `next` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) of the `pets` [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that relates a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to another in the same [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createRelationships, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', next: 'felix'},
  felix: {species: 'cat', next: 'cujo'},
  cujo: {species: 'dog'},
});

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store);
relationships.setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)(
  'petSequence', // relationshipId
  'pets', //        localTableId to link from
  'pets', //        the same remoteTableId to link within
  'next', //        cellId containing link key
);

console.log(relationships.getLinkedRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlinkedrowids/)('petSequence', 'fido'));
// -> ['fido', 'felix', 'cujo']

```
