# `getLinkedRowIds`
The `getLinkedRowIds` method gets the linked [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for a given [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a linked list [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).

```
getLinkedRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlinkedrowids/)(
  relationshipId: string,
  firstRowId: string,
): Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `relationshipId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).  |  
| `firstRowId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the first [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the linked list [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).  |  
| returns  | `Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)`  | The linked [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).  |  
A linked list [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) is one that has the same [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) specified as both local [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and remote [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), allowing you to create a sequence of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects within that one [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).
If the identified [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) or [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) does not exist (or if the definition references a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that does not exist) then an array containing just the first [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) is returned.
## Example
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and defines a simple linked list [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/). It then uses getLinkedRowIds to see the linked [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) (and also the linked [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) that does not exist, and for a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) that has not been defined).

```
import {createRelationships, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', next: 'felix'},
  felix: {species: 'cat', next: 'cujo'},
  cujo: {species: 'dog'},
});

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store);
relationships.setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)(
  'petSequence',
  'pets',
  'pets',
  'next',
);

console.log(relationships.getLinkedRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlinkedrowids/)('petSequence', 'fido'));
// -> ['fido', 'felix', 'cujo']
console.log(relationships.getLinkedRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlinkedrowids/)('petSequence', 'felix'));
// -> ['felix', 'cujo']
console.log(relationships.getLinkedRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlinkedrowids/)('petSequence', 'toto'));
// -> ['toto']
console.log(relationships.getLinkedRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlinkedrowids/)('petFriendships', 'fido'));
// -> ['fido']

```
