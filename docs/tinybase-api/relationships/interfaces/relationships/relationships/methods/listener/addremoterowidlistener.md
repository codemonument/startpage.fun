# `addRemoteRowIdListener`
The `addRemoteRowIdListener` method registers a listener function with the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object that will be called whenever a remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) changes.

```
addRemoteRowIdListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/addremoterowidlistener/)(
  relationshipId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  localRowId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: RemoteRowIdListener[](https://tinybase.org/api/relationships/type-aliases/listener/remoterowidlistener/),
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `relationshipId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) to listen to, or `null` as a wildcard.  |  
| `localRowId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `RemoteRowIdListener[](https://tinybase.org/api/relationships/type-aliases/listener/remoterowidlistener/)`  | The function that will be called whenever the remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) changes.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
You can either listen to a single local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) (by specifying the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first two parameters), or changes to any local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) (by providing a `null` wildcards).
Both, either, or neither of the `relationshipId` and `localRowId` parameters can be wildcarded with `null`. You can listen to a specific local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), any local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), a specific local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), or any local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).
The provided listener is a [`RemoteRowIdListener`](https://tinybase.org/api/relationships/type-aliases/listener/remoterowidlistener/) function, and will be called with a reference to the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) that had its remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) change.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and then registers a listener that responds to any changes to a specific local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/)'s remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).

```
import {createRelationships, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog'},
    felix: {species: 'cat'},
    cujo: {species: 'dog'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    wolf: {price: 10},
    dog: {price: 5},
    cat: {price: 4},
  });

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store);
relationships.setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)(
  'petSpecies',
  'pets',
  'species',
  'species',
);

const listenerId = relationships.addRemoteRowIdListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/addremoterowidlistener/)(
  'petSpecies',
  'cujo',
  (relationships) => {
    console.log('petSpecies relationship (from cujo) changed');
    console.log(relationships.getRemoteRowId[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getremoterowid/)('petSpecies', 'cujo'));
  },
);

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'cujo', 'species', 'wolf');
// -> 'petSpecies relationship (from cujo) changed'
// -> 'wolf'

relationships.delListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/dellistener/)(listenerId);

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and then registers a listener that responds to any changes to any local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/)'s remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/). It also illustrates how you can use the [`getStore`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getstore/) method and the [`getRemoteRowId`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getremoterowid/) method to resolve the remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) as a whole.

```
import {createRelationships, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
    cujo: {species: 'dog', color: 'brown'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    wolf: {price: 10},
    dog: {price: 5},
    cat: {price: 4},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('color', {
    brown: {discount: 0.1},
    black: {discount: 0},
    grey: {discount: 0.2},
  });

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store)
  .setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)('petSpecies', 'pets', 'species', 'species')
  .setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)('petColor', 'pets', 'color', 'color');

const listenerId = relationships.addRemoteRowIdListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/addremoterowidlistener/)(
  null,
  null,
  (relationships, relationshipId, localRowId) => {
    console.log(
      `${relationshipId} relationship (from ${localRowId}) changed`,
    );
    console.log(relationships.getRemoteRowId[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getremoterowid/)(relationshipId, localRowId));
    console.log(
      relationships
        .getStore[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getstore/)()
        .getRow[](https://tinybase.org/api/the-essentials/getting-data/getrow/)(
          relationships.getRemoteTableId[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getremotetableid/)(relationshipId),
          relationships.getRemoteRowId[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getremoterowid/)(relationshipId, localRowId),
        ),
    );
  },
);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'cujo', {species: 'wolf', color: 'grey'});
// -> 'petSpecies relationship (from cujo) changed'
// -> 'wolf'
// -> {price: 10}
// -> 'petColor relationship (from cujo) changed'
// -> 'grey'
// -> {discount: 0.2}

relationships.delListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/dellistener/)(listenerId);

```
