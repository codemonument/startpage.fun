# `addLocalRowIdsListener`
The `addLocalRowIdsListener` method registers a listener function with the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object that will be called whenever the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) change.

```
addLocalRowIdsListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/addlocalrowidslistener/)(
  relationshipId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  remoteRowId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: LocalRowIdsListener[](https://tinybase.org/api/relationships/type-aliases/listener/localrowidslistener/),
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `relationshipId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) to listen to, or `null` as a wildcard.  |  
| `remoteRowId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `LocalRowIdsListener[](https://tinybase.org/api/relationships/type-aliases/listener/localrowidslistener/)`  | The function that will be called whenever the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) change.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
You can either listen to a single local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) (by specifying the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first two parameters), or changes to any local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) (by providing a `null` wildcards).
Both, either, or neither of the `relationshipId` and `remoteRowId` parameters can be wildcarded with `null`. You can listen to a specific remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), any remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), a specific remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), or any remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).
The provided listener is a [`LocalRowIdsListener`](https://tinybase.org/api/relationships/type-aliases/listener/localrowidslistener/) function, and will be called with a reference to the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) that had its local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects change.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and then registers a listener that responds to any changes to a specific remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/)'s local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects.

```
import {createRelationships, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog'},
    felix: {species: 'cat'},
    cujo: {species: 'dog'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    wolf: {price: 10},
    dog: {price: 5},
    cat: {price: 4},
  });

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store);
relationships.setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)(
  'petSpecies',
  'pets',
  'species',
  'species',
);

const listenerId = relationships.addLocalRowIdsListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/addlocalrowidslistener/)(
  'petSpecies',
  'dog',
  (relationships) => {
    console.log('petSpecies relationship (to dog) changed');
    console.log(relationships.getLocalRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlocalrowids/)('petSpecies', 'dog'));
  },
);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'toto', {species: 'dog'});
// -> 'petSpecies relationship (to dog) changed'
// -> ['fido', 'cujo', 'toto']

relationships.delListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/dellistener/)(listenerId);

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and then registers a listener that responds to any changes to any remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/)'s local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects.

```
import {createRelationships, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
    cujo: {species: 'dog', color: 'brown'},
    toto: {species: 'dog', color: 'grey'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    wolf: {price: 10},
    dog: {price: 5},
    cat: {price: 4},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('color', {
    brown: {discount: 0.1},
    black: {discount: 0},
    grey: {discount: 0.2},
  });

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store)
  .setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)('petSpecies', 'pets', 'species', 'species')
  .setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)('petColor', 'pets', 'color', 'color');

const listenerId = relationships.addLocalRowIdsListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/addlocalrowidslistener/)(
  null,
  null,
  (relationships, relationshipId, remoteRowId) => {
    console.log(
      `${relationshipId} relationship (to ${remoteRowId}) changed`,
    );
    console.log(relationships.getLocalRowIds[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/getter/getlocalrowids/)(relationshipId, remoteRowId));
  },
);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'cujo', {species: 'wolf', color: 'grey'});
// -> 'petSpecies relationship (to dog) changed'
// -> ['fido', 'toto']
// -> 'petSpecies relationship (to wolf) changed'
// -> ['cujo']
// -> 'petColor relationship (to brown) changed'
// -> ['fido']
// -> 'petColor relationship (to grey) changed'
// -> ['toto', 'cujo']

relationships.delListener[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/listener/dellistener/)(listenerId);

```
