# Interfaces
## `Relationships`
A [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object lets you associate a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a one [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) with the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in another [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). [Read more](https://tinybase.org/api/relationships/interfaces/relationships/relationships/).
