# `getCellHash`
The `getCellHash` function returns a hash for a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), based on its value and the HLC of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
getCellHash[](https://tinybase.org/api/common/functions/hash/getcellhash/)(
  cell: CellOrUndefined[](https://tinybase.org/api/store/type-aliases/store/cellorundefined/),
  cellHlc: string,
): Hash[](https://tinybase.org/api/common/type-aliases/stamps/hash/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `cell`  | `CellOrUndefined[](https://tinybase.org/api/store/type-aliases/store/cellorundefined/)`  | The [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/)'s value (or `undefined`).  |  
| `cellHlc`  | `string`  | The HLC of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).  |  
| returns  | `Hash[](https://tinybase.org/api/common/type-aliases/stamps/hash/)`  | A hash of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).  |  
## Example
This example gets the hash of a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) and its HLC.

```
import {getCellHash} from 'tinybase';

const cell = 'dog';
const cellHlc = '03E3B------mmxrx';

console.log(getCellHash[](https://tinybase.org/api/common/functions/hash/getcellhash/)(cell, cellHlc));
// -> 3002200796

```
