# Hash functions
## `getTableInTablesHash`
The [`getTableInTablesHash`](https://tinybase.org/api/common/functions/hash/gettableintableshash/) function returns a hash for a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), based on its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash (in turn produced from its Rows). [Read more](https://tinybase.org/api/common/functions/hash/gettableintableshash/).
## `getTablesHash`
The [`getTablesHash`](https://tinybase.org/api/common/functions/hash/gettableshash/) function returns a hash for the tabular part of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), based on each [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash. [Read more](https://tinybase.org/api/common/functions/hash/gettableshash/).
## `getRowInTableHash`
The [`getRowInTableHash`](https://tinybase.org/api/common/functions/hash/getrowintablehash/) function returns a hash for a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), based on its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash (in turn produced from its Cells). [Read more](https://tinybase.org/api/common/functions/hash/getrowintablehash/).
## `getTableHash`
The [`getTableHash`](https://tinybase.org/api/common/functions/hash/gettablehash/) function returns a hash for a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), based on each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash. [Read more](https://tinybase.org/api/common/functions/hash/gettablehash/).
## `getCellInRowHash`
The [`getCellInRowHash`](https://tinybase.org/api/common/functions/hash/getcellinrowhash/) function returns a hash for a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), based on its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash (in turn produced from its value). [Read more](https://tinybase.org/api/common/functions/hash/getcellinrowhash/).
## `getRowHash`
The [`getRowHash`](https://tinybase.org/api/common/functions/hash/getrowhash/) function returns a hash for a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), based on each [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash. [Read more](https://tinybase.org/api/common/functions/hash/getrowhash/).
## `getCellHash`
The [`getCellHash`](https://tinybase.org/api/common/functions/hash/getcellhash/) function returns a hash for a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), based on its value and the HLC of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/). [Read more](https://tinybase.org/api/common/functions/hash/getcellhash/).
## `getValueInValuesHash`
The [`getValueInValuesHash`](https://tinybase.org/api/common/functions/hash/getvalueinvalueshash/) function returns a hash for a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in a [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) object, based on its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash (in turn produced from its value). [Read more](https://tinybase.org/api/common/functions/hash/getvalueinvalueshash/).
## `getValuesHash`
The [`getValuesHash`](https://tinybase.org/api/common/functions/hash/getvalueshash/) function returns a hash for a [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) object, based on each [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and hash. [Read more](https://tinybase.org/api/common/functions/hash/getvalueshash/).
## `getValueHash`
The [`getValueHash`](https://tinybase.org/api/common/functions/hash/getvaluehash/) function returns a hash for a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/), based on its value and the HLC of the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/). [Read more](https://tinybase.org/api/common/functions/hash/getvaluehash/).
## `addOrRemoveHash`
The [`addOrRemoveHash`](https://tinybase.org/api/common/functions/hash/addorremovehash/) function combines two hashes together, which, because it is a simple alias for bitwise XOR, serves both as addition and removal of one hash from the other. [Read more](https://tinybase.org/api/common/functions/hash/addorremovehash/).
## `getHash`
The [`getHash`](https://tinybase.org/api/common/functions/hash/gethash/) function returns a deterministic hash of a string, which can be used to quickly compare the content of two entities. [Read more](https://tinybase.org/api/common/functions/hash/gethash/).
