# `AnyObject`
The `AnyObject` type is a simple alias for a plain object with string keys and unknown values.

```
{[key: string]: unknown}
```

It is used to indicate that the value should be considered to be a plain JavaScript object, as can be stored in a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) with the `object` schema type.
