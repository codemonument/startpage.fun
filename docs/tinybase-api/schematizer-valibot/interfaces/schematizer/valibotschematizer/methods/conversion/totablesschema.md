# `toTablesSchema`
The `toTablesSchema` method converts a mapping of Valibot object schemas into a TinyBase [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/).

```
toTablesSchema[](https://tinybase.org/api/schematizer-valibot/interfaces/schematizer/valibotschematizer/methods/conversion/totablesschema/)(schemas: {[tableId: string]: any}): TablesSchema[](https://tinybase.org/api/store/type-aliases/schema/tablesschema/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `schemas`  | `{[tableId: string]: any}`  | A mapping of table IDs to Valibot object schemas.  |  
| returns  | `TablesSchema[](https://tinybase.org/api/store/type-aliases/schema/tablesschema/)`  | A TinyBase [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/).  |  
This method extracts basic type information (string, number, boolean), fallback values, and nullable flags from Valibot schemas. Complex validation rules like min/max, regex patterns, refinements, and transforms are ignored.
## Example
This example converts Valibot schemas to TinyBase format.

```
import {createStore} from 'tinybase';
import {createValibotSchematizer} from 'tinybase/schematizers/schematizer-valibot';
import {boolean, fallback, number, object, string} from 'valibot';

const schematizer = createValibotSchematizer[](https://tinybase.org/api/schematizer-valibot/functions/creation/createvalibotschematizer/)();

const tablesSchema = schematizer.toTablesSchema[](https://tinybase.org/api/schematizer-valibot/interfaces/schematizer/valibotschematizer/methods/conversion/totablesschema/)({
  pets: object({
    species: string(),
    age: number(),
    sold: fallback(boolean(), false),
  }),
});

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTablesSchema[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/)(tablesSchema);
store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'fido', {species: 'dog', age: 3});
console.log(store.getRow[](https://tinybase.org/api/the-essentials/getting-data/getrow/)('pets', 'fido'));
// -> {species: 'dog', age: 3, sold: false}

```
