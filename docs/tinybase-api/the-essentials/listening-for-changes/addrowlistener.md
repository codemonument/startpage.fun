# `addRowListener`
Essential
The `addRowListener` method registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called whenever data in a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) changes.

```
addRowListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addrowlistener/)(
  tableId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  rowId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: RowListener[](https://tinybase.org/api/store/type-aliases/listener/rowlistener/)<Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)>,
  mutator?: boolean,
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to listen to, or `null` as a wildcard.  |  
| `rowId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `RowListener[](https://tinybase.org/api/store/type-aliases/listener/rowlistener/)<Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)>`  | The function that will be called whenever data in the matching [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) changes.  |  
| `mutator?`  | `boolean`  | An optional boolean that indicates that the listener mutates [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to call it explicitly, or to remove it.  |  
The provided listener is a [`RowListener`](https://tinybase.org/api/store/type-aliases/listener/rowlistener/) function, and will be called with a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that changed, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) that changed, and a [`GetCellChange`](https://tinybase.org/api/store/type-aliases/listener/getcellchange/) function in case you need to inspect any changes that occurred.
You can either listen to a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) (by specifying the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first two parameters) or changes to any [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) (by providing `null` wildcards).
Both, either, or neither of the `tableId` and `rowId` parameters can be wildcarded with `null`. You can listen to a specific [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), any [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), a specific [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), or any [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).
Use the optional mutator parameter to indicate that there is code in the listener that will mutate [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data. If set to `false` (or omitted), such mutations will be silently ignored. All relevant mutator listeners (with this flag set to `true`) are called _before_ any non-mutator listeners (since the latter may become relevant due to changes made in the former). The changes made by mutator listeners do not fire other mutating listeners, though they will fire non-mutator listeners.
## Examples
This example registers a listener that responds to any changes to a specific [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addRowListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addrowlistener/)(
  'pets',
  'fido',
  (store, tableId, rowId, getCellChange) => {
    console.log('fido row in pets table changed');
    console.log(getCellChange('pets', 'fido', 'color'));
  },
);

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
// -> 'fido row in pets table changed'
// -> [true, 'brown', 'walnut']

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any changes to any [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addRowListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addrowlistener/)(
  null,
  null,
  (store, tableId, rowId) => {
    console.log(`${rowId} row in ${tableId} table changed`);
  },
);

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
// -> 'fido row in pets table changed'
store.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {dog: {price: 5}});
// -> 'dog row in species table changed'

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any changes to a specific [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), and which also mutates the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) itself.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addRowListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addrowlistener/)(
  'pets',
  'fido',
  (store, tableId, rowId) =>
    store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('meta', 'update', `${tableId}_${rowId}`, true),
  true,
);

store.delCell[](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/delcell/)('pets', 'fido', 'color');
console.log(store.getTable[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettable/)('meta'));
// -> {update: {pets_fido: true}}

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```
