# `addCellListener`
Essential
The `addCellListener` method registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called whenever data in a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) changes.

```
addCellListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addcelllistener/)(
  tableId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  rowId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  cellId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: CellListener[](https://tinybase.org/api/store/type-aliases/listener/celllistener/)<Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)>,
  mutator?: boolean,
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to listen to, or `null` as a wildcard.  |  
| `rowId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to listen to, or `null` as a wildcard.  |  
| `cellId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `CellListener[](https://tinybase.org/api/store/type-aliases/listener/celllistener/)<Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)>`  | The function that will be called whenever data in the matching [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) changes.  |  
| `mutator?`  | `boolean`  | An optional boolean that indicates that the listener mutates [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to call it explicitly, or to remove it.  |  
The provided listener is a [`CellListener`](https://tinybase.org/api/store/type-aliases/listener/celllistener/) function, and will be called with a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that changed, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) that changed, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) that changed, the new [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value, the old [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value, and a [`GetCellChange`](https://tinybase.org/api/store/type-aliases/listener/getcellchange/) function in case you need to inspect any changes that occurred.
You can either listen to a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) (by specifying the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first three parameters) or changes to any [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) (by providing `null` wildcards).
All, some, or none of the `tableId`, `rowId`, and `cellId` parameters can be wildcarded with `null`. You can listen to a specific [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a specific [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), any [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in any [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), for example - or every other combination of wildcards.
Use the optional mutator parameter to indicate that there is code in the listener that will mutate [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data. If set to `false` (or omitted), such mutations will be silently ignored. All relevant mutator listeners (with this flag set to `true`) are called _before_ any non-mutator listeners (since the latter may become relevant due to changes made in the former). The changes made by mutator listeners do not fire other mutating listeners, though they will fire non-mutator listeners.
## Examples
This example registers a listener that responds to any changes to a specific [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addCellListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addcelllistener/)(
  'pets',
  'fido',
  'color',
  (store, tableId, rowId, cellId, newCell, oldCell, getCellChange) => {
    console.log('color cell in fido row in pets table changed');
    console.log([oldCell, newCell]);
    console.log(getCellChange('pets', 'fido', 'color'));
  },
);

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
// -> 'color cell in fido row in pets table changed'
// -> ['brown', 'walnut']
// -> [true, 'brown', 'walnut']

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any changes to any [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addCellListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addcelllistener/)(
  null,
  null,
  null,
  (store, tableId, rowId, cellId) => {
    console.log(
      `${cellId} cell in ${rowId} row in ${tableId} table changed`,
    );
  },
);

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
// -> 'color cell in fido row in pets table changed'
store.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {dog: {price: 5}});
// -> 'price cell in dog row in species table changed'

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any changes to a specific [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), and which also mutates the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) itself.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addCellListener[](https://tinybase.org/api/the-essentials/listening-for-changes/addcelllistener/)(
  'pets',
  'fido',
  'color',
  (store, tableId, rowId, cellId) =>
    store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('meta', 'update', `${tableId}_${rowId}_${cellId}`, true),
  true,
);

store.delCell[](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/delcell/)('pets', 'fido', 'color');
console.log(store.getTable[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettable/)('meta'));
// -> {update: {pets_fido_color: true}}

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```
