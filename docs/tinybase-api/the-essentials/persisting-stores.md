# Persisting stores
## `Persister`
Essential
A [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object lets you save and load [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data to and from different locations, or underlying storage types. [Read more](https://tinybase.org/api/the-essentials/persisting-stores/persister/).
## `createDurableObjectSqlStoragePersister`
Essential
The [`createDurableObjectSqlStoragePersister`](https://tinybase.org/api/the-essentials/persisting-stores/createdurableobjectsqlstoragepersister/) function creates a [`DurableObjectSqlStoragePersister`](https://tinybase.org/api/persister-durable-object-sql-storage/interfaces/persister/durableobjectsqlstoragepersister/) object that can persist the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to and from Cloudflare Durable Object SQLite storage. [Read more](https://tinybase.org/api/the-essentials/persisting-stores/createdurableobjectsqlstoragepersister/).
## `createLocalPersister`
Essential
The [`createLocalPersister`](https://tinybase.org/api/the-essentials/persisting-stores/createlocalpersister/) function creates a [`LocalPersister`](https://tinybase.org/api/persister-browser/interfaces/persister/localpersister/) object that can persist the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to the browser's local storage. [Read more](https://tinybase.org/api/the-essentials/persisting-stores/createlocalpersister/).
## `createPglitePersister`
Essential
The [`createPglitePersister`](https://tinybase.org/api/the-essentials/persisting-stores/createpglitepersister/) function creates a [`PglitePersister`](https://tinybase.org/api/persister-pglite/interfaces/persister/pglitepersister/) object that can persist the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to a local PGlite database. [Read more](https://tinybase.org/api/the-essentials/persisting-stores/createpglitepersister/).
## `createSessionPersister`
Essential
The [`createSessionPersister`](https://tinybase.org/api/the-essentials/persisting-stores/createsessionpersister/) function creates a [`SessionPersister`](https://tinybase.org/api/persister-browser/interfaces/persister/sessionpersister/) object that can persist the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to the browser's session storage. [Read more](https://tinybase.org/api/the-essentials/persisting-stores/createsessionpersister/).
## `createSqliteWasmPersister`
Essential
The [`createSqliteWasmPersister`](https://tinybase.org/api/the-essentials/persisting-stores/createsqlitewasmpersister/) function creates a [`SqliteWasmPersister`](https://tinybase.org/api/persister-sqlite-wasm/interfaces/persister/sqlitewasmpersister/) object that can persist the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to a local SQLite database. [Read more](https://tinybase.org/api/the-essentials/persisting-stores/createsqlitewasmpersister/).
