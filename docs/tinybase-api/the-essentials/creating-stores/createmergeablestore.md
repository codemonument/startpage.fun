# `createMergeableStore`
Essential
The `createMergeableStore` function creates a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/), and is the main entry point into the [`mergeable-store`](https://tinybase.org/api/mergeable-store/) module.

```
createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)(
  uniqueId?: string,
  getNow?: GetNow[](https://tinybase.org/api/common/type-aliases/stamps/getnow/),
): MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `uniqueId?`  | `string`  | An optional unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).  |  
| `getNow?`  | `GetNow[](https://tinybase.org/api/common/type-aliases/stamps/getnow/)`  | An optional function that generates millisecond timestamps, since v6.1.0, defaulting to `Date.now`.  |  
| returns  | `MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)`  | A reference to the new [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).  |  
There are two optional parameters which are only for testing and advanced usage.
The first is a uniqueId for the [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/), used to distinguish conflicting changes made in the same millisecond by two different [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) objects as its hash is added to the end of the HLC timestamps. Generally this can be omitted unless you have a need for deterministic HLCs, such as in a testing scenario. Otherwise, TinyBase will assign a unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) at the time of creation.
Since v6.1.0, the second is a function that can be used to replace the way the timestamp is generated for HLCs (by default JavaScript's `Date.now()` method).
## Examples
This example creates a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).

```
import {createMergeableStore} from 'tinybase';

const store = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)('store1');

console.log(store.getContent[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getcontent/)());
// -> [{}, {}]
console.log(store.getMergeableContent[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getmergeablecontent/)());
// -> [[{}, '', 0], [{}, '', 0]]

```

This example creates a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) with some initial data:

```
import {createMergeableStore} from 'tinybase';

const store = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)('store1').setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({
  pets: {fido: {species: 'dog'}},
});

console.log(store.getContent[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getcontent/)());
// -> [{pets: {fido: {species: 'dog'}}}, {}]
console.log(store.getMergeableContent[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getmergeablecontent/)());
// ->
[
  [
    {
      pets: [
        {
          fido: [
            {species: ['dog', 'Nn1JUF-----FnHIC', 290599168]},
            '',
            2682656941,
          ],
        },
        '',
        2102515304,
      ],
    },
    '',
    3506229770,
  ],
  [{}, '', 0],
];

```

This example creates a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) with some initial data and a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/):

```
import {createMergeableStore} from 'tinybase';

const store = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)('store1')
  .setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {fido: {species: 'dog'}}})
  .setTablesSchema[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settablesschema/)({
    pets: {
      species: {type: 'string'},
      sold: {type: 'boolean', default: false},
    },
  });

console.log(store.getContent[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getcontent/)());
// -> [{pets: {fido: {sold: false, species: 'dog'}}}, {}]
console.log(store.getMergeableContent[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getmergeablecontent/)());
// ->
[
  [
    {
      pets: [
        {
          fido: [
            {
              sold: [false, 'Nn1JUF----2FnHIC', 2603026204],
              species: ['dog', 'Nn1JUF----1FnHIC', 2817056260],
            },
            '',
            2859424112,
          ],
        },
        '',
        1640515891,
      ],
    },
    '',
    2077041985,
  ],
  [{}, '', 0],
];

```
