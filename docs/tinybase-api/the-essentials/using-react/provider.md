# `Provider`
Essential
The `Provider` component is used to wrap part of an application in a context that provides default objects to be used by hooks and components within.

```
Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)(props: (
  ProviderProps[](https://tinybase.org/api/ui-react/type-aliases/props/providerprops/) &
  {children: ReactNode}
)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `( ProviderProps[](https://tinybase.org/api/ui-react/type-aliases/props/providerprops/) & {children: ReactNode} )`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the child components.  |  
[`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/), [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/), [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/), [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/), [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/), [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/), and [`Synchronizer`](https://tinybase.org/api/the-essentials/synchronizing-stores/synchronizer/) objects can be passed into the context of an application and used throughout. One of each type of object can be provided as a default within the context. Additionally, multiple of each type of object can be provided in an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)-keyed map to the `___ById` props.
Provider contexts can be nested and the objects passed in will be merged. For example, if an outer context contains a default [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object and an inner context contains only a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), both the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) objects and the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) will be visible within the inner context. If the outer context contains a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and the inner context contains a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) named by a different [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), both will be visible within the inner context.
## Examples
This example creates a Provider context into which a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object are provided, one by default, and one named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). Components within it then render content from both, without the need to have them passed as props.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {CellView, Provider, useMetric} from 'tinybase/ui-react';

const App = ({store, metrics}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) store={store} metricsById={{petStore: metrics}}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => (
  <span>
    <CellView[](https://tinybase.org/api/ui-react/functions/store-components/cellview/) tableId="species" rowId="dog" cellId="price" />,
    <CellView[](https://tinybase.org/api/ui-react/functions/store-components/cellview/) tableId="species" rowId="cat" cellId="price" />,
    {useMetric[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetric/)('highestPrice', 'petStore')}
  </span>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
store.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {dog: {price: 5}, cat: {price: 4}});
const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App store={store} metrics={metrics} />);
console.log(app.innerHTML);
// -> '<span>5,4,5</span>'

```

This example creates nested Provider contexts into which [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) objects are provided, showing how visibility is merged.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {
  CellView,
  Provider,
  useCreateStore,
  useMetric,
} from 'tinybase/ui-react';

const App = ({petStore, metrics}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) storesById={{pet: petStore}} metrics={metrics}>
    <OuterPane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const OuterPane = () => {
  const planetStore = useCreateStore[](https://tinybase.org/api/the-essentials/using-react/usecreatestore/)(() =>
    createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({planets: {mars: {moons: 2}}}),
  );
  return (
    <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) storesById={{planet: planetStore}}>
      <InnerPane />
    </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
  );
};
const InnerPane = () => (
  <span>
    <CellView[](https://tinybase.org/api/ui-react/functions/store-components/cellview/) tableId="species" rowId="dog" cellId="price" store="pet" />,
    {useMetric[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetric/)('highestPrice')},
    <CellView[](https://tinybase.org/api/ui-react/functions/store-components/cellview/)
      tableId="planets"
      rowId="mars"
      cellId="moons"
      store="planet"
    />
  </span>
);

const petStore = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
petStore.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {dog: {price: 5}, cat: {price: 4}});
const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(petStore);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App petStore={petStore} metrics={metrics} />);
console.log(app.innerHTML);
// -> '<span>5,5,2</span>'

```
