# `useCell`
Essential
The `useCell` hook returns an object containing the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a given [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), in a given [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and registers a listener so that any changes to that result will cause a re-render.

```
useCell[](https://tinybase.org/api/the-essentials/using-react/usecell/)(
  tableId: string,
  rowId: string,
  cellId: string,
  storeOrStoreId?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/),
): CellOrUndefined[](https://tinybase.org/api/store/type-aliases/store/cellorundefined/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `rowId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `cellId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).  |  
| `storeOrStoreId?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be accessed: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| returns  | `CellOrUndefined[](https://tinybase.org/api/store/type-aliases/store/cellorundefined/)`  | The value of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).  |  
A [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component is used to wrap part of an application in a context, and it can contain a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) or a set of [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). The `useCell` hook lets you indicate which [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to get data for: omit the final optional final parameter for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) explicitly by reference.
When first rendered, this hook will create a listener so that changes to the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) will cause a re-render. When the component containing this hook is unmounted, the listener will be automatically removed.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) outside the application, which is used in the `useCell` hook by reference. A change to the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {useCell} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'brown');
const App = () => <span>{useCell[](https://tinybase.org/api/the-essentials/using-react/usecell/)('pets', 'fido', 'color', store)}</span>;

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<span>brown</span>'

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
console.log(app.innerHTML);
// -> '<span>walnut</span>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. A component within it then uses the `useCell` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, useCell} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => <span>{useCell[](https://tinybase.org/api/the-essentials/using-react/usecell/)('pets', 'fido', 'color')}</span>;

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'brown');
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<span>brown</span>'

```

This example creates a Provider context into which a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided, named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). A component within it then uses the `useCell` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, useCell} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) storesById={{petStore: store}}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => (
  <span>{useCell[](https://tinybase.org/api/the-essentials/using-react/usecell/)('pets', 'fido', 'color', 'petStore')}</span>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'brown');
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<span>brown</span>'

```
