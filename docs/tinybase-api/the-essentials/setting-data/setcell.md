# `setCell`
Essential
The `setCell` method sets the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)(
  tableId: string,
  rowId: string,
  cellId: string,
  cell: Cell[](https://tinybase.org/api/store/type-aliases/store/cell/) | MapCell[](https://tinybase.org/api/store/type-aliases/callback/mapcell/),
): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `rowId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `cellId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).  |  
| `cell`  | `Cell[](https://tinybase.org/api/store/type-aliases/store/cell/) | MapCell[](https://tinybase.org/api/store/type-aliases/callback/mapcell/)`  | The value of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to be set, or a [`MapCell`](https://tinybase.org/api/store/type-aliases/callback/mapcell/) function to update it.  |  
| returns  | `this`  | A reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
This method will cause listeners to be called for any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), or [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) changes resulting from it.
If the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value is invalid (either because of its type, or because it does not match a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) associated with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/)), will be ignored silently.
As well as string, number, boolean, null, object, and array [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) types, this method can also take a [`MapCell`](https://tinybase.org/api/store/type-aliases/callback/mapcell/) function that takes the current [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value as a parameter and maps it. This is useful if you want to efficiently increment a value without fetching it first, for example.
The method returns a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) so that subsequent operations can be chained in a fluent style.
## Examples
This example sets the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'species', 'dog');
console.log(store.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}}}

```

This example sets the data of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) by mapping the existing value.

```
import {createStore} from 'tinybase';

const increment = (cell) => cell + 1;
const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({pets: {fido: {visits: 1}}});

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'visits', increment);
console.log(store.getCell[](https://tinybase.org/api/the-essentials/getting-data/getcell/)('pets', 'fido', 'visits'));
// -> 2

```

This example attempts to set the data of an existing [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with an invalid [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({pets: {fido: {species: 'dog'}}});

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'bug', new Date(0));
console.log(store.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}}}

```
