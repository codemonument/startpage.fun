# `setValue`
Essential
The `setValue` method sets a single keyed [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)(
  valueId: string,
  value: Value[](https://tinybase.org/api/store/type-aliases/store/value/) | MapValue[](https://tinybase.org/api/store/type-aliases/callback/mapvalue/),
): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `valueId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `value`  | `Value[](https://tinybase.org/api/store/type-aliases/store/value/) | MapValue[](https://tinybase.org/api/store/type-aliases/callback/mapvalue/)`  | The [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) to be set, or a [`MapValue`](https://tinybase.org/api/store/type-aliases/callback/mapvalue/) function to update it.  |  
| returns  | `this`  | A reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
This method will cause listeners to be called for any [`Value`](https://tinybase.org/api/store/type-aliases/store/value/), or [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) changes resulting from it.
If the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) is invalid (either because of its type, or because it does not match a [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) associated with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/)), will be ignored silently.
As well as string, number, boolean, null, object, and array [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) types, this method can also take a [`MapValue`](https://tinybase.org/api/store/type-aliases/callback/mapvalue/) function that takes the current [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) as a parameter and maps it. This is useful if you want to efficiently increment a value without fetching it first, for example.
The method returns a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) so that subsequent operations can be chained in a fluent style.
## Examples
This example sets a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('open', true);
console.log(store.getValues[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getvalues/)());
// -> {open: true}

```

This example sets the data of a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) by mapping the existing [`Value`](https://tinybase.org/api/store/type-aliases/store/value/).

```
import {createStore} from 'tinybase';

const increment = (value) => value + 1;
const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({employees: 3});

store.setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('employees', increment);
console.log(store.getValue[](https://tinybase.org/api/the-essentials/getting-data/getvalue/)('employees'));
// -> 4

```

This example attempts to set an invalid [`Value`](https://tinybase.org/api/store/type-aliases/store/value/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({employees: 3});

store.setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('bug', new Date(0));
console.log(store.getValues[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getvalues/)());
// -> {employees: 3}

```
