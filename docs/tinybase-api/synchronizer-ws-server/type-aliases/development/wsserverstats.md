# `WsServerStats`
The `WsServerStats` type describes the number of paths and clients that are active on the [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/).

```
{
  paths: number;
  clients: number;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `paths`  | `number`  | The number of paths currently being served by the [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/).  |  
| `clients`  | `number`  | The number of clients currently being served by the [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/).  |  
A `WsServerStats` object is returned from the [`getStats`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/development/getstats/) method.
