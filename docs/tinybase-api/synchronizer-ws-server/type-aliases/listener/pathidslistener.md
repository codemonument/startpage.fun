# `PathIdsListener`
The `PathIdsListener` type describes a function that is used to listen to changes of active paths that a [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/) is handling.

```
(
  wsServer: WsServer[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/),
  pathId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/),
  addedOrRemoved: IdAddedOrRemoved[](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `wsServer`  | `WsServer[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/)`  | A reference to the [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/).  |  
| `pathId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the path being added or removed.  |  
| `addedOrRemoved`  | `IdAddedOrRemoved[](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/)`  | Whether the path was added (`1`) or removed (`-1`).  |  
| returns  | `void`  | This has no return value.  |  
A [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/) listens to any path, allowing an app to have the concept of distinct 'rooms' that only certain clients are participating in. As soon as a single client connects to a new path, this listener will be called with the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the new path and an `addedOrRemoved` value of `1`.
When the final client disconnects from a path, it will be called again with the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the deactivated path and an `addedOrRemoved` value of `-1`.
A `PathIdsListener` is provided when using the [`addPathIdsListener`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/listener/addpathidslistener/) method. See that method for specific examples.
