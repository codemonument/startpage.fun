# `addClientIdsListener`
The `addClientIdsListener` method registers a listener function with the [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/) that will be called whenever there is a change in the clients connected to a path that a [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/) is handling.

```
addClientIdsListener[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/listener/addclientidslistener/)(
  pathId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: ClientIdsListener[](https://tinybase.org/api/synchronizer-ws-server/type-aliases/listener/clientidslistener/),
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `pathId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The path to listen to, or `null` as a wildcard.  |  
| `listener`  | `ClientIdsListener[](https://tinybase.org/api/synchronizer-ws-server/type-aliases/listener/clientidslistener/)`  | The function that will be called whenever the client [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) on a path handled by the [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/) change.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
The provided listener is a [`ClientIdsListener`](https://tinybase.org/api/synchronizer-ws-server/type-aliases/listener/clientidslistener/) function, and will be called with a reference to the [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/), the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the path that the client joined or left, and a callback you can use to get information about the change.
You can either listen to a single path (by specifying its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first parameter) or changes to any path (by providing a `null` wildcard).
## Examples
This example creates a [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/), and listens to changes to the clients connecting to and disconnecting from a specific path.

```
import {createMergeableStore} from 'tinybase';
import {createWsSynchronizer} from 'tinybase/synchronizers/synchronizer-ws-client';
import {createWsServer} from 'tinybase/synchronizers/synchronizer-ws-server';
import {WebSocket, WebSocketServer} from 'ws';

const server = createWsServer[](https://tinybase.org/api/synchronizer-ws-server/functions/creation/createwsserver/)(new WebSocketServer({port: 8047}));
const listenerId = server.addClientIdsListener[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/listener/addclientidslistener/)(
  'roomA',
  (server, pathId) => {
    console.log(
      `${server.getClientIds[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/getclientids/)(pathId).length} client(s) in roomA`,
    );
  },
);

const synchronizer1 = await createWsSynchronizer[](https://tinybase.org/api/the-essentials/synchronizing-stores/createwssynchronizer/)(
  createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)(),
  new WebSocket('ws://localhost:8047/roomA'),
);
// -> '1 client(s) in roomA'

const synchronizer2 = await createWsSynchronizer[](https://tinybase.org/api/the-essentials/synchronizing-stores/createwssynchronizer/)(
  createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)(),
  new WebSocket('ws://localhost:8047/roomB'),
);
// The listener is not called.

await synchronizer1.destroy[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/destroy/)();
// ...
// -> '0 client(s) in roomA'

await synchronizer2.destroy[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/destroy/)();

server.delListener[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/listener/dellistener/)(listenerId);
await server.destroy[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/destroy/)();

```

This example creates a [`WsServer`](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/), and listens to changes to the clients connecting to and disconnecting from any path.

```
import {createMergeableStore} from 'tinybase';
import {createWsSynchronizer} from 'tinybase/synchronizers/synchronizer-ws-client';
import {createWsServer} from 'tinybase/synchronizers/synchronizer-ws-server';
import {WebSocket, WebSocketServer} from 'ws';

const server = createWsServer[](https://tinybase.org/api/synchronizer-ws-server/functions/creation/createwsserver/)(new WebSocketServer({port: 8047}));
const listenerId = server.addClientIdsListener[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/listener/addclientidslistener/)(null, (server, pathId) => {
  console.log(
    `${server.getClientIds[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/getclientids/)(pathId).length} client(s) in ${pathId}`,
  );
});

const synchronizer1 = await createWsSynchronizer[](https://tinybase.org/api/the-essentials/synchronizing-stores/createwssynchronizer/)(
  createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)(),
  new WebSocket('ws://localhost:8047/roomA'),
);
// -> '1 client(s) in roomA'

const synchronizer2 = await createWsSynchronizer[](https://tinybase.org/api/the-essentials/synchronizing-stores/createwssynchronizer/)(
  createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)(),
  new WebSocket('ws://localhost:8047/roomB'),
);
// -> '1 client(s) in roomB'

await synchronizer1.destroy[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/destroy/)();
// ...
// -> '0 client(s) in roomA'

await synchronizer2.destroy[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/destroy/)();
// ...
// -> '0 client(s) in roomB'

server.delListener[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/listener/dellistener/)(listenerId);
await server.destroy[](https://tinybase.org/api/synchronizer-ws-server/interfaces/server/wsserver/methods/getter/destroy/)();

```
