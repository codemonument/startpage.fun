# `addInvalidCellListener`
The `addInvalidCellListener` method registers a listener function with the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) that will be called whenever invalid data was attempted to be written to a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
addInvalidCellListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addinvalidcelllistener/)(
  tableId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  rowId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  cellId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: InvalidCellListener[](https://tinybase.org/api/store/type-aliases/listener/invalidcelllistener/)<Store[](https://tinybase.org/api/store/interfaces/store/store/)>,
  mutator?: boolean,
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to listen to, or `null` as a wildcard.  |  
| `rowId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to listen to, or `null` as a wildcard.  |  
| `cellId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `InvalidCellListener[](https://tinybase.org/api/store/type-aliases/listener/invalidcelllistener/)<Store[](https://tinybase.org/api/store/interfaces/store/store/)>`  | The function that will be called whenever an attempt to write invalid data to the matching [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) was made.  |  
| `mutator?`  | `boolean`  | An optional boolean that indicates that the listener mutates [`Store`](https://tinybase.org/api/store/interfaces/store/store/) data.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to call it explicitly, or to remove it.  |  
The provided listener is an [`InvalidCellListener`](https://tinybase.org/api/store/type-aliases/listener/invalidcelllistener/) function, and will be called with a reference to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) that was being attempted to be changed. It is also given the invalid value of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), which could have been of absolutely any type. Since there could have been multiple failed attempts to set the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) within a single transaction, this is an array containing each attempt, chronologically.
You can either listen to a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) (by specifying the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first three parameters) or invalid attempts to change any [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) (by providing `null` wildcards).
All, some, or none of the `tableId`, `rowId`, and `cellId` parameters can be wildcarded with `null`. You can listen to a specific [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a specific [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), any [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in any [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), for example - or every other combination of wildcards.
Use the optional mutator parameter to indicate that there is code in the listener that will mutate [`Store`](https://tinybase.org/api/store/interfaces/store/store/) data. If set to `false` (or omitted), such mutations will be silently ignored. All relevant mutator listeners (with this flag set to `true`) are called _before_ any non-mutator listeners (since the latter may become relevant due to changes made in the former). The changes made by mutator listeners do not fire other mutating listeners, though they will fire non-mutator listeners.
Special note should be made for how the listener will be called when a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) is present. The listener will be called:
  * if a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is being updated that is not specified in the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/),
  * if a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) is of the wrong type specified in the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/),
  * if a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) is omitted and is not defaulted in the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/),
  * or if an empty [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is provided and there are no [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) defaults in the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/).


The listener will not be called if a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) that is defaulted in the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) is not provided, as long as all of the Cells that are _not_ defaulted _are_ provided.
To help understand all of these schema-based conditions, please see the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) example below.
## Examples
This example registers a listener that responds to any invalid changes to a specific [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addInvalidCellListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addinvalidcelllistener/)(
  'pets',
  'fido',
  'birth',
  (store, tableId, rowId, cellId, invalidCells) => {
    console.log('Invalid birth cell in fido row in pets table');
    console.log(invalidCells);
  },
);

store.setCell[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/)('pets', 'fido', 'birth', new Date(0));
// -> 'Invalid birth cell in fido row in pets table'
// -> [new Date(0)]

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any invalid changes to any [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) - in a [`Store`](https://tinybase.org/api/store/interfaces/store/store/) _without_ a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/). Note also how it then responds to cases where empty or invalid [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects, or [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) objects, or [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) objects are provided.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addInvalidCellListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addinvalidcelllistener/)(
  null,
  null,
  null,
  (store, tableId, rowId, cellId) => {
    console.log(
      `Invalid ${cellId} cell in ${rowId} row in ${tableId} table`,
    );
  },
);

store.setCell[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/)('pets', 'fido', 'birth', new Date(0));
// -> 'Invalid birth cell in fido row in pets table'
store.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('sales', {fido: {birth: new Date()}});
// -> 'Invalid birth cell in fido row in sales table'

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'felix', {});
// -> 'Invalid undefined cell in felix row in pets table'

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('filter', 'name', /[a-z]?/);
// -> 'Invalid undefined cell in name row in filter table'

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('sales', '2021', {forecast: undefined});
// -> 'Invalid forecast cell in 2021 row in sales table'

store.addRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/addrow/)('filter', /[0-9]?/);
// -> 'Invalid undefined cell in undefined row in filter table'

store.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('raw', {});
// -> 'Invalid undefined cell in undefined row in raw table'

store.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('raw', ['row1', 'row2']);
// -> 'Invalid undefined cell in undefined row in raw table'

store.setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)(['table1', 'table2']);
// -> 'Invalid undefined cell in undefined row in undefined table'

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any invalid changes to any [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) - in a [`Store`](https://tinybase.org/api/store/interfaces/store/store/) _with_ a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/). Note how it responds to cases where missing parameters are provided for optional, and defaulted [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values in a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTablesSchema[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/)({
  pets: {
    species: {type: 'string'},
    color: {type: 'string', default: 'unknown'},
  },
});

const listenerId = store.addInvalidCellListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addinvalidcelllistener/)(
  null,
  null,
  null,
  (store, tableId, rowId, cellId) => {
    console.log(
      `Invalid ${cellId} cell in ${rowId} row in ${tableId} table`,
    );
  },
);

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('sales', 'fido', {price: 5});
// -> 'Invalid price cell in fido row in sales table'
// The listener is called, because the sales Table is not in the schema

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'felix', {species: true});
// -> 'Invalid species cell in felix row in pets table'
// The listener is called, because species is invalid...
console.log(store.getRow[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getrow/)('pets', 'felix'));
// -> {color: 'unknown'}
// ...even though a Row was set with the default value

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'fido', {color: 'brown'});
// -> 'Invalid species cell in fido row in pets table'
// The listener is called, because species is missing and not defaulted...
console.log(store.getRow[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getrow/)('pets', 'fido'));
// -> {color: 'brown'}
// ...even though a Row was set

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'rex', {species: 'dog'});
console.log(store.getRow[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getrow/)('pets', 'rex'));
// -> {species: 'dog', color: 'unknown'}
// The listener is not called, because color is defaulted

store.delTables[](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/deltables/)().setTablesSchema[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/)({
  pets: {
    species: {type: 'string'},
    color: {type: 'string'},
  },
});

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'cujo', {});
// -> 'Invalid species cell in cujo row in pets table'
// -> 'Invalid color cell in cujo row in pets table'
// -> 'Invalid undefined cell in cujo row in pets table'
// The listener is called multiple times, because neither Cell is defaulted
// and the Row as a whole is empty

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any changes to a specific [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), and which also mutates the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) itself.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addInvalidCellListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addinvalidcelllistener/)(
  'pets',
  'fido',
  'birth',
  (store, tableId, rowId, cellId, invalidCells) =>
    store.setCell[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/)(
      'meta',
      'invalid_updates',
      `${tableId}_${rowId}_${cellId}`,
      JSON.stringify(invalidCells[0]),
    ),
  true,
);

store.setCell[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/)('pets', 'fido', 'birth', new Date(0));
console.log(store.getRow[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getrow/)('meta', 'invalid_updates'));
// -> {'pets_fido_birth': '"1970-01-01T00:00:00.000Z"'}

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);
```
