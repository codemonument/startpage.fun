# `addTableCellIdsListener`
The `addTableCellIdsListener` method registers a listener function with the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) that will be called whenever the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that appear anywhere in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) change.

```
addTableCellIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addtablecellidslistener/)(
  tableId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: TableCellIdsListener[](https://tinybase.org/api/store/type-aliases/listener/tablecellidslistener/)<Store[](https://tinybase.org/api/store/interfaces/store/store/)>,
  mutator?: boolean,
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `TableCellIdsListener[](https://tinybase.org/api/store/type-aliases/listener/tablecellidslistener/)<Store[](https://tinybase.org/api/store/interfaces/store/store/)>`  | The function that will be called whenever the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that appear anywhere in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) change.  |  
| `mutator?`  | `boolean`  | An optional boolean that indicates that the listener mutates [`Store`](https://tinybase.org/api/store/interfaces/store/store/) data.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to call it explicitly, or to remove it.  |  
The provided listener is a [`TableCellIdsListener`](https://tinybase.org/api/store/type-aliases/listener/tablecellidslistener/) function, and will be called with a reference to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that changed.
By default, such a listener is only called when a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) is added or removed from the whole of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). To listen to all changes in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), use the [`addTableListener`](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addtablelistener/) method.
You can either listen to a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (by specifying its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first parameter) or changes to any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (by providing a `null` wildcard).
Use the optional mutator parameter to indicate that there is code in the listener that will mutate [`Store`](https://tinybase.org/api/store/interfaces/store/store/) data. If set to `false` (or omitted), such mutations will be silently ignored. All relevant mutator listeners (with this flag set to `true`) are called _before_ any non-mutator listeners (since the latter may become relevant due to changes made in the former). The changes made by mutator listeners do not fire other mutating listeners, though they will fire non-mutator listeners.
## Examples
This example registers a listener that responds to any change to the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that appear anywhere in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addTableCellIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addtablecellidslistener/)('pets', (store) => {
  console.log('Cell Ids in pets table changed');
  console.log(store.getTableCellIds[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettablecellids/)('pets'));
});

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'felix', {species: 'cat', legs: 4});
// -> 'Cell Ids in pets table changed'
// -> ['species', 'color', 'legs']

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any change to the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that appear anywhere in any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
  species: {dog: {price: 5}},
});
const listenerId = store.addTableCellIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addtablecellidslistener/)(
  null,
  (store, tableId) => {
    console.log(`Cell Ids in ${tableId} table changed`);
    console.log(store.getTableCellIds[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettablecellids/)(tableId));
  },
);

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'felix', {species: 'cat', legs: 4});
// -> 'Cell Ids in pets table changed'
// -> ['species', 'color', 'legs']

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('species', 'cat', {price: 4, friendly: true});
// -> 'Cell Ids in species table changed'
// -> ['price', 'friendly']

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that appear anywhere in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and which also mutates the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) itself.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', color: 'brown'}},
});
const listenerId = store.addTableCellIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addtablecellidslistener/)(
  'pets',
  (store, tableId) => store.setCell[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/)('meta', 'update', tableId, true),
  true, // mutator
);

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'felix', {species: 'cat', legs: 4});
console.log(store.getTable[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettable/)('meta'));
// -> {update: {pets: true}}

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```
