# `addSortedRowIdsListener`
The `addSortedRowIdsListener` method registers a listener function with the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) that will be called whenever sorted (and optionally, paginated) [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) change.

```
addSortedRowIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addsortedrowidslistener/)(
  tableId: string,
  cellId: undefined | string,
  descending: boolean,
  offset: number,
  limit: undefined | number,
  listener: SortedRowIdsListener[](https://tinybase.org/api/store/type-aliases/listener/sortedrowidslistener/)<Store[](https://tinybase.org/api/store/interfaces/store/store/)>,
  mutator?: boolean,
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to listen to.  |  
| `cellId`  | `undefined | string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) whose values are used for the sorting, or `undefined` to sort by the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) itself.  |  
| `descending`  | `boolean`  | Whether the sorting should be in descending order.  |  
| `offset`  | `number`  | The number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to skip for pagination purposes, if any.  |  
| `limit`  | `undefined | number`  | The maximum number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to return, or `undefined` for all.  |  
| `listener`  | `SortedRowIdsListener[](https://tinybase.org/api/store/type-aliases/listener/sortedrowidslistener/)<Store[](https://tinybase.org/api/store/interfaces/store/store/)>`  | The function that will be called whenever the sorted [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) change.  |  
| `mutator?`  | `boolean`  | An optional boolean that indicates that the listener mutates [`Store`](https://tinybase.org/api/store/interfaces/store/store/) data.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to call it explicitly, or to remove it.  |  
The provided listener is a [`SortedRowIdsListener`](https://tinybase.org/api/store/type-aliases/listener/sortedrowidslistener/) function, and will be called with a reference to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) whose [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) sorting changed, the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) being used to sort them, whether descending or not, and the offset and limit of the number of [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) returned, for pagination purposes. It also receives the sorted array of [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) itself, so that you can use them in the listener without the additional cost of an explicit call to getSortedRowIds.
Such a listener is called when a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is added or removed, but also when a value in the specified [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) (somewhere in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)) has changed enough to change the sorting of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/).
Unlike most other listeners, you cannot provide wildcards (due to the cost of detecting changes to the sorting). You can only listen to a single specified [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), sorted by a single specified [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).
The sorting of the rows is alphanumeric, and you can indicate whether it should be in descending order. The `offset` and `limit` parameters are used to paginate results, but default to `0` and `undefined` to return all available [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) if not specified.
Use the optional mutator parameter to indicate that there is code in the listener that will mutate [`Store`](https://tinybase.org/api/store/interfaces/store/store/) data. If set to `false` (or omitted), such mutations will be silently ignored. All relevant mutator listeners (with this flag set to `true`) are called _before_ any non-mutator listeners (since the latter may become relevant due to changes made in the former). The changes made by mutator listeners do not fire other mutating listeners, though they will fire non-mutator listeners.
## Examples
This example registers a listener that responds to any change to the sorted [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {
    cujo: {species: 'wolf'},
    felix: {species: 'cat'},
  },
});
console.log(store.getSortedRowIds[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getsortedrowids/)('pets', 'species', false));
// -> ['felix', 'cujo']

const listenerId = store.addSortedRowIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addsortedrowidslistener/)(
  'pets',
  'species',
  false,
  0,
  undefined,
  (store, tableId, cellId, descending, offset, limit, sortedRowIds) => {
    console.log(`Sorted Row Ids for ${tableId} table changed`);
    console.log(sortedRowIds);
    // ^ cheaper than calling getSortedRowIds again
  },
);

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'fido', {species: 'dog'});
// -> 'Sorted Row Ids for pets table changed'
// -> ['felix', 'fido', 'cujo']

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any change to a paginated section of the sorted [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {
    fido: {price: 6},
    felix: {price: 5},
    mickey: {price: 2},
    tom: {price: 4},
    carnaby: {price: 3},
    lowly: {price: 1},
  },
});

const listenerId = store.addSortedRowIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addsortedrowidslistener/)(
  'pets',
  'price',
  false,
  0,
  3,
  (store, tableId, cellId, descending, offset, limit, sortedRowIds) => {
    console.log(`First three sorted Row Ids for ${tableId} table changed`);
    console.log(sortedRowIds);
    // ^ cheaper than calling getSortedRowIds again
  },
);
console.log(store.getSortedRowIds[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getsortedrowids/)('pets', 'price', false, 0, 3));
// -> ['lowly', 'mickey', 'carnaby']

store.setCell[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/)('pets', 'carnaby', 'price', 4.5);
// -> 'First three sorted Row Ids for pets table changed'
// -> ['lowly', 'mickey', 'tom']

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any change to the sorted [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and which also mutates the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) itself.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {
```
```
    cujo: {species: 'wolf'},
    felix: {species: 'cat'},
  },
});
const listenerId = store.addSortedRowIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addsortedrowidslistener/)(
  'pets',
  'species',
  false,
  0,
  undefined,
  (store, tableId) => store.setCell[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/)('meta', 'sorted', tableId, true),
  true, // mutator
);

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'fido', {species: 'dog'});
console.log(store.getTable[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettable/)('meta'));
// -> {sorted: {pets: true}}

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```

## Since
v2.0.0
When called with an object as the first argument, the `addSortedRowIdsListener` method destructures it to make it easier to skip optional parameters.

```
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `args`  | `SortedRowIdsArgs[](https://tinybase.org/api/store/type-aliases/store/sortedrowidsargs/)`  | A [`SortedRowIdsArgs`](https://tinybase.org/api/store/type-aliases/store/sortedrowidsargs/) object containing the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), and optional `cellId`, `descending`, `offset`, and `limit` parameters.  |  
| `listener`  | `SortedRowIdsListener[](https://tinybase.org/api/store/type-aliases/listener/sortedrowidslistener/)<Store[](https://tinybase.org/api/store/interfaces/store/store/)>`  | The function that will be called whenever the sorted [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) change.  |  
| `mutator?`  | `boolean`  | An optional boolean that indicates that the listener mutates [`Store`](https://tinybase.org/api/store/interfaces/store/store/) data.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to call it explicitly, or to remove it.  |  
## Example
This example registers a listener that responds to any change to the first of the sorted [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of a specific [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {price: 6}, felix: {price: 5}},
});

const listenerId = store.addSortedRowIdsListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addsortedrowidslistener/)(
  {tableId: 'pets', limit: 1},
  (store, tableId, cellId, descending, offset, limit, sortedRowIds) => {
    console.log(`First sorted Row Id for ${tableId} table changed`);
    console.log(sortedRowIds);
    // ^ cheaper than calling getSortedRowIds again
  },
);
console.log(store.getSortedRowIds[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getsortedrowids/)({tableId: 'pets', limit: 1}));
// -> ['felix']

store.setRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/)('pets', 'carnaby', {price: 4.5});
// -> 'First sorted Row Id for pets table changed'
// -> ['carnaby']

store.delListener[](https://tinybase.org/api/store/interfaces/store/store/methods/listener/dellistener/)(listenerId);

```
