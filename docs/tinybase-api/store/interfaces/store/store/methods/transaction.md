# Transaction methods
## `finishTransaction`
The [`finishTransaction`](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/finishtransaction/) method allows you to explicitly finish a transaction that has made multiple mutations to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), triggering all calls to the relevant listeners. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/finishtransaction/).
## `getTransactionChanges`
The [`getTransactionChanges`](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/gettransactionchanges/) method returns the net meaningful changes that have been made to a [`Store`](https://tinybase.org/api/store/interfaces/store/store/) during a transaction. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/gettransactionchanges/).
## `getTransactionLog`
The [`getTransactionLog`](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/gettransactionlog/) method returns the changes that were made to a [`Store`](https://tinybase.org/api/store/interfaces/store/store/) during a transaction in more detail, including invalid changes, and what previous values were. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/gettransactionlog/).
## `startTransaction`
The [`startTransaction`](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/starttransaction/) method allows you to explicitly start a transaction that will make multiple mutations to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), buffering all calls to the relevant listeners until it completes when you call the [`finishTransaction`](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/finishtransaction/) method. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/starttransaction/).
## `transaction`
Essential
The [`transaction`](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/transaction/) method takes a function that makes multiple mutations to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), buffering all calls to the relevant listeners until it completes. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/transaction/).
