# `setTablesSchema`
The `setTablesSchema` method lets you specify the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) of the tabular part of the [`Store`](https://tinybase.org/api/store/interfaces/store/store/).

```
setTablesSchema[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/)(tablesSchema: TablesSchema[](https://tinybase.org/api/store/type-aliases/schema/tablesschema/)): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tablesSchema`  | `TablesSchema[](https://tinybase.org/api/store/type-aliases/schema/tablesschema/)`  | The [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) to be set for the [`Store`](https://tinybase.org/api/store/interfaces/store/store/).  |  
| returns  | `this`  | A reference to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/).  |  
Note that this may result in a change to data in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), as defaults are applied or as invalid [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), or [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) objects are removed. These changes will fire any listeners to that data, as expected.
When no longer needed, you can also completely remove an existing [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) with the [`delTablesSchema`](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/deltablesschema/) method.
## Example
This example sets the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) of a [`Store`](https://tinybase.org/api/store/interfaces/store/store/) after it has been created.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTablesSchema[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/)({
  pets: {
    species: {type: 'string'},
    sold: {type: 'boolean', default: false},
  },
});
store.addRow[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/addrow/)('pets', {species: 'dog', color: 'brown', sold: 'maybe'});

console.log(store.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {0: {species: 'dog', sold: false}}}

```
