# Setter methods
## `setTables`
The [`setTables`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/) method takes an object and sets the entire tabular data of the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/).
## `setTablesJson`
The [`setTablesJson`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesjson/) method takes a string serialization of all of the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) and attempts to update them to that. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesjson/).
## `setTablesSchema`
The [`setTablesSchema`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/) method lets you specify the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) of the tabular part of the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/).
## `setTable`
The [`setTable`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/) method takes an object and sets the entire data of a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/).
## `setRow`
Essential
The [`setRow`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/) method takes an object and sets the entire data of a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setrow/).
## `addRow`
Essential
The [`addRow`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/addrow/) method takes an object and creates a new [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), returning the unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) assigned to it. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/addrow/).
## `setPartialRow`
The [`setPartialRow`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setpartialrow/) method takes an object and sets partial data of a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), leaving other [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values unaffected. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setpartialrow/).
## `setCell`
Essential
The [`setCell`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/) method sets the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/).
## `setPartialValues`
The [`setPartialValues`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setpartialvalues/) method takes an object and sets its [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), but leaving existing [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) unaffected. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setpartialvalues/).
## `setValues`
The [`setValues`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/) method takes an object and sets all the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/).
## `setValuesJson`
The [`setValuesJson`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvaluesjson/) method takes a string serialization of all of the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) and attempts to update them to those values. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvaluesjson/).
## `setValuesSchema`
The [`setValuesSchema`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvaluesschema/) method lets you specify the [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) of the keyed [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) part of the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvaluesschema/).
## `setValue`
Essential
The [`setValue`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalue/) method sets a single keyed [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalue/).
## `applyChanges`
The [`applyChanges`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/applychanges/) method applies a set of [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/applychanges/).
## `setContent`
The [`setContent`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcontent/) method takes an array of two objects and sets the entire data of the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcontent/).
## `setJson`
The [`setJson`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setjson/) method takes a string serialization of all of the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) and [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) and attempts to update them to those values. [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setjson/).
## `setSchema`
The [`setSchema`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setschema/) method lets you specify the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) and [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) of the [`Store`](https://tinybase.org/api/store/interfaces/store/store/). [Read more](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setschema/).
