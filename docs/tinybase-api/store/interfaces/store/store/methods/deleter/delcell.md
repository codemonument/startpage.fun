# `delCell`
The `delCell` method lets you remove a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) from a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).

```
delCell[](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/delcell/)(
  tableId: string,
  rowId: string,
  cellId: string,
  forceDel?: boolean,
): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/store/interfaces/store/store/).  |  
| `rowId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `cellId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).  |  
| `forceDel?`  | `boolean`  | An optional flag to indicate that the whole [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) should be deleted, even if a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) provides a default value for this [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/). Defaults to `false`.  |  
| returns  | `this`  | A reference to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/).  |  
When there is no [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) applied to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/), then if this is the last [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in its [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), then that [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) will be removed. If, in turn, that is the last [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in its [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), then that [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) will be removed.
If there is a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) applied to the [`Store`](https://tinybase.org/api/store/interfaces/store/store/) and it specifies a default value for this [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), then deletion will result in it being set back to its default value. To override this, use the `forceDel` parameter, as described below.
The `forceDel` parameter is an optional flag that is only relevant if a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) provides a default value for this [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/). Under such circumstances, deleting a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value will normally restore it to the default value. If this flag is set to `true`, the complete removal of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) is instead guaranteed. But since doing do so would result in an invalid [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) (according to the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/)), in fact the whole [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is deleted to retain the integrity of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). Therefore, this flag should be used with caution.
## Examples
This example removes a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) from a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) without a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog', sold: true}},
});
store.delCell[](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/delcell/)('pets', 'fido', 'sold');

console.log(store.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}}}

```

This example removes a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) from a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) with a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) that defaults its value.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
    pets: {fido: {species: 'dog', sold: true}},
  })
  .setTablesSchema[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/)({
    pets: {
      species: {type: 'string'},
      sold: {type: 'boolean', default: false},
    },
  });
store.delCell[](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/delcell/)('pets', 'fido', 'sold');

console.log(store.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog', sold: false}}}

```

This example removes a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) from a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) with a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) that defaults its value, but uses the `forceDel` parameter to override it.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
    pets: {fido: {species: 'dog', sold: true}, felix: {species: 'cat'}},
  })
  .setTablesSchema[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settablesschema/)({
    pets: {
      species: {type: 'string'},
      sold: {type: 'boolean', default: false},
    },
  });
store.delCell[](https://tinybase.org/api/store/interfaces/store/store/methods/deleter/delcell/)('pets', 'fido', 'sold', true);

console.log(store.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {felix: {species: 'cat', sold: false}}}

```
