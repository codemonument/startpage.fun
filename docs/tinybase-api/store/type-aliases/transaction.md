# Transaction type aliases
## `ChangedTableIds`
The [`ChangedTableIds`](https://tinybase.org/api/store/type-aliases/transaction/changedtableids/) type describes the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that were added or removed during a transaction. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedtableids/).
## `ChangedRowIds`
The [`ChangedRowIds`](https://tinybase.org/api/store/type-aliases/transaction/changedrowids/) type describes the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that were added or removed during a transaction. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedrowids/).
## `ChangedCellIds`
The [`ChangedCellIds`](https://tinybase.org/api/store/type-aliases/transaction/changedcellids/) type describes the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that were added or removed during a transaction. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedcellids/).
## `ChangedCell`
The [`ChangedCell`](https://tinybase.org/api/store/type-aliases/transaction/changedcell/) type describes a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) that has been changed during a transaction, primarily used so that you can indicate whether the transaction should be rolled back. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedcell/).
## `ChangedCells`
The [`ChangedCells`](https://tinybase.org/api/store/type-aliases/transaction/changedcells/) type describes the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values that have been changed during a transaction, primarily used so that you can indicate whether the transaction should be rolled back. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedcells/).
## `InvalidCells`
The [`InvalidCells`](https://tinybase.org/api/store/type-aliases/transaction/invalidcells/) type describes the invalid [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values that have been attempted during a transaction, primarily used so that you can indicate whether the transaction should be rolled back. [Read more](https://tinybase.org/api/store/type-aliases/transaction/invalidcells/).
## `ChangedValues`
The [`ChangedValues`](https://tinybase.org/api/store/type-aliases/transaction/changedvalues/) type describes the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) that have been changed during a transaction, primarily used so that you can indicate whether the transaction should be rolled back. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedvalues/).
## `InvalidValues`
The [`InvalidValues`](https://tinybase.org/api/store/type-aliases/transaction/invalidvalues/) type describes the invalid [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) that have been attempted during a transaction, primarily used so that you can indicate whether the transaction should be rolled back. [Read more](https://tinybase.org/api/store/type-aliases/transaction/invalidvalues/).
## `ChangedValue`
The [`ChangedValue`](https://tinybase.org/api/store/type-aliases/transaction/changedvalue/) type describes a [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) that has been changed during a transaction, primarily used so that you can indicate whether the transaction should be rolled back. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedvalue/).
## `ChangedValueIds`
The [`ChangedValueIds`](https://tinybase.org/api/store/type-aliases/transaction/changedvalueids/) type describes the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that were added or removed during a transaction. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changedvalueids/).
## `Changes`
The [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) type describes the net meaningful changes that were made to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) during a transaction. [Read more](https://tinybase.org/api/store/type-aliases/transaction/changes/).
## `IdAddedOrRemoved`
The [`IdAddedOrRemoved`](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/) type describes a change made to an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in either the tabular or keyed-value part of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (or in other TinyBase modules). [Read more](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/).
## `TransactionLog`
The [`TransactionLog`](https://tinybase.org/api/store/type-aliases/transaction/transactionlog/) type describes the changes that were made to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) during a transaction in detail. [Read more](https://tinybase.org/api/store/type-aliases/transaction/transactionlog/).
