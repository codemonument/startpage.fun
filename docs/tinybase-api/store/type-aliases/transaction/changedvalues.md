# `ChangedValues`
The `ChangedValues` type describes the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) that have been changed during a transaction, primarily used so that you can indicate whether the transaction should be rolled back.

```
{[valueId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: ChangedValue[](https://tinybase.org/api/store/type-aliases/transaction/changedvalue/)}
```

A `ChangedValues` object is provided to the `doRollback` callback when using the [`transaction`](https://tinybase.org/api/the-essentials/setting-data/transaction/) method and the [`finishTransaction`](https://tinybase.org/api/store/interfaces/store/store/methods/transaction/finishtransaction/) method. See those methods for specific examples.
This type is an object containing the old and new [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in two-part arrays. These are describing the state of each changed [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) at the _start_ of the transaction, and by the _end_ of the transaction.
Hence, an `undefined` value for the first item in the array means that the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) was added during the transaction. An `undefined` value for the second item in the array means that the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) was removed during the transaction. An array with two different [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) indicates that it was changed. The two-part array will never contain two items of the same value (including two `undefined` values), even if, during the transaction, a [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) was changed to a different value and then changed back.
