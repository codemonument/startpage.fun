# `ChangedRowIds`
The `ChangedRowIds` type describes the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that were added or removed during a transaction.

```
{[tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: {[rowId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: IdAddedOrRemoved[](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/)}}
```

It is available to the [`DoRollback`](https://tinybase.org/api/store/type-aliases/callback/dorollback/) function and to a [`TransactionListener`](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/) function via the [`TransactionLog`](https://tinybase.org/api/store/type-aliases/transaction/transactionlog/) object.
It is a nested object that has [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as a top-level key, and then [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as an inner key. The values of the inner objects are [`IdAddedOrRemoved`](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/) numbers indicating whether the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) was added (1) or removed (-1) to the given [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).
Note that there will be no entry if the content of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) itself changed. For that you should consult the [`ChangedCellIds`](https://tinybase.org/api/store/type-aliases/transaction/changedcellids/) or [`ChangedCells`](https://tinybase.org/api/store/type-aliases/transaction/changedcells/) types.
