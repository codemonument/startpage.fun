# `TransactionLog`
The `TransactionLog` type describes the changes that were made to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) during a transaction in detail.

```
[cellsTouched: boolean, valuesTouched: boolean, changedCells: ChangedCells[](https://tinybase.org/api/store/type-aliases/transaction/changedcells/), invalidCells: InvalidCells[](https://tinybase.org/api/store/type-aliases/transaction/invalidcells/), changedValues: ChangedValues[](https://tinybase.org/api/store/type-aliases/transaction/changedvalues/), invalidValues: InvalidValues[](https://tinybase.org/api/store/type-aliases/transaction/invalidvalues/), changedTableIds: ChangedTableIds[](https://tinybase.org/api/store/type-aliases/transaction/changedtableids/), changedRowIds: ChangedRowIds[](https://tinybase.org/api/store/type-aliases/transaction/changedrowids/), changedCellIds: ChangedCellIds[](https://tinybase.org/api/store/type-aliases/transaction/changedcellids/), changedValueIds: ChangedValueIds[](https://tinybase.org/api/store/type-aliases/transaction/changedvalueids/)]
```

This contains equivalent information to a [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) object, but also information about what the previous state of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) was. The changedCells and changedValues entries contain information about all changes to those parts of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), with their before and after values, for example.
`cellsTouched` and `valuesTouched` indicate whether [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) data has been touched during the transaction. The two flags are intended as a hint about whether non-mutating listeners might be being called at the end of the transaction.
Here, 'touched' means that [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) data has either been changed, or changed and then changed back to its original value during the transaction. The exception is a transaction that has been rolled back, for which the value of `cellsTouched` and `valuesTouched` in the listener will be `false` because all changes have been reverted.
In v5.0, this type changed from an object to an array, but still contains the same values.
See the documentation for the types of the inner objects for other details.
