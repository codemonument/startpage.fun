# `Changes`
The `Changes` type describes the net meaningful changes that were made to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) during a transaction.

```
[changedTables: {[tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: {[rowId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: {[cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: CellOrUndefined[](https://tinybase.org/api/store/type-aliases/store/cellorundefined/)} | undefined} | undefined}, changedValues: {[valueId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: ValueOrUndefined[](https://tinybase.org/api/store/type-aliases/store/valueorundefined/)}, isChanges: 1]
```

This contains mostly equivalent information to a [`TransactionLog`](https://tinybase.org/api/store/type-aliases/transaction/transactionlog/), but in a form that can be more efficiently parsed and serialized (for example in the case of synchronization between systems).
It is an array of two objects, representing tabular and keyed value changes. If the first item is an empty object, it means no tabular changes were made. If the second item is an empty object, it means no keyed value changes were made.
If not empty, the first object has an entry for each [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that has had a change within it. If the entry is null, it means that whole [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) was deleted. Otherwise, the entry will be an object with an entry for each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in that [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that had a change within it. In turn, if that entry is null, it means the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) was deleted. Otherwise, the entry will be an object with an entry for each [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in that [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) that had a change within it. If the entry is null, the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) was deleted, otherwise it will contain the new value the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) was changed to during the transaction.
If not empty, the second object has an entry for each [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that has had a change. If the entry is null, the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) was deleted, otherwise it will contain the new [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) it was changed to during the transaction.
A third, required, item in the array is the digit `1`, so that instances of [`Content`](https://tinybase.org/api/store/type-aliases/store/content/) and `Changes` types can be disambiguated.
## Example
The following is a valid `Changes` array that conveys the following:

```
[
  {                     // changes to tabular data in the Store
    "pets": {             // this Table was changed
      "fido": null,         // this Row was deleted
      "felix": {            // this Row was changed
        "sold": true,         // this Cell was changed
        "price": null,        // this Cell was deleted
      },
    },
    "pendingSales": null, // this Table was deleted
  },
  {},                   // no changes to keyed value data in the Store
  1,                    // indicates that this is a Changes array
]

```
