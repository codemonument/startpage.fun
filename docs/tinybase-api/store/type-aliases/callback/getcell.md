# `GetCell`
The `GetCell` type describes a function that takes a [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and returns the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value for a particular [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).

```
(cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)): CellOrUndefined[](https://tinybase.org/api/store/type-aliases/store/cellorundefined/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `cellId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to fetch the value for.  |  
| returns  | `CellOrUndefined[](https://tinybase.org/api/store/type-aliases/store/cellorundefined/)`  |   |  
A `GetCell` can be provided when setting definitions, as in the [`setMetricDefinition`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/) method of a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, or the [`setIndexDefinition`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/) method of an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object. See those methods for specific examples.
