# Listener type aliases
## `TablesListener`
The [`TablesListener`](https://tinybase.org/api/store/type-aliases/listener/tableslistener/) type describes a function that is used to listen to changes to the tabular part of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/store/type-aliases/listener/tableslistener/).
## `HasTablesListener`
The [`HasTablesListener`](https://tinybase.org/api/store/type-aliases/listener/hastableslistener/) type describes a function that is used to listen to [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) as a whole being added to or removed from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/store/type-aliases/listener/hastableslistener/).
## `TableIdsListener`
The [`TableIdsListener`](https://tinybase.org/api/store/type-aliases/listener/tableidslistener/) type describes a function that is used to listen to changes to the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/store/type-aliases/listener/tableidslistener/).
## `TableCellIdsListener`
The [`TableCellIdsListener`](https://tinybase.org/api/store/type-aliases/listener/tablecellidslistener/) type describes a function that is used to listen to changes to the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that appear anywhere in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). [Read more](https://tinybase.org/api/store/type-aliases/listener/tablecellidslistener/).
## `TableListener`
The [`TableListener`](https://tinybase.org/api/store/type-aliases/listener/tablelistener/) type describes a function that is used to listen to changes to a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). [Read more](https://tinybase.org/api/store/type-aliases/listener/tablelistener/).
## `HasTableCellListener`
The [`HasTableCellListener`](https://tinybase.org/api/store/type-aliases/listener/hastablecelllistener/) type describes a function that is used to listen to a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) being added to or removed from a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) as a whole. [Read more](https://tinybase.org/api/store/type-aliases/listener/hastablecelllistener/).
