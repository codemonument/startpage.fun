# `NoTablesSchema`
The `NoTablesSchema` type is a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/)-like type for when one has not been provided.

```
{[tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: {[cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: {type: "any"}}}
```
