# `HasTableCellListener`
The `HasTableCellListener` type describes a function that is used to listen to a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) being added to or removed from a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) as a whole.

```
(
  store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/),
  tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/),
  cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/),
  hasTableCell: boolean,
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `store`  | `Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)`  | A reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that changed.  |  
| `tableId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that changed.  |  
| `cellId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) that changed.  |  
| `hasTableCell`  | `boolean`  | Whether the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) now exists anywhere in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) or not.  |  
| returns  | `void`  | This has no return value.  |  
A `HasTableCellListener` is provided when using the [`addHasTableCellListener`](https://tinybase.org/api/store/interfaces/store/store/methods/listener/addhastablecelllistener/) method. See that method for specific examples.
When called, a `HasTableCellListener` is given a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that changed, and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) that changed. It is also given a flag to indicate whether the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) now exists anywhere in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (having not done previously), or does not (having done so previously).
