# `StoreListenerStats`
The `StoreListenerStats` type describes the number of listeners registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and can be used for debugging purposes.

```
{
  hasTables: number;
  tables: number;
  tableIds: number;
  hasTable: number;
  table: number;
  tableCellIds: number;
  hasTableCell: number;
  rowCount: number;
  rowIds: number;
  sortedRowIds: number;
  hasRow: number;
  row: number;
  cellIds: number;
  hasCell: number;
  cell: number;
  invalidCell: number;
  hasValues: number;
  values: number;
  valueIds: number;
  hasValue: number;
  value: number;
  invalidValue: number;
  transaction: number;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `hasTables`  | `number`  | The number of [`HasTablesListener`](https://tinybase.org/api/store/type-aliases/listener/hastableslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.4.  |  
| `tables`  | `number`  | The number of [`TablesListener`](https://tinybase.org/api/store/type-aliases/listener/tableslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `tableIds`  | `number`  | The number of [`TableIdsListener`](https://tinybase.org/api/store/type-aliases/listener/tableidslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `hasTable`  | `number`  | The number of [`HasTableListener`](https://tinybase.org/api/store/type-aliases/listener/hastablelistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.4.  |  
| `table`  | `number`  | The number of [`TableListener`](https://tinybase.org/api/store/type-aliases/listener/tablelistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `tableCellIds`  | `number`  | The number of [`TableCellIdsListener`](https://tinybase.org/api/store/type-aliases/listener/tablecellidslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v3.3.  |  
| `hasTableCell`  | `number`  | The number of [`HasTableCellListener`](https://tinybase.org/api/store/type-aliases/listener/hastablecelllistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.4.  |  
| `rowCount`  | `number`  | The number of [`RowCountListener`](https://tinybase.org/api/store/type-aliases/listener/rowcountlistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.1.0.  |  
| `rowIds`  | `number`  | The number of [`RowIdsListener`](https://tinybase.org/api/store/type-aliases/listener/rowidslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `sortedRowIds`  | `number`  | The number of [`SortedRowIdsListener`](https://tinybase.org/api/store/type-aliases/listener/sortedrowidslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `hasRow`  | `number`  | The number of [`HasRowListener`](https://tinybase.org/api/store/type-aliases/listener/hasrowlistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.4.  |  
| `row`  | `number`  | The number of [`RowListener`](https://tinybase.org/api/store/type-aliases/listener/rowlistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `cellIds`  | `number`  | The number of [`CellIdsListener`](https://tinybase.org/api/store/type-aliases/listener/cellidslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `hasCell`  | `number`  | The number of [`HasCellListener`](https://tinybase.org/api/store/type-aliases/listener/hascelllistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.4.  |  
| `cell`  | `number`  | The number of [`CellListener`](https://tinybase.org/api/store/type-aliases/listener/celllistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `invalidCell`  | `number`  | The number of [`InvalidCellListener`](https://tinybase.org/api/store/type-aliases/listener/invalidcelllistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `hasValues`  | `number`  | The number of [`HasValuesListener`](https://tinybase.org/api/store/type-aliases/listener/hasvalueslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.4.  |  
| `values`  | `number`  | The number of [`ValuesListener`](https://tinybase.org/api/store/type-aliases/listener/valueslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v3.0.  |  
| `valueIds`  | `number`  | The number of [`ValueIdsListener`](https://tinybase.org/api/store/type-aliases/listener/valueidslistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v3.0.  |  
| `hasValue`  | `number`  | The number of [`HasValueListener`](https://tinybase.org/api/store/type-aliases/listener/hasvaluelistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v4.4.  |  
| `value`  | `number`  | The number of [`ValueListener`](https://tinybase.org/api/store/type-aliases/listener/valuelistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v3.0.  |  
| `invalidValue`  | `number`  | The number of [`InvalidValueListener`](https://tinybase.org/api/store/type-aliases/listener/invalidvaluelistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), since v3.0.  |  
| `transaction`  | `number`  | The number of [`TransactionListener`](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/) functions registered with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
The `StoreListenerStats` object contains a breakdown of the different types of listener. Totals include both mutator and non-mutator listeners. A `StoreListenerStats` object is returned from the [`getListenerStats`](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/) method.
