# `Cell`
The `Cell` type is the data structure representing the data in a single cell.

```
string | number | boolean | null | AnyObject[](https://tinybase.org/api/common/type-aliases/general/anyobject/) | AnyArray[](https://tinybase.org/api/common/type-aliases/general/anyarray/)
```

A `Cell` is used when setting a cell with the [`setCell`](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setcell/) method, and when getting it back out again with the [`getCell`](https://tinybase.org/api/the-essentials/getting-data/getcell/) method. A `Cell` is a JavaScript string, number, boolean, or null (since v7.0), or a plain JavaScript object or array (since v8.0).
## Example

```
import type {Cell} from 'tinybase';

export const cell: Cell = 'dog';

```
