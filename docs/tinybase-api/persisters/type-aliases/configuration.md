# Configuration type aliases
## `DatabasePersisterConfig`
The [`DatabasePersisterConfig`](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/) type describes the configuration of a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/), such as those for SQLite and PostgreSQL. [Read more](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/).
## `DpcJson`
The [`DpcJson`](https://tinybase.org/api/persisters/type-aliases/configuration/dpcjson/) type describes the configuration of a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) operating in serialized JSON mode. [Read more](https://tinybase.org/api/persisters/type-aliases/configuration/dpcjson/).
## `DpcTabular`
The [`DpcTabular`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabular/) type describes the configuration of a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) that is operating in tabular mapping mode. [Read more](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabular/).
## `DpcTabularCondition`
The [`DpcTabularCondition`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularcondition/) type describes the SQL WHERE clause that will be used to filter the rows that are loaded and saved to in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). [Read more](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularcondition/).
## `DpcTabularLoad`
The [`DpcTabularLoad`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularload/) type describes the configuration for loading [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) that is operating in tabular mode. [Read more](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularload/).
## `DpcTabularSave`
The [`DpcTabularSave`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularsave/) type describes the configuration for saving [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) that is operating in tabular mode. [Read more](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularsave/).
## `DpcTabularValues`
The [`DpcTabularValues`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularvalues/) type describes the configuration for handling [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) that is operating in tabular mode. [Read more](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularvalues/).
