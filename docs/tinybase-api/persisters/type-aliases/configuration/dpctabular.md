# `DpcTabular`
The `DpcTabular` type describes the configuration of a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) that is operating in tabular mapping mode.

```
{
  mode: "tabular";
  tables?: {
    load?: DpcTabularLoad[](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularload/);
    save?: DpcTabularSave[](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularsave/);
  };
  values?: DpcTabularValues[](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularvalues/);
  autoLoadIntervalSeconds?: number;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `mode`  | `"tabular"`  | The mode to be used for persisting the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to the database, in this case tabular mapping. See the [`DpcJson`](https://tinybase.org/api/persisters/type-aliases/configuration/dpcjson/) type for the alternative JSON serialization mode.  |  
| `tables?`  | `{ load?: DpcTabularLoad[](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularload/); save?: DpcTabularSave[](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularsave/); }`  | The settings for how the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) are mapped to and from the database.  |  
| `values?`  | `DpcTabularValues[](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularvalues/)`  | The settings for how the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) are mapped to and from the database.  |  
| `autoLoadIntervalSeconds?`  | `number`  | How often the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) should poll the database for any changes made to it by other clients, defaulting to 1 second.  |  
This configuration can only be used when the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) is persisting a regular [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). For those database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) types that support [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) data, you will need to use JSON-serialization, es described in the [`DpcJson`](https://tinybase.org/api/persisters/type-aliases/configuration/dpcjson/) section.
It is important to note that both the tabular mapping in ('save') and out ('load') of an underlying database are disabled by default. This is to ensure that if you pass in an existing populated database you don't run the immediate risk of corrupting or losing all your data.
This configuration therefore takes a `tables` property object (with child `load` and `save` property objects) and a `values` property object. These indicate how you want to load and save [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) and [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) respectively. At least one of these two properties are required for the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) to do anything!
Note that if you are planning to both load from and save to a database, it is important to make sure that the load and save table mappings are symmetrical. For example, consider the following.

```
import type {DatabasePersisterConfig} from 'tinybase';

export const databasePersisterConfig: DatabasePersisterConfig = {
  mode: 'tabular',
  tables: {
    load: {petsInDb: 'pets', speciesInDb: 'species'},
    save: {pets: 'petsInDb', species: 'speciesInDb'},
  },
};

```

See the documentation for the [`DpcTabularLoad`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularload/), [`DpcTabularSave`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularsave/), and [`DpcTabularValues`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularvalues/) types for more details on how to configure the tabular mapping mode.
Columns in SQLite database have no type, and so in this mode, the table can contain strings and numbers for Cells and [`Values`](https://tinybase.org/api/store/type-aliases/store/values/), just as TinyBase does. Booleans, unfortunately, are stored as 0 or 1 in SQLite, and cannot be distinguished from numbers.
In PostgreSQL databases, all [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) and [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) columns are expected to be typed as `text`, and the strings, booleans, and numbers are all JSON-encoded by the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/).
The 'Dpc' prefix indicates that this type is used within the [`DatabasePersisterConfig`](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/) type.
## Example
When applied to a database [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/), this [`DatabasePersisterConfig`](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/) will load and save [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) data from and to tables specified in the `load` and `save` mappings, and [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) data from and to a table called `my_tinybase_values`.

```
import type {DatabasePersisterConfig} from 'tinybase';

export const databasePersisterConfig: DatabasePersisterConfig = {
  mode: 'tabular',
  tables: {
    load: {petsInDb: 'pets', speciesInDb: 'species'},
    save: {pets: 'petsInDb', species: 'speciesInDb'},
  },
  values: {
    load: true,
    save: true,
    tableName: 'my_tinybase_values',
  },
};

```
