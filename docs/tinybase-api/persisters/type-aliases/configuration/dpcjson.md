# `DpcJson`
The `DpcJson` type describes the configuration of a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) operating in serialized JSON mode.

```
{
  mode: "json";
  storeTableName?: string;
  storeIdColumnName?: string;
  storeColumnName?: string;
  autoLoadIntervalSeconds?: number;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `mode`  | `"json"`  | The mode to be used for persisting the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to the database, in this case JSON serialization. See the [`DpcTabular`](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabular/) type for the alternative tabular mapping mode.  |  
| `storeTableName?`  | `string`  | An optional string which indicates the name of a table in the database which will be used to serialize the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) content into. It defaults to `tinybase`.  |  
| `storeIdColumnName?`  | `string`  | The optional name of the column in the database table that will be used as the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), defaulting to '_id', since v5.0.  |  
| `storeColumnName?`  | `string`  | The optional name of the column in the database table that will be used for the JSON of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), defaulting to 'store', since v5.0.  |  
| `autoLoadIntervalSeconds?`  | `number`  | How often the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) should poll the database for any changes made to it by other clients, defaulting to 1 second.  |  
One setting is the `storeTableName` property, which indicates the name of a table in the database which will be used to serialize the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) content into. It defaults to `tinybase`.
That table in the database will be given two columns: a primary key column called `_id`, and one called `store`. (These column names can be changed using the `rowIdColumnName` and `storeColumnName` settings). The [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) will place a single row in this table with `_` in the `_id` column, and the JSON serialization in the `store` column, something like the following.

```
> SELECT * FROM tinybase;
+-----+-----------------------------------------------------+
| _id | store                                               |
+-----+-----------------------------------------------------+
| _   | [{"pets":{"fido":{"species":"dog"}}},{"open":true}] |
+-----+-----------------------------------------------------+

```

The 'Dpc' prefix indicates that this type is used within the [`DatabasePersisterConfig`](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/) type.
## Example
When applied to a database [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/), this [`DatabasePersisterConfig`](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/) will load and save a JSON serialization from and to a table called `tinybase_json`.

```
import type {DatabasePersisterConfig} from 'tinybase';

export const databasePersisterConfig: DatabasePersisterConfig = {
  mode: 'json',
  storeTableName: 'tinybase_json',
};

```
