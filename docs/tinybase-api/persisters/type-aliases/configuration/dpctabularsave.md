# `DpcTabularSave`
The `DpcTabularSave` type describes the configuration for saving [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in a database-oriented [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) that is operating in tabular mode.

```
{[tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: {
  tableName: string;
  rowIdColumnName?: string;
  deleteEmptyColumns?: boolean;
  deleteEmptyTable?: boolean;
  condition?: DpcTabularCondition[](https://tinybase.org/api/persisters/type-aliases/configuration/dpctabularcondition/);
} | string}
```

It is an object where each key is an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and the value is a child configuration object for how that [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) should be saved out to the database. The properties of the child configuration object are:  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableName`  | string  | The name of the database table out to which the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) should be saved.  |  
| `rowIdColumnName?`  | string  | The optional name of the column in the database table that will be used to save the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), defaulting to '_id'.  |  
| `deleteEmptyColumns?`  | boolean  | Whether columns in the database table will be removed if they are empty in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), defaulting to false.  |  
| `deleteEmptyTable?`  | boolean  | Whether tables in the database will be removed if the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is empty, defaulting to false.  |  
| `condition?`  | string  | The optional SQL WHERE clause that will be used to scope cleanup operations to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). When set it must include the `$tableName` placeholder for the table name, since v6.1.0. Defaults to `[`DpcTabularLoad`](/api/persisters/type-aliases/configuration/dpctabularload/).condition`.  |  
As a shortcut, if you do not need to specify a custom `rowIdColumnName`, or enable the `deleteEmptyColumns` or `deleteEmptyTable` settings, you can simply provide the name of the database table instead of the whole object.
`deleteEmptyColumns` and `deleteEmptyTable` only have a guaranteed effect when an explicit call is made to the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/)'s [`save`](https://tinybase.org/api/persisters/interfaces/persister/persister/methods/save/save/) method. Columns and tables will not necessarily be removed when the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) is incrementally 'autoSaving', due to performance reasons. If you want to be sure that your database table matches a TinyBase [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) without any extraneous columns, simply call the [`save`](https://tinybase.org/api/persisters/interfaces/persister/persister/methods/save/save/) method at an idle moment.
The 'Dpc' prefix indicates that this type is used within the [`DatabasePersisterConfig`](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/) type.
## Example
When applied to a database [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/), this [`DatabasePersisterConfig`](https://tinybase.org/api/persisters/type-aliases/configuration/databasepersisterconfig/) will save the data of two [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) (called 'pets' and 'species') into two database tables (called 'petsInDb' and 'speciesInDb'). One has a column for the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) called 'id' and will delete columns and the whole table if empty, the other defaults to '_id' and will not delete columns or the whole table if empty.

```
import type {DatabasePersisterConfig} from 'tinybase';

export const databasePersisterConfig: DatabasePersisterConfig = {
  mode: 'tabular',
  tables: {
    save: {
      pets: {
        tableName: 'petsInDb',
        deleteEmptyColumns: true,
        deleteEmptyTable: true,
      },
      species: 'speciesInDb',
    },
  },
};

```

Imagine a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) that look like this:

```
{
  "pets": {
    "fido": {"species": "dog", "color": "brown"},
    "felix": {"species": "cat", "color": "black"},
  },
  "species": {
    "dog": {"price": 5},
    "cat": {"price": 4},
  },
}

```

With the configuration above, this will save out to a database with tables that look like this:

```
> SELECT * FROM petsInDb;
+-------+---------+-------+
| id    | species | color |
+-------+---------+-------+
| fido  | dog     | brown |
| felix | cat     | black |
+-------+---------+-------+

> SELECT * FROM speciesInDb;
+------+-------+
| _id  | price |
+------+-------+
| dog  | 5     |
| cat  | 4     |
+------+-------+

```

The example above represents what happens with a SQLite [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/). In PostgreSQL databases, all [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) and [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) columns are expected to be typed as `text`, and the strings, booleans, and numbers would be JSON-encoded if you queried them.
