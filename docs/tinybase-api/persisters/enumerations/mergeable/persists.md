# `Persists`
The `Persists` enum is used to indicate whether a [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) can support a regular [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/), or both.

```
{
  StoreOnly: 1;
  MergeableStoreOnly: 2;
  StoreOrMergeableStore: 3;
}
```
  
|   | Value  | Description  |  
| --- | --- | --- |  
| `StoreOnly`  | `1`  | Indicates that only a regular [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) can be supported by a [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/).  |  
| `MergeableStoreOnly`  | `2`  | Indicates that only a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) can be supported by a [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/).  |  
| `StoreOrMergeableStore`  | `3`  | Indicates that either a regular [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) or a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) can be supported by a [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/).  |  
The enum is intended to be used by the author of a [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) to indicate which types of store can be persisted. If you discover type errors when trying to instantiate a [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/), it is most likely that you are passing in an unsupported type of store.
See the createCustomPersister method for an example of this enum being used.
