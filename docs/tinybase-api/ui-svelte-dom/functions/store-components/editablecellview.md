# `EditableCellView`

| `props`  | `( CellViewProps[](https://tinybase.org/api/ui-svelte/type-aliases/props/cellviewprops/) & { className?: string; showType?: boolean; } )`  | The props passed to the component.  |  
| returns  | `{ $on?: (type: string, callback: (e: any) => void): () => void; $set?: (props: Partial<( CellViewProps[](https://tinybase.org/api/ui-svelte/type-aliases/props/cellviewprops/) & { className?: string; showType?: boolean; } )>): void; }`  |   |  
See the [<EditableCellView /> (Svelte)](https://tinybase.org/demos/ui-components-svelte/editablecellview-svelte/) demo for this component in action:
![EditableCellView example](https://tinybase.org/shots/editablecellview-svelte-demo.png)
The component's props identify which [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to render based on [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (which is either the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or an explicit reference).
A [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) contains a string, number, boolean, object or array (since v8.0) so the value is rendered in an appropriate <input> tag, possibly as JSON and a button lets the user cycle through the types.
Set the `showType` prop to false to remove the ability for the user to see or change the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) type. They will also not be able to change the type if there is a [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) applied to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).
This component uses the [`useCell`](https://tinybase.org/api/ui-react/functions/store-hooks/usecell/) hook under the covers, which means that any changes to the specified [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) outside of this component will cause a re-render.
You can provide a custom className prop which well be used on the root of the resulting element. If omitted the element's class will be `editableCell`. The debugIds prop has no effect on this component.
## Example
This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `EditableCellView` component within it then renders an editable [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).
App.svelte

```
<script>
  import {Provider} from 'tinybase/ui-svelte';
  import {EditableCellView} from 'tinybase/ui-svelte-dom';

  export let store;
</script>

<Provider {store}>
  <EditableCellView tableId="pets" rowId="fido" cellId="color" />
</Provider>

```

```
import {flushSync, mount} from 'svelte';
import {createStore} from 'tinybase';
import App from './App.svelte';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'brown');
const app = document.body.appendChild(document.createElement('div'));
flushSync(() => mount(App, {target: app, props: {store}}));
console.log(app.innerHTML);
// ->
`
<div class="editableCell">
  <button title="string" class="string">string</button>
  <input value="brown">
</div>
`;

```
