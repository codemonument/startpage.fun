# Store components
[![TableInHtmlTable example](https://tinybase.org/shots/tableinhtmltable-svelte-demo.png)](https://tinybase.org/api/ui-svelte-dom/functions/store-components/tableinhtmltable/)
## `TableInHtmlTable`
The [`TableInHtmlTable`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/tableinhtmltable/) component renders the contents of a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) as an HTML <table> element, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte-dom/functions/store-components/tableinhtmltable/).
[![SortedTableInHtmlTable example](https://tinybase.org/shots/sortedtableinhtmltable-svelte-demo.png)](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtableinhtmltable/)
## `SortedTableInHtmlTable`
The [`SortedTableInHtmlTable`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtableinhtmltable/) component renders the contents of a single sorted [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), as an HTML <table> element, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtableinhtmltable/).
[![SortedTablePaginator example](https://tinybase.org/shots/sortedtablepaginator-svelte-demo.png)](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtablepaginator/)
## `SortedTablePaginator`
The [`SortedTablePaginator`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtablepaginator/) component renders a paginator for a sorted table. [Read more](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtablepaginator/).
[![ValuesInHtmlTable example](https://tinybase.org/shots/valuesinhtmltable-svelte-demo.png)](https://tinybase.org/api/ui-svelte-dom/functions/store-components/valuesinhtmltable/)
## `ValuesInHtmlTable`
The [`ValuesInHtmlTable`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/valuesinhtmltable/) component renders the keyed value contents of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) as an HTML <table> element, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte-dom/functions/store-components/valuesinhtmltable/).
[![EditableCellView example](https://tinybase.org/shots/editablecellview-svelte-demo.png)](https://tinybase.org/api/ui-svelte-dom/functions/store-components/editablecellview/)
## `EditableCellView`
The [`EditableCellView`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/editablecellview/) component renders the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a way that can be edited in a web browser, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte-dom/functions/store-components/editablecellview/).
[![EditableValueView example](https://tinybase.org/shots/editablevalueview-svelte-demo.png)](https://tinybase.org/api/ui-svelte-dom/functions/store-components/editablevalueview/)
## `EditableValueView`
The [`EditableValueView`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/editablevalueview/) component renders the value of a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in a way that can be edited in a web browser, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte-dom/functions/store-components/editablevalueview/).
