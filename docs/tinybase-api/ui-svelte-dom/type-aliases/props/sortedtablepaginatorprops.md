# `SortedTablePaginatorProps`
`SortedTablePaginatorProps` props are used for components that will be used as a table paginator, such as the [`SortedTablePaginator`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtablepaginator/) component.

```
{
  onChange: (offset: number) => void;
  offset?: number;
  limit?: number;
  total: number;
  singular?: string;
  plural?: string;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `onChange`  | `(offset: number) => void`  | An event that will fire when the offset is updated, called with the new offset.  |  
| `offset?`  | `number`  | The number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to skip for pagination.  |  
| `limit?`  | `number`  | The maximum number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) being returned.  |  
| `total`  | `number`  | The total number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the paginated table.  |  
| `singular?`  | `string`  | A noun to use in the pagination label for a single row, defaulting to 'row'.  |  
| `plural?`  | `string`  | A noun to use in the pagination label for multiple rows, defaulting to the value of the singular noun suffixed with the letter 's'.  |
