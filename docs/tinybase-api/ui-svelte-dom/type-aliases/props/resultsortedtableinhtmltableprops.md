# `ResultSortedTableInHtmlTableProps`
`ResultSortedTableInHtmlTableProps` props are used for components that will render a sorted [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in an HTML table, such as the [`SortedTableInHtmlTable`](https://tinybase.org/api/ui-svelte-dom/functions/store-components/sortedtableinhtmltable/) component.

```
{
  queryId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  cellId?: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  descending?: boolean;
  offset?: number;
  limit?: number;
  queries?: QueriesOrQueriesId[](https://tinybase.org/api/ui-react/type-aliases/identity/queriesorqueriesid/);
  customCells?: Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/) | {[cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: string | CustomResultCell[](https://tinybase.org/api/ui-svelte-dom/type-aliases/configuration/customresultcell/)};
  extraCellsBefore?: ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[];
  extraCellsAfter?: ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[];
  sortOnClick?: boolean;
  paginator?: boolean | Component<SortedTablePaginatorProps[](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sortedtablepaginatorprops/)>;
  onChange?: (sortAndOffset: [cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/) | undefined, descending: boolean, offset: number]) => void;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query in the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object for which the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) will be rendered.  |  
| `cellId?`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) whose values are used for the sorting. If omitted, the view will sort the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) itself.  |  
| `descending?`  | `boolean`  | Whether the sorting should be in descending order.  |  
| `offset?`  | `number`  | The number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to skip for pagination purposes.  |  
| `limit?`  | `number`  | The maximum number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to return.  |  
| `queries?`  | `QueriesOrQueriesId[](https://tinybase.org/api/ui-react/type-aliases/identity/queriesorqueriesid/)`  | The [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object to be accessed: omit for the default context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, or provide an explicit reference.  |  
| `customCells?`  | `Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/) | {[cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: string | CustomResultCell[](https://tinybase.org/api/ui-svelte-dom/type-aliases/configuration/customresultcell/)}`  | An optional list of [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to use for rendering a prescribed set of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/)'s Cells in a given order. This can also be an object with the desired [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) as keys, and with a value that can either be a string label to show in the column header, or a ResultCustomCell object to further configure the column.  |  
| `extraCellsBefore?`  | `ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[]`  | An optional list of extra Cells to render before the main table Cells.  |  
| `extraCellsAfter?`  | `ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[]`  | An optional list of extra Cells to render after the main table Cells.  |  
| `sortOnClick?`  | `boolean`  | Whether the table should be interactive such that clicking a header changes the sorting and/or direction.  |  
| `paginator?`  | `boolean | Component<SortedTablePaginatorProps[](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sortedtablepaginatorprops/)>`  | Either `true` to show the default SortedTablePaginator for the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), or provide your own paginator component that takes [`SortedTablePaginatorProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sortedtablepaginatorprops/).  |  
| `onChange?`  | `(sortAndOffset: [cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/) | undefined, descending: boolean, offset: number]) => void`  | A function that is called whenever the sorting or pagination of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) is changed by the user, invoked with the sorted [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), whether descending or not, and the offset of the pagination.  |
