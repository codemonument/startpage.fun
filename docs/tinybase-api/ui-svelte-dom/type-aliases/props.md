# Props type aliases
## `TableInHtmlTableProps`
[`TableInHtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/tableinhtmltableprops/) props are used for components that will render a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in an HTML table, such as the [`TableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/tableinhtmltable/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/tableinhtmltableprops/).
## `HtmlTableProps`
[`HtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/htmltableprops/) props are used for components that will render in an HTML table, such as the [`TableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/tableinhtmltable/) component or [`SortedTableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/sortedtableinhtmltable/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/htmltableprops/).
## `RelationshipInHtmlTableProps`
[`RelationshipInHtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/relationshipinhtmltableprops/) props are used for components that will render the contents of the two [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) linked by a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) as an HTML table, such as the [`RelationshipInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/other-components/relationshipinhtmltable/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/relationshipinhtmltableprops/).
## `ResultSortedTableInHtmlTableProps`
[`ResultSortedTableInHtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/resultsortedtableinhtmltableprops/) props are used for components that will render a sorted [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in an HTML table, such as the [`SortedTableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/sortedtableinhtmltable/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/resultsortedtableinhtmltableprops/).
## `ResultTableInHtmlTableProps`
[`ResultTableInHtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/resulttableinhtmltableprops/) props are used for components that will render a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) in an HTML table, such as the [`ResultTableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/queries-components/resulttableinhtmltable/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/resulttableinhtmltableprops/).
## `SliceInHtmlTableProps`
[`SliceInHtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sliceinhtmltableprops/) props are used for components that will render an [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in an HTML table, such as the [`SliceInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/other-components/sliceinhtmltable/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sliceinhtmltableprops/).
## `SortedTableInHtmlTableProps`
[`SortedTableInHtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sortedtableinhtmltableprops/) props are used for components that will render a sorted [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in an HTML table, such as the [`SortedTableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/sortedtableinhtmltable/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sortedtableinhtmltableprops/).
## `SortedTablePaginatorProps`
[`SortedTablePaginatorProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sortedtablepaginatorprops/) props are used for components that will be used as a table paginator, such as the [`SortedTablePaginator`](https://tinybase.org/api/ui-react-dom/functions/store-components/sortedtablepaginator/) component. [Read more](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/sortedtablepaginatorprops/).

[`ValuesInHtmlTableProps`](https://tinybase.org/api/ui-svelte-dom/type-aliases/props/valuesinhtmltableprops/) props are used for components that will render [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in an HTML table, such as the [`ValuesInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/valuesinhtmltable/) component.
