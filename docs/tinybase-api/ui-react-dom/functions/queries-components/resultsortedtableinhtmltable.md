# `ResultSortedTableInHtmlTable`
The [`SortedTableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/sortedtableinhtmltable/) component renders the contents of a single query's sorted [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) in a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object as an HTML <table> element, and registers a listener so that any changes to that result will cause a re-render.

```
ResultSortedTableInHtmlTable[](https://tinybase.org/api/ui-react-dom/functions/queries-components/resultsortedtableinhtmltable/)(props: (
  ResultSortedTableInHtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/resultsortedtableinhtmltableprops/) &
  HtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/htmltableprops/)
)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `( ResultSortedTableInHtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/resultsortedtableinhtmltableprops/) & HtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/htmltableprops/) )`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) in a <table> element.  |  
See the [<ResultSortedTableInHtmlTable /> (React)](https://tinybase.org/demos/ui-components-react/resultsortedtableinhtmltable-react/) demo for this component in action:
![ResultSortedTableInHtmlTable example](https://tinybase.org/shots/resultsortedtableinhtmltable-react-demo.png)
The component's props identify which [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) to render based on query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object (which is either the default context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, a named context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, or by explicit reference). It also takes a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to sort by and a boolean to indicate that the sorting should be in descending order. The `offset` and `limit` props are used to paginate results, but default to `0` and `undefined` to return all available [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) if not specified.
This component renders a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) by iterating over its [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects, in the order dictated by the sort parameters. By default the Cells are in turn rendered with the [`CellView`](https://tinybase.org/api/ui-react/functions/store-components/cellview/) component, but you can override this behavior by providing a `component` for each [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the `customCells` prop. You can pass additional props to that custom component with the `getComponentProps` callback. See the ResultCustomCell type for more details.
This component uses the [`useSortedRowIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usesortedrowids/) hook under the covers, which means that any changes to the structure or sorting of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) will cause a re-render.
You can use the `headerRow` and `idColumn` props to control whether the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) appear in a <th> element at the top of the table, and the start of each row.
The `sortOnClick` prop makes the table's sorting interactive such that the user can click on a column heading to sort by that column. The style classes `sorted` and `ascending` (or `descending`) are added so that you can provide hints to the user how the sorting is being applied.
Provide a paginator component for the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) with the `paginator` prop. Set to `true` to use the default SortedTablePaginator, or provide your own component that accepts [`SortedTablePaginatorProps`](https://tinybase.org/api/ui-react-dom/type-aliases/props/sortedtablepaginatorprops/).
Finally, the `onChange` prop lets you listen to a user's changes to the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/)'s sorting or pagination.
## Examples
This example creates a Provider context into which a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided. The `ResultSortedTableInHtmlTable` component within it then renders the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) in a <table> element with a CSS class.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {Provider} from 'tinybase/ui-react';
import {ResultSortedTableInHtmlTable} from 'tinybase/ui-react-dom';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queries={queries}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <ResultSortedTableInHtmlTable[](https://tinybase.org/api/ui-react-dom/functions/queries-components/resultsortedtableinhtmltable/)
    queryId="petColors"
    cellId="color"
    className="table"
  />
);

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
  }),
).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('petColors', 'pets', ({select}) => select('color'));
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// ->
`
<table class="table">
  <thead>
    <tr>
      <th>Id</th>
      <th class="sorted ascending">↑ color</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th title="felix">felix</th>
      <td>black</td>
    </tr>
    <tr>
      <th title="fido">fido</th>
      <td>brown</td>
    </tr>
  </tbody>
</table>
`;

```

This example creates a Provider context into which a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided. The `ResultSortedTableInHtmlTable` component within it then renders the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) with a custom component and a custom props callback for the `color` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/). The header row at the top of the table and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) column at the start of each row is removed.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {Provider, ResultCellView} from 'tinybase/ui-react';
import {ResultSortedTableInHtmlTable} from 'tinybase/ui-react-dom';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queries={queries}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);

const Pane = () => (
  <ResultSortedTableInHtmlTable[](https://tinybase.org/api/ui-react-dom/functions/queries-components/resultsortedtableinhtmltable/)
    queryId="petColors"
    cellId="color"
    customCells={customCells}
    headerRow={false}
    idColumn={false}
  />
);

const FormattedResultCellView = ({queryId, rowId, cellId, bold}) => (
  <>
    {bold ? <b>{rowId}</b> : rowId}:
    <ResultCellView[](https://tinybase.org/api/ui-react/functions/queries-components/resultcellview/) queryId={queryId} rowId={rowId} cellId={cellId} />
  </>
);
const customCells = {
  color: {
    component: FormattedResultCellView,
    getComponentProps: (rowId) => ({bold: rowId == 'fido'}),
  },
};

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
  }),
).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('petColors', 'pets', ({select}) => select('color'));
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// ->
`
<table>
  <tbody>
    <tr>
      <td>felix:black</td>
    </tr>
    <tr>
      <td><b>fido</b>:brown</td>
    </tr>
  </tbody>
</table>
`;

```
