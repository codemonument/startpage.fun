# `EditableValueView`
The `EditableValueView` component renders the value of a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in a way that can be edited in a web browser, and registers a listener so that any changes to that result will cause a re-render.

```
EditableValueView[](https://tinybase.org/api/ui-react-dom/functions/store-components/editablevalueview/)(props: (
  ValueProps[](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/) &
  {
    className?: string;
    showType?: boolean;
  }
)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `( ValueProps[](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/) & { className?: string; showType?: boolean; } )`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | An editable rendering of the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/).  |  
See the [<EditableValueView /> (React)](https://tinybase.org/demos/ui-components-react/editablevalueview-react/) demo for this component in action:
![EditableValueView example](https://tinybase.org/shots/editablevalueview-react-demo.png)
The component's props identify which [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) to render based on [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (which is either the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or an explicit reference).
A [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) contains a string, number, boolean, object or array (since v8.0) so the value is rendered in an appropriate <input> tag, possibly as JSON and a button lets the user cycle through the types.
Set the `showType` prop to false to remove the ability for the user to see or change the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) type. They will also not be able to change the type if there is a [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) applied to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).
This component uses the [`useValue`](https://tinybase.org/api/ui-react/functions/store-hooks/usevalue/) hook under the covers, which means that any changes to the specified [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) outside of this component will cause a re-render.
You can provide a custom className prop which well be used on the root of the resulting element. If omitted the element's class will be `editableValue`. The debugIds prop has no effect on this component.
## Example
This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `EditableValueView` component within it then renders an editable [`Value`](https://tinybase.org/api/store/type-aliases/store/value/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider} from 'tinybase/ui-react';
import {EditableValueView} from 'tinybase/ui-react-dom';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => <EditableValueView[](https://tinybase.org/api/ui-react-dom/functions/store-components/editablevalueview/) valueId="employees" />;

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('employees', 3);
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// ->
`
<div class="editableValue">
  <button title="number" class="number">number</button>
  <input type="number" value="3">
</div>
`;

```
