# `ValuesInHtmlTable`
The `ValuesInHtmlTable` component renders the keyed value contents of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) as an HTML <table> element, and registers a listener so that any changes to that result will cause a re-render.

```
ValuesInHtmlTable[](https://tinybase.org/api/ui-react-dom/functions/store-components/valuesinhtmltable/)(props: (
  ValuesInHtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/valuesinhtmltableprops/) &
  HtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/htmltableprops/)
)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `( ValuesInHtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/valuesinhtmltableprops/) & HtmlTableProps[](https://tinybase.org/api/ui-react-dom/type-aliases/props/htmltableprops/) )`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in a <table> element.  |  
See the [<ValuesInHtmlTable /> (React)](https://tinybase.org/demos/ui-components-react/valuesinhtmltable-react/) demo for this component in action:
![ValuesInHtmlTable example](https://tinybase.org/shots/valuesinhtmltable-react-demo.png)
The component's props identify which [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to render based on [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (which is either the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or an explicit reference).
This component renders a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) by iterating over its [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) objects. By default the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) are in turn rendered with the [`ValueView`](https://tinybase.org/api/ui-react/functions/store-components/valueview/) component, but you can override this behavior by providing a `valueComponent` prop, a custom component of your own that will render a [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) based on [`ValueProps`](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/). You can also pass additional props to your custom component with the `getValueComponentProps` callback prop.
This component uses the [`useValueIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usevalueids/) hook under the covers, which means that any changes to the structure of the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) will cause a re-render.
You can use the `headerRow` and `idColumn` props to control whether labels and [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) appear in a <th> element at the top of the table, and the start of each row.
## Examples
This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `ValuesInHtmlTable` component within it then renders the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in a <table> element with a CSS class.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider} from 'tinybase/ui-react';
import {ValuesInHtmlTable} from 'tinybase/ui-react-dom';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => <ValuesInHtmlTable[](https://tinybase.org/api/ui-react-dom/functions/store-components/valuesinhtmltable/) className="values" />;

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({open: true, employees: 3});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// ->
`
<table class="values">
  <thead>
    <tr>
      <th>Id</th>
      <th>Value</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th title="open">open</th>
      <td>true</td>
    </tr>
    <tr>
      <th title="employees">employees</th>
      <td>3</td>
    </tr>
  </tbody>
</table>
`;

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `ValuesInHtmlTable` component within it then renders the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) with a custom [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) component and a custom props callback. The header row at the top of the table and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) column at the start of each row is removed.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, ValueView} from 'tinybase/ui-react';
import {ValuesInHtmlTable} from 'tinybase/ui-react-dom';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const getBoldProp = (valueId) => ({bold: valueId == 'open'});
const Pane = () => (
  <ValuesInHtmlTable[](https://tinybase.org/api/ui-react-dom/functions/store-components/valuesinhtmltable/)
    valueComponent={FormattedValueView}
    getValueComponentProps={getBoldProp}
    headerRow={false}
    idColumn={false}
  />
);
const FormattedValueView = ({valueId, bold}) => (
  <>
    {bold ? <b>{valueId}</b> : valueId}
    {': '}
    <ValueView[](https://tinybase.org/api/ui-react/functions/store-components/valueview/) valueId={valueId} />
  </>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({open: true, employees: 3});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// ->
`
<table>
  <tbody>
    <tr><td><b>open</b>: true</td></tr>
    <tr><td>employees: 3</td></tr>
  </tbody>
</table>
`;

```
