# `ValuesInHtmlTableProps`
`ValuesInHtmlTableProps` props are used for components that will render [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in an HTML table, such as the [`ValuesInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/valuesinhtmltable/) component.

```
{
  store?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/);
  editable?: boolean;
  valueComponent?: ComponentType<ValueProps[](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/)>;
  getValueComponentProps?: (valueId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)) => ExtraProps[](https://tinybase.org/api/ui-react/type-aliases/props/extraprops/);
  extraCellsBefore?: ExtraValueCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extravaluecell/)[];
  extraCellsAfter?: ExtraValueCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extravaluecell/)[];
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `store?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be accessed: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| `editable?`  | `boolean`  | Whether the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) should be editable. This affects the default [`ValueView`](https://tinybase.org/api/ui-react/functions/store-components/valueview/) component (to use the [`EditableValueView`](https://tinybase.org/api/ui-react-dom/functions/store-components/editablevalueview/) component instead) but of course will not affect a custom valueComponent if you have set one.  |  
| `valueComponent?`  | `ComponentType<ValueProps[](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/)>`  | A custom component for rendering each [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (to override the default [`ValueView`](https://tinybase.org/api/ui-react/functions/store-components/valueview/) component).  |  
| `getValueComponentProps?`  | `(valueId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)) => ExtraProps[](https://tinybase.org/api/ui-react/type-aliases/props/extraprops/)`  | A function for generating extra props for each custom [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) component based on its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
| `extraCellsBefore?`  | `ExtraValueCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extravaluecell/)[]`  | An optional list of extra Cells to render before the main table Cells.  |  
| `extraCellsAfter?`  | `ExtraValueCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extravaluecell/)[]`  | An optional list of extra Cells to render after the main table Cells.  |
