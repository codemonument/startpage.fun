# `TableInHtmlTableProps`
`TableInHtmlTableProps` props are used for components that will render a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in an HTML table, such as the [`TableInHtmlTable`](https://tinybase.org/api/ui-react-dom/functions/store-components/tableinhtmltable/) component.

```
{
  tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  store?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/);
  editable?: boolean;
  customCells?: Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/) | {[cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: string | CustomCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/customcell/)};
  extraCellsBefore?: ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[];
  extraCellsAfter?: ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[];
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be rendered.  |  
| `store?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be accessed: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| `editable?`  | `boolean`  | Whether the Cells should be editable. This affects the default [`CellView`](https://tinybase.org/api/ui-react/functions/store-components/cellview/) component (to use the [`EditableCellView`](https://tinybase.org/api/ui-react-dom/functions/store-components/editablecellview/) component instead) but of course will not affect custom [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) components if you have set them.  |  
| `customCells?`  | `Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/) | {[cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: string | CustomCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/customcell/)}`  | An optional list of [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to use for rendering a prescribed set of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s Cells in a given order. This can also be an object with the desired [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) as keys, and with a value that can either be a string label to show in the column header, or a [`CustomCell`](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/customcell/) object to further configure the column.  |  
| `extraCellsBefore?`  | `ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[]`  | An optional list of extra Cells to render before the main table Cells.  |  
| `extraCellsAfter?`  | `ExtraRowCell[](https://tinybase.org/api/ui-react-dom/type-aliases/configuration/extrarowcell/)[]`  | An optional list of extra Cells to render after the main table Cells.  |
