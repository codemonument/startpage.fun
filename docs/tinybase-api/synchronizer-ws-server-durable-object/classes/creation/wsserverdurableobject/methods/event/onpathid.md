# `onPathId`
The `onPathId` method is called when the first client connects to, or the last client disconnects from, the server with a given path [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).

```
onPathId[](https://tinybase.org/api/synchronizer-ws-server-durable-object/classes/creation/wsserverdurableobject/methods/event/onpathid/)(
  pathId: string,
  addedOrRemoved: IdAddedOrRemoved[](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `pathId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the path being served by the Durable Object.  |  
| `addedOrRemoved`  | `IdAddedOrRemoved[](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/)`  | Whether the path had the first joiner, or the last leaver.  |  
| returns  | `void`  | This has no return value.  |  
This method is called with the path [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and an [`IdAddedOrRemoved`](https://tinybase.org/api/store/type-aliases/transaction/idaddedorremoved/) flag indicating whether it this is being triggered by the first client joining (`1`) or the last client leaving (`-1`).
## Example
This example logs the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the path being served by the Durable Object when the first client joins (the path [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) is 'added'), and when the last client leaves (the path [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) is 'removed').

```
import {WsServerDurableObject} from 'tinybase/synchronizers/synchronizer-ws-server-durable-object';

export class MyDurableObject extends WsServerDurableObject[](https://tinybase.org/api/synchronizer-ws-server-durable-object/classes/creation/wsserverdurableobject/) {
  onPathId[](https://tinybase.org/api/synchronizer-ws-server-durable-object/classes/creation/wsserverdurableobject/methods/event/onpathid/)(pathId, addedOrRemoved) {
    console.info(
      (addedOrRemoved == 1 ? 'Added' : 'Removed') + ` path ${pathId}`,
    );
  }
}

```
