# `Indexes`
An `Indexes` object lets you look up all the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that have a certain [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value.
This is useful for creating filtered views of a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), or simple search functionality.
Create an `Indexes` object easily with the [`createIndexes`](https://tinybase.org/api/indexes/functions/creation/createindexes/) function. From there, you can add new [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) definitions (with the [`setIndexDefinition`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/) method), query their contents (with the [`getSliceIds`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getsliceids/) method and [`getSliceRowIds`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/) method), and add listeners for when they change (with the [`addSliceIdsListener`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addsliceidslistener/) method and [`addSliceRowIdsListener`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addslicerowidslistener/) method).
This module defaults to indexing [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects by one of their [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values. However, far more complex indexes can be configured with a custom function.
## Example
This example shows a very simple lifecycle of an `Indexes` object: from creation, to adding a definition, getting its contents, and then registering and removing a listener for it.

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  cujo: {species: 'dog'},
});

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)(
  'bySpecies', // indexId
  'pets', //      tableId to index
  'species', //   cellId to index
);

console.log(indexes.getSliceIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getsliceids/)('bySpecies'));
// -> ['dog', 'cat']
console.log(indexes.getSliceRowIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/)('bySpecies', 'dog'));
// -> ['fido', 'cujo']

const listenerId = indexes.addSliceIdsListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addsliceidslistener/)('bySpecies', () => {
  console.log(indexes.getSliceIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getsliceids/)('bySpecies'));
});
store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'lowly', {species: 'worm'});
// -> ['dog', 'cat', 'worm']

indexes.delListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/dellistener/)(listenerId);
indexes.destroy[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/lifecycle/destroy/)();

```
