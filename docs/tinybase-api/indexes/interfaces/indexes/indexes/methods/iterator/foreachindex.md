# `forEachIndex`
The `forEachIndex` method takes a function that it will then call for each [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) in a specified [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object.

```
forEachIndex[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/iterator/foreachindex/)(indexCallback: IndexCallback[](https://tinybase.org/api/indexes/type-aliases/callback/indexcallback/)): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `indexCallback`  | `IndexCallback[](https://tinybase.org/api/indexes/type-aliases/callback/indexcallback/)`  | The function that should be called for every [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).  |  
| returns  | `void`  | This has no return value.  |  
This method is useful for iterating over the structure of the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object in a functional style. The `indexCallback` parameter is a [`IndexCallback`](https://tinybase.org/api/indexes/type-aliases/callback/indexcallback/) function that will be called with the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of each [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), and with a function that can then be used to iterate over each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) of the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), should you wish.
## Example
This example iterates over each [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) in an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, and lists each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) within them.

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
  cujo: {species: 'dog', color: 'black'},
});
const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store)
  .setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species')
  .setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('byColor', 'pets', 'color');

indexes.forEachIndex[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/iterator/foreachindex/)((indexId, forEachSlice) => {
  console.log(indexId);
  forEachSlice[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/iterator/foreachslice/)((sliceId) => console.log(`- ${sliceId}`));
});
// -> 'bySpecies'
// -> '- dog'
// -> '- cat'
// -> 'byColor'
// -> '- brown'
// -> '- black'

```
