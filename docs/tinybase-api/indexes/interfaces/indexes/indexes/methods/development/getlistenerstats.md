# `getListenerStats`
The `getListenerStats` method provides a set of statistics about the listeners registered with the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, and is used for debugging purposes.

```
getListenerStats[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/development/getlistenerstats/)(): IndexesListenerStats[](https://tinybase.org/api/indexes/type-aliases/development/indexeslistenerstats/)
```
  
| returns  | `IndexesListenerStats[](https://tinybase.org/api/indexes/type-aliases/development/indexeslistenerstats/)`  | A [`IndexesListenerStats`](https://tinybase.org/api/indexes/type-aliases/development/indexeslistenerstats/) object containing [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) listener statistics.  |  
| --- | --- | --- |  
The [`IndexesListenerStats`](https://tinybase.org/api/indexes/type-aliases/development/indexeslistenerstats/) object contains a breakdown of the different types of listener.
The method is intended to be used during development to ensure your application is not leaking listener registrations, for example.
## Example
This example gets the listener statistics of an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object.

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.addSliceIdsListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addsliceidslistener/)(null, () => {
  console.log('Slice Ids changed');
});
indexes.addSliceRowIdsListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addslicerowidslistener/)(null, null, () => {
  console.log('Slice Row Ids changed');
});

console.log(indexes.getListenerStats[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/development/getlistenerstats/)());
// -> {sliceIds: 1, sliceRowIds: 1}

```
