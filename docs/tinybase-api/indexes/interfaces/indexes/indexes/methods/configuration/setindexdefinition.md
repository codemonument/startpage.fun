# `setIndexDefinition`
The `setIndexDefinition` method lets you set the definition of an [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).

```
setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)(
  indexId: string,
  tableId: string,
  getSliceIdOrIds?: string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => string | Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/),
  getSortKey?: string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => SortKey[](https://tinybase.org/api/common/type-aliases/parameter/sortkey/),
  sliceIdSorter?: (sliceId1: string, sliceId2: string) => number,
  rowIdSorter?: (sortKey1: SortKey[](https://tinybase.org/api/common/type-aliases/parameter/sortkey/), sortKey2: SortKey[](https://tinybase.org/api/common/type-aliases/parameter/sortkey/), sliceId: string) => number,
): Indexes[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `indexId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) to define.  |  
| `tableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) will be generated from.  |  
| `getSliceIdOrIds?`  | `string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => string | Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)`  | Either the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) containing, or a function that produces, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) that is used to indicate which [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) should be in. Defaults to a function that returns `''` (meaning that if this `getSliceIdOrIds` parameter is omitted, the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) will simply contain a single [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) containing all the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)). Since v2.1, this can return an array of [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/), each of which the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) will then belong to.  |  
| `getSortKey?`  | `string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => SortKey[](https://tinybase.org/api/common/type-aliases/parameter/sortkey/)`  | Either the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) containing, or a function that produces, the value that is used to sort the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/).  |  
| `sliceIdSorter?`  | `(sliceId1: string, sliceId2: string) => number`  | A function that takes two [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) values and returns a positive or negative number to indicate how they should be sorted.  |  
| `rowIdSorter?`  | `(sortKey1: SortKey[](https://tinybase.org/api/common/type-aliases/parameter/sortkey/), sortKey2: SortKey[](https://tinybase.org/api/common/type-aliases/parameter/sortkey/), sliceId: string) => number`  | A function that takes two [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) values (and a slice [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) and returns a positive or negative number to indicate how they should be sorted.  |  
| returns  | `Indexes[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/)`  | A reference to the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object.  |  
Every [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) definition is identified by a unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and if you re-use an existing [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) with this method, the previous definition is overwritten.
An [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) is a keyed map of [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) objects, each of which is a list of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) from a given [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). Therefore the definition must specify the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (by its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) to be indexed.
The [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) represent [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects from a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that all have a derived string value in common, as described by this method. Those values are used as the key for each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in the overall [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) object.
Without the third `getSliceIdOrIds` parameter, the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) will simply have a single [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/), keyed by an empty string. But more often you will specify a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value containing the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) that the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) should belong to. Alternatively, a custom function can be provided that produces your own [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) from the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) as a whole. Since v2.1, the custom function can return an array of [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/), each of which the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) will then belong to.
The fourth `getSortKey` parameter specifies a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to get a value (or a function that processes a whole [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to get a value) that is used to sort the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) within each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).
The fifth parameter, `sliceIdSorter`, lets you specify a way to sort the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) when you access the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), which may be useful if you are trying to create an alphabetic [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) entries. If not specified, the order of the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will match the order of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) insertion.
The final parameter, `rowIdSorter`, lets you specify a way to sort the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) within each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/), based on the `getSortKey` parameter. This may be useful if you are trying to keep Rows in a determined order relative to each other in the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/). If omitted, the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) are sorted alphabetically, based on the `getSortKey` parameter.
The two 'sorter' parameters, `sliceIdSorter` and `rowIdSorter`, are functions that take two values and return a positive or negative number for when they are in the wrong or right order, respectively. This is exactly the same as the 'compareFunction' that is used in the standard JavaScript array `sort` method, with the addition that `rowIdSorter` also takes the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) parameter, in case you want to sort [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) differently in each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/). You can use the convenient [`defaultSorter`](https://tinybase.org/api/common/functions/convenience/defaultsorter/) function to default this to be alphanumeric.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, and defines a simple [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) based on the values in the `species` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  cujo: {species: 'dog'},
});

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species');

console.log(indexes.getSliceIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getsliceids/)('bySpecies'));
// -> ['dog', 'cat']
console.log(indexes.getSliceRowIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/)('bySpecies', 'dog'));
// -> ['fido', 'cujo']

```

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, and defines an [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) based on each of the letters present in the pets' names.

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  rex: {species: 'dog'},
});

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('containsLetter', 'pets', (_, rowId) =>
  rowId.split(''),
);

console.log(indexes.getSliceIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getsliceids/)('containsLetter'));
// -> ['f', 'i', 'd', 'o', 'e', 'l', 'x', 'r']
console.log(indexes.getSliceRowIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/)('containsLetter', 'i'));
// -> ['fido', 'felix']
console.log(indexes.getSliceRowIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/)('containsLetter', 'x'));
// -> ['felix', 'rex']

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, and defines an [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) based on the first letter of the pets' names. The [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) (and [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) within them) are alphabetically sorted.

```
import {createIndexes, createStore, defaultSorter} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  cujo: {species: 'dog'},
});

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)(
  'byFirst', //              indexId
  'pets', //                 tableId
  (_, rowId) => rowId[0], // each Row's sliceId
  (_, rowId) => rowId, //    each Row's sort key
  defaultSorter, //          sort Slice Ids
  defaultSorter, //          sort Row Ids
);

console.log(indexes.getSliceIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getsliceids/)('byFirst'));
// -> ['c', 'f']
console.log(indexes.getSliceRowIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/)('byFirst', 'f'));
// -> ['felix', 'fido']

```
