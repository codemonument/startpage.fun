# `addSliceRowIdsListener`
The `addSliceRowIdsListener` method registers a listener function with the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object that will be called whenever the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) change.

```
addSliceRowIdsListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addslicerowidslistener/)(
  indexId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  sliceId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: SliceRowIdsListener[](https://tinybase.org/api/indexes/type-aliases/listener/slicerowidslistener/),
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `indexId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) to listen to, or `null` as a wildcard.  |  
| `sliceId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `SliceRowIdsListener[](https://tinybase.org/api/indexes/type-aliases/listener/slicerowidslistener/)`  | The function that will be called whenever the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) change.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
You can either listen to a single [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) (by specifying the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first two parameters), or changes to any [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) (by providing `null` wildcards).
Both, either, or neither of the `indexId` and `sliceId` parameters can be wildcarded with `null`. You can listen to a specific [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in a specific [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), any [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in a specific [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), a specific [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in any [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), or any [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in any [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).
The provided listener is a [`SliceRowIdsListener`](https://tinybase.org/api/indexes/type-aliases/listener/slicerowidslistener/) function, and will be called with a reference to the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), and the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) that changed.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, and then registers a listener that responds to any changes to a specific [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/).

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  cujo: {species: 'dog'},
});

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species');

const listenerId = indexes.addSliceRowIdsListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addslicerowidslistener/)(
  'bySpecies',
  'dog',
  (indexes) => {
    console.log('Row Ids for dog slice in bySpecies index changed');
    console.log(indexes.getSliceRowIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/)('bySpecies', 'dog'));
  },
);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'toto', {species: 'dog'});
// -> 'Row Ids for dog slice in bySpecies index changed'
// -> ['fido', 'cujo', 'toto']

indexes.delListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/dellistener/)(listenerId);

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, and then registers a listener that responds to any changes to any [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/).

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
  cujo: {species: 'dog', color: 'black'},
});

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store)
  .setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species')
  .setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('byColor', 'pets', 'color');

const listenerId = indexes.addSliceRowIdsListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addslicerowidslistener/)(
  null,
  null,
  (indexes, indexId, sliceId) => {
    console.log(
      `Row Ids for ${sliceId} slice in ${indexId} index changed`,
    );
    console.log(indexes.getSliceRowIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/)(indexId, sliceId));
  },
);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'toto', {species: 'dog', color: 'brown'});
// -> 'Row Ids for dog slice in bySpecies index changed'
// -> ['fido', 'cujo', 'toto']
// -> 'Row Ids for brown slice in byColor index changed'
// -> ['fido', 'toto']

indexes.delListener[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/dellistener/)(listenerId);

```
