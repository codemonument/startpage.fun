# `hasSlice`
The `hasSlice` method returns a boolean indicating whether a given [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) exists in the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object.

```
hasSlice[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/hasslice/)(
  indexId: string,
  sliceId: string,
): boolean
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `indexId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a possible [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) in the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object.  |  
| `sliceId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a possible [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).  |  
| returns  | `boolean`  | Whether a [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) with that [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) exists.  |  
## Example
This example shows two simple [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) existence checks.

```
import {createIndexes, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  cujo: {species: 'dog'},
});
const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species');
console.log(indexes.hasSlice[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/hasslice/)('bySpecies', 'dog'));
// -> true
console.log(indexes.hasSlice[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/hasslice/)('bySpecies', 'worm'));
// -> false

```
