# `Index`
The `Index` type represents the concept of a map of [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) objects, keyed by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).

```
{[sliceId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Slice[](https://tinybase.org/api/indexes/type-aliases/concept/slice/)}
```

The [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) represent [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects from a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that all have a derived string value in common, as described by the [`setIndexDefinition`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/) method. Those values are used as the key for each [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in the overall `Index` object.
Note that the `Index` type is not actually used in the [API](https://tinybase.org/api/), and you instead enumerate and access its structure with the [`getSliceIds`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getsliceids/) method and [`getSliceRowIds`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getslicerowids/) method.
