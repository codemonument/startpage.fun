# Storage functions
## `hasStoreInStorage`
The [`hasStoreInStorage`](https://tinybase.org/api/persister-partykit-server/functions/storage/hasstoreinstorage/) function returns a boolean indicating whether durable PartyKit storage contains a serialized [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/persister-partykit-server/functions/storage/hasstoreinstorage/).
## `loadStoreFromStorage`
The [`loadStoreFromStorage`](https://tinybase.org/api/persister-partykit-server/functions/storage/loadstorefromstorage/) function returns the content of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) from durable PartyKit storage. [Read more](https://tinybase.org/api/persister-partykit-server/functions/storage/loadstorefromstorage/).
