# `Inspector`
Essential

```
Inspector[](https://tinybase.org/api/ui-svelte-inspector/functions/development-components/inspector/)(
  this: void,
  props: InspectorProps[](https://tinybase.org/api/ui-svelte-inspector/type-aliases/props/inspectorprops/),
): {
  $on?: (type: string, callback: (e: any) => void): () => void;
  $set?: (props: Partial<InspectorProps[](https://tinybase.org/api/ui-svelte-inspector/type-aliases/props/inspectorprops/)>): void;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `this`  | `void`  |   |  
| `props`  | `InspectorProps[](https://tinybase.org/api/ui-svelte-inspector/type-aliases/props/inspectorprops/)`  | The props passed to the component.  |  
| returns  | `{ $on?: (type: string, callback: (e: any) => void): () => void; $set?: (props: Partial<InspectorProps[](https://tinybase.org/api/ui-svelte-inspector/type-aliases/props/inspectorprops/)>): void; }`  |   |  
See the [<Inspector /> (Svelte)](https://tinybase.org/demos/ui-components-svelte/inspector-svelte/) demo for this component in action:
![Inspector example](https://tinybase.org/shots/inspector-svelte-demo.png)
The component displays a nub in the corner of the screen which you may then click to interact with all the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects in the [`Provider`](https://tinybase.org/api/ui-svelte/functions/component/provider/) component context.
The component's props identify the nub's initial location and panel state, though subsequent user changes to that will be preserved on each reload.
## Example
This example imports the `Inspector` component from the module.

```
import {Inspector} from 'tinybase/ui-svelte-inspector';

console.log(typeof Inspector);
// -> 'function'

```
