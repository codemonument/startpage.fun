# `WillApplyChangesCallback`
The `WillApplyChangesCallback` type describes a function that is called before [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) are applied to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
(changes: Changes[](https://tinybase.org/api/store/type-aliases/transaction/changes/)): Changes[](https://tinybase.org/api/store/type-aliases/transaction/changes/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `changes`  | `Changes[](https://tinybase.org/api/store/type-aliases/transaction/changes/)`  | The [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) about to be applied.  |  
| returns  | `Changes[](https://tinybase.org/api/store/type-aliases/transaction/changes/) | undefined`  | The [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) to use (possibly transformed), or `undefined` to prevent the write.  |  
The callback receives the [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) object that is about to be applied. It can return the [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) (possibly transformed) to allow the write, or `undefined` to prevent the [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) from being applied.
Multiple `WillApplyChangesCallback` functions can be registered and they will be called sequentially, the [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) being updated successively. If any callback returns `undefined`, the chain short-circuits and the [`Changes`](https://tinybase.org/api/store/type-aliases/transaction/changes/) will not be applied.
