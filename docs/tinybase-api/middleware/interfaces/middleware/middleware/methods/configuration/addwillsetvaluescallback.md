# `addWillSetValuesCallback`
The `addWillSetValuesCallback` method registers a [`WillSetValuesCallback`](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluescallback/) that will be called before [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) are set in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
addWillSetValuesCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetvaluescallback/)(callback: WillSetValuesCallback[](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluescallback/)): Middleware[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `callback`  | `WillSetValuesCallback[](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluescallback/)`  | The [`WillSetValuesCallback`](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluescallback/) to register.  |  
| returns  | `Middleware[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/)`  | A reference to the [`Middleware`](https://tinybase.org/api/middleware/interfaces/middleware/middleware/) object, for chaining.  |  
The callback can transform the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) or return `undefined` to prevent the write. Multiple callbacks can be registered and they are called sequentially, each receiving the (possibly transformed) values from the previous callback.
## Examples
This example registers a callback that upper-cases all string [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the pet store's settings.

```
import {createMiddleware, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const middleware = createMiddleware[](https://tinybase.org/api/middleware/functions/creation/createmiddleware/)(store);

middleware.addWillSetValuesCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetvaluescallback/)((values) =>
  Object.fromEntries(
    Object.entries(values).map(([k, v]) => [
      k,
      typeof v === 'string' ? v.toUpperCase() : v,
    ]),
  ),
);

store.setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({storeName: 'happy pets', limit: 50});
console.log(store.getValues[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getvalues/)());
// -> {storeName: 'HAPPY PETS', limit: 50}

middleware.destroy[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/lifecycle/destroy/)();

```

This example registers a callback that prevents setting [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) when the pet store is 'closed'.

```
import {createMiddleware, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const middleware = createMiddleware[](https://tinybase.org/api/middleware/functions/creation/createmiddleware/)(store);

middleware.addWillSetValuesCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetvaluescallback/)((values) =>
  'closed' in values ? undefined : values,
);

store.setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({closed: true, storeName: 'happy pets'});
console.log(store.getValues[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/getvalues/)());
// -> {}

middleware.destroy[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/lifecycle/destroy/)();

```
