# `addWillSetValueCallback`
The `addWillSetValueCallback` method registers a [`WillSetValueCallback`](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluecallback/) that will be called before any [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) is set in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
addWillSetValueCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetvaluecallback/)(callback: WillSetValueCallback[](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluecallback/)): Middleware[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `callback`  | `WillSetValueCallback[](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluecallback/)`  | The [`WillSetValueCallback`](https://tinybase.org/api/middleware/type-aliases/callback/willsetvaluecallback/) to register.  |  
| returns  | `Middleware[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/)`  | A reference to the [`Middleware`](https://tinybase.org/api/middleware/interfaces/middleware/middleware/) object, for chaining.  |  
The callback can transform the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) or return `undefined` to prevent the write. Multiple callbacks can be registered and they are called sequentially, each receiving the (possibly transformed) value from the previous callback.
## Example
This example registers a callback that clamps the 'limit' [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) to the maximum capacity of the pet store.

```
import {createMiddleware, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const middleware = createMiddleware[](https://tinybase.org/api/middleware/functions/creation/createmiddleware/)(store);

middleware.addWillSetValueCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetvaluecallback/)((valueId, value) =>
  valueId === 'limit' && typeof value === 'number'
    ? Math.min(50, Math.max(0, value))
    : value,
);

store.setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('limit', 100);
console.log(store.getValue[](https://tinybase.org/api/the-essentials/getting-data/getvalue/)('limit'));
// -> 50

middleware.destroy[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/lifecycle/destroy/)();

```
