# `addWillSetRowCallback`
The `addWillSetRowCallback` method registers a [`WillSetRowCallback`](https://tinybase.org/api/middleware/type-aliases/callback/willsetrowcallback/) that will be called before any [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is set in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
addWillSetRowCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetrowcallback/)(callback: WillSetRowCallback[](https://tinybase.org/api/middleware/type-aliases/callback/willsetrowcallback/)): Middleware[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `callback`  | `WillSetRowCallback[](https://tinybase.org/api/middleware/type-aliases/callback/willsetrowcallback/)`  | The [`WillSetRowCallback`](https://tinybase.org/api/middleware/type-aliases/callback/willsetrowcallback/) to register.  |  
| returns  | `Middleware[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/)`  | A reference to the [`Middleware`](https://tinybase.org/api/middleware/interfaces/middleware/middleware/) object, for chaining.  |  
The callback can transform the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) or return `undefined` to prevent the write. Multiple callbacks can be registered and they are called sequentially, each receiving the (possibly transformed) row from the previous callback.
This callback fires both when a whole [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is set with the [`setRow`](https://tinybase.org/api/the-essentials/setting-data/setrow/) method, _and_ when a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) is set with the [`setCell`](https://tinybase.org/api/the-essentials/setting-data/setcell/) method. When called from setCell, the callback receives a prospective row consisting of the existing [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values merged with the new [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value. The entire returned [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is then applied as though setRow had been called: all cells in the returned [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) are written (each also passing through willSetCell), and any cells absent from the returned [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) that existed before will be deleted. Return `undefined` to cancel the operation entirely.
## Examples
This example registers a callback that upper-cases string [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values in rows set to the 'pets' table.

```
import {createMiddleware, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const middleware = createMiddleware[](https://tinybase.org/api/middleware/functions/creation/createmiddleware/)(store);

middleware.addWillSetRowCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetrowcallback/)((tableId, _rowId, row) =>
  tableId === 'pets'
    ? Object.fromEntries(
        Object.entries(row).map(([k, v]) => [
          k,
          typeof v === 'string' ? v.toUpperCase() : v,
        ]),
      )
    : row,
);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'fido', {species: 'dog', legs: 4});
console.log(store.getRow[](https://tinybase.org/api/the-essentials/getting-data/getrow/)('pets', 'fido'));
// -> {species: 'DOG', legs: 4}

middleware.destroy[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/lifecycle/destroy/)();

```

This example registers a callback that prevents writes to the 'species' table.

```
import {createMiddleware, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const middleware = createMiddleware[](https://tinybase.org/api/middleware/functions/creation/createmiddleware/)(store);

middleware.addWillSetRowCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetrowcallback/)((tableId, _rowId, row) =>
  tableId === 'species' ? undefined : row,
);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('species', 'dog', {legs: 4, sound: 'woof'});
console.log(store.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {}

middleware.destroy[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/lifecycle/destroy/)();

```

This example shows the callback firing when setCell is called, automatically stamping an 'updated' timestamp onto the row each time any cell in it is written.

```
import {createMiddleware, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const middleware = createMiddleware[](https://tinybase.org/api/middleware/functions/creation/createmiddleware/)(store);

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'fido', {species: 'dog'});

middleware.addWillSetRowCallback[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/configuration/addwillsetrowcallback/)((_tableId, _rowId, row) => ({
  ...row,
  updated: Date.now(),
}));

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'legs', 4);
console.log(store.getCell[](https://tinybase.org/api/the-essentials/getting-data/getcell/)('pets', 'fido', 'legs'));
// -> 4
console.log(typeof store.getCell[](https://tinybase.org/api/the-essentials/getting-data/getcell/)('pets', 'fido', 'updated'));
// -> 'number'

middleware.destroy[](https://tinybase.org/api/middleware/interfaces/middleware/middleware/methods/lifecycle/destroy/)();

```
