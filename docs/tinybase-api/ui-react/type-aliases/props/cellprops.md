# `CellProps`
`CellProps` props are used for components that refer to a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), such as the [`CellView`](https://tinybase.org/api/ui-react/functions/store-components/cellview/) component.

```
{
  tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  rowId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  cellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  store?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/);
  debugIds?: boolean;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `rowId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `cellId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to be rendered.  |  
| `store?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be accessed: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| `debugIds?`  | `boolean`  | Whether the component should also render the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to assist with debugging.  |
