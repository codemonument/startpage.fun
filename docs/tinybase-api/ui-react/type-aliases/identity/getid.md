# `GetId`
The `GetId` type describes a function which, when passed a parameter, will return an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).

```
(
  parameter: Parameter,
  store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/),
): Id[](https://tinybase.org/api/common/type-aliases/identity/id/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `parameter`  | `Parameter`  |   |  
| `store`  | `Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)`  |   |  
| returns  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  |   |  
This type is used in hooks that create callbacks - like the [`useSetTableCallback`](https://tinybase.org/api/ui-react/functions/store-hooks/usesettablecallback/) hook or [`useSetRowCallback`](https://tinybase.org/api/ui-react/functions/store-hooks/usesetrowcallback/) hook - so that the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) arguments of the object to set can also be dependent on the event or parameter provided (as well as the object itself being set).
