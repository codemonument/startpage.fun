# Checkpoints hooks
## `useCheckpoint`
The [`useCheckpoint`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpoint/) hook returns the label for a checkpoint, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpoint/).
## `useCheckpointIds`
The [`useCheckpointIds`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointids/) hook returns an array of the checkpoint [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) being managed by this [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointids/).
## `useCheckpointIdsListener`
The [`useCheckpointIdsListener`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointidslistener/) hook registers a listener function with the [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object that will be called whenever its set of checkpoints changes. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointidslistener/).
## `useCheckpointListener`
The [`useCheckpointListener`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointlistener/) hook registers a listener function with the [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object that will be called whenever the label of a checkpoint changes. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointlistener/).
## `useCheckpoints`
The [`useCheckpoints`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpoints/) hook is used to get a reference to a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpoints/).
## `useCheckpointsIds`
The [`useCheckpointsIds`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointsids/) hook is used to retrieve the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all the named [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) objects present in the current [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointsids/).
## `useCheckpointsOrCheckpointsById`
The [`useCheckpointsOrCheckpointsById`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointsorcheckpointsbyid/) hook is used to get a reference to a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context, _or_ have it passed directly to this hook. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointsorcheckpointsbyid/).
## `useCreateCheckpoints`
The [`useCreateCheckpoints`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecreatecheckpoints/) hook is used to create a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object within a React application with convenient memoization. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecreatecheckpoints/).
## `useGoBackwardCallback`
The [`useGoBackwardCallback`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usegobackwardcallback/) hook returns a callback that moves the state of the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) back to the previous checkpoint, effectively performing an 'undo' on the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usegobackwardcallback/).
## `useGoForwardCallback`
The [`useGoForwardCallback`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usegoforwardcallback/) hook returns a callback that moves the state of the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) forwards to a future checkpoint, effectively performing an 'redo' on the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usegoforwardcallback/).
## `useGoToCallback`
The [`useGoToCallback`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usegotocallback/) hook returns a parameterized callback that can be used to move the state of the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) backwards or forwards to a specified checkpoint. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usegotocallback/).
## `useProvideCheckpoints`
The [`useProvideCheckpoints`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/useprovidecheckpoints/) hook is used to add a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component, but imperatively from a component within it. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/useprovidecheckpoints/).
## `useRedoInformation`
The [`useRedoInformation`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/useredoinformation/) hook returns an [`UndoOrRedoInformation`](https://tinybase.org/api/ui-react/type-aliases/checkpoints/undoorredoinformation/) array that indicates if and how you can move the state of the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) forwards to a future checkpoint. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/useredoinformation/).
## `useSetCheckpointCallback`
The [`useSetCheckpointCallback`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usesetcheckpointcallback/) hook returns a parameterized callback that can be used to record a checkpoint of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) into a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object that can be reverted to in the future. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usesetcheckpointcallback/).
## `useUndoInformation`
The [`useUndoInformation`](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/useundoinformation/) hook returns an [`UndoOrRedoInformation`](https://tinybase.org/api/ui-react/type-aliases/checkpoints/undoorredoinformation/) array that indicates if and how you can move the state of the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) backward to the previous checkpoint. [Read more](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/useundoinformation/).
