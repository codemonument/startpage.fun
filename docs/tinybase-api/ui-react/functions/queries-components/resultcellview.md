# `ResultCellView`
The `ResultCellView` component renders the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a given [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), in a given query's [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), and registers a listener so that any changes to that result will cause a re-render.

```
ResultCellView[](https://tinybase.org/api/ui-react/functions/queries-components/resultcellview/)(props: ResultCellProps[](https://tinybase.org/api/ui-react/type-aliases/props/resultcellprops/)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `ResultCellProps[](https://tinybase.org/api/ui-react/type-aliases/props/resultcellprops/)`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the result [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), or nothing, if not present.  |  
The component's props identify which [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to render based on query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object (which is either the default context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, a named context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, or an explicit reference).
A [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) contains a string, number, or boolean, so the value is rendered directly without further decoration. You can create your own ResultCellView-like component to customize the way that a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) is rendered: see the [`ResultRowView`](https://tinybase.org/api/ui-react/functions/queries-components/resultrowview/) component for more details.
This component uses the [`useResultCell`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcell/) hook under the covers, which means that any changes to the specified [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) will cause a re-render.
## Examples
This example creates a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object outside the application, which is used in the `ResultCellView` component by reference. A change to the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {ResultCellView} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
  cujo: {species: 'dog', color: 'black'},
});
const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)(
  'petColors',
  'pets',
  ({select}) => select('color'),
);
const App = () => (
  <span>
    <ResultCellView[](https://tinybase.org/api/ui-react/functions/queries-components/resultcellview/)
      queryId="petColors"
      rowId="fido"
      cellId="color"
      queries={queries}
    />
  </span>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<span>brown</span>'

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
console.log(app.innerHTML);
// -> '<span>walnut</span>'

```

This example creates a Provider context into which a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided. The `ResultCellView` component within it then renders the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) (with its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for readability).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {Provider, ResultCellView} from 'tinybase/ui-react';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queries={queries}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <span>
    <ResultCellView[](https://tinybase.org/api/ui-react/functions/queries-components/resultcellview/)
      queryId="petColors"
      rowId="fido"
      cellId="color"
      debugIds={true}
    />
  </span>
);

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
    cujo: {species: 'dog', color: 'black'},
  }),
).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('petColors', 'pets', ({select}) => select('color'));
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// -> '<span>color:{brown}</span>'

```

This example creates a Provider context into which a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided. The `ResultCellView` component within it then attempts to render a non-existent [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {Provider, ResultCellView} from 'tinybase/ui-react';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queries={queries}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <span>
    <ResultCellView[](https://tinybase.org/api/ui-react/functions/queries-components/resultcellview/) queryId="petColors" rowId="fido" cellId="height" />
  </span>
);

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
    cujo: {species: 'dog', color: 'black'},
  }),
).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('petColors', 'pets', ({select}) => select('color'));
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// -> '<span></span>'

```
