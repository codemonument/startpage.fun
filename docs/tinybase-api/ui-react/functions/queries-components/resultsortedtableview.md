# `ResultSortedTableView`
The `ResultSortedTableView` component renders the contents of a single query's sorted [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) in a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will cause a re-render.

```
ResultSortedTableView[](https://tinybase.org/api/ui-react/functions/queries-components/resultsortedtableview/)(props: ResultSortedTableProps[](https://tinybase.org/api/ui-react/type-aliases/props/resultsortedtableprops/)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `ResultSortedTableProps[](https://tinybase.org/api/ui-react/type-aliases/props/resultsortedtableprops/)`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), or nothing, if not present.  |  
The component's props identify which [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) to render based on query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object (which is either the default context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, a named context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, or by explicit reference). It also takes a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to sort by and a boolean to indicate that the sorting should be in descending order. The `offset` and `limit` props are used to paginate results, but default to `0` and `undefined` to return all available [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) if not specified.
This component renders a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) by iterating over its [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects, in the order dictated by the sort parameters. By default these are in turn rendered with the [`ResultRowView`](https://tinybase.org/api/ui-react/functions/queries-components/resultrowview/) component, but you can override this behavior by providing a `resultRowComponent` prop, a custom component of your own that will render a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) based on [`ResultRowProps`](https://tinybase.org/api/ui-react/type-aliases/props/resultrowprops/). You can also pass additional props to your custom component with the `getResultRowComponentProps` callback prop.
This component uses the [`useResultSortedRowIds`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultsortedrowids/) hook under the covers, which means that any changes to the structure or sorting of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) will cause a re-render.
## Examples
This example creates a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object outside the application, which is used in the `ResultSortedTableView` component by reference. A change to the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {ResultSortedTableView} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
});
const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)(
  'petColors',
  'pets',
  ({select}) => select('color'),
);
const App = () => (
  <div>
    <ResultSortedTableView[](https://tinybase.org/api/ui-react/functions/queries-components/resultsortedtableview/)
      queryId="petColors"
      cellId="color"
      queries={queries}
      separator="/"
    />
  </div>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<div>black/brown</div>'

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'felix', 'color', 'white');
console.log(app.innerHTML);
// -> '<div>brown/white</div>'

```

This example creates a Provider context into which a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided. The `ResultSortedTableView` component within it then renders the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (with [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for readability).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {Provider, ResultSortedTableView} from 'tinybase/ui-react';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queries={queries}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <div>
    <ResultSortedTableView[](https://tinybase.org/api/ui-react/functions/queries-components/resultsortedtableview/)
      queryId="petColors"
      cellId="color"
      debugIds={true}
    />
  </div>
);

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
  }),
).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('petColors', 'pets', ({select}) => select('color'));
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// -> '<div>petColors:{felix:{color:{black}}fido:{color:{brown}}}</div>'

```

This example creates a Provider context into which a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided. The `ResultSortedTableView` component within it then renders the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) with a custom [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) component and a custom props callback.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {
  Provider,
  ResultRowView,
  ResultSortedTableView,
} from 'tinybase/ui-react';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queries={queries}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const getBoldProp = (rowId) => ({bold: rowId == 'fido'});
const Pane = () => (
  <div>
    <ResultSortedTableView[](https://tinybase.org/api/ui-react/functions/queries-components/resultsortedtableview/)
      queryId="petColors"
      cellId="color"
      resultRowComponent={FormattedRowView}
      getResultRowComponentProps={getBoldProp}
    />
  </div>
);
const FormattedRowView = ({queryId, rowId, bold}) => (
  <span>
    {bold ? <b>{rowId}</b> : rowId}
    {': '}
    <ResultRowView[](https://tinybase.org/api/ui-react/functions/queries-components/resultrowview/) queryId={queryId} rowId={rowId} />
  </span>
);

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
  }),
).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('petColors', 'pets', ({select}) => select('color'));
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// -> '<div><span>felix: black</span><span><b>fido</b>: brown</span></div>'

```
