# `useCheckpointIds`
The `useCheckpointIds` hook returns an array of the checkpoint [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) being managed by this [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, and registers a listener so that any changes to that result will cause a re-render.

```
useCheckpointIds[](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointids/)(checkpointsOrCheckpointsId?: CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-react/type-aliases/identity/checkpointsorcheckpointsid/)): CheckpointIds[](https://tinybase.org/api/checkpoints/type-aliases/identity/checkpointids/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `checkpointsOrCheckpointsId?`  | `CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-react/type-aliases/identity/checkpointsorcheckpointsid/)`  | The [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object to be accessed: omit for the default context [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, or provide an explicit reference.  |  
| returns  | `CheckpointIds[](https://tinybase.org/api/checkpoints/type-aliases/identity/checkpointids/)`  | A [`CheckpointIds`](https://tinybase.org/api/checkpoints/type-aliases/identity/checkpointids/) array, containing the checkpoint [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) managed by this [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object.  |  
A [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component is used to wrap part of an application in a context, and it can contain a default [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object or a set of [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). The `useCheckpointIds` hook lets you indicate which [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object to get data for: omit the optional parameter for the default context [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, or provide a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object explicitly by reference.
When first rendered, this hook will create a listener so that changes to the checkpoint [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will cause a re-render. When the component containing this hook is unmounted, the listener will be automatically removed.
## Examples
This example creates a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object outside the application, which is used in the `useCheckpointIds` hook by reference. A change to the checkpoint [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createCheckpoints, createStore} from 'tinybase';
import {useCheckpointIds} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {fido: {species: 'dog'}});
const checkpoints = createCheckpoints[](https://tinybase.org/api/checkpoints/functions/creation/createcheckpoints/)(store);
const App = () => (
  <span>{JSON.stringify(useCheckpointIds[](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointids/)(checkpoints))}</span>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<span>[[],"0",[]]</span>'

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'sold', true);
console.log(app.innerHTML);
// -> '<span>[["0"],null,[]]</span>'

checkpoints.addCheckpoint[](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/methods/setter/addcheckpoint/)('sale');
console.log(app.innerHTML);
// -> '<span>[["0"],"1",[]]</span>'

```

This example creates a Provider context into which a default [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object is provided. A component within it then uses the `useCheckpointIds` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createCheckpoints, createStore} from 'tinybase';
import {Provider, useCheckpointIds} from 'tinybase/ui-react';

const App = ({checkpoints}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) checkpoints={checkpoints}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => <span>{JSON.stringify(useCheckpointIds[](https://tinybase.org/api/ui-react/functions/checkpoints-hooks/usecheckpointids/)())}</span>;

const checkpoints = createCheckpoints[](https://tinybase.org/api/checkpoints/functions/creation/createcheckpoints/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {fido: {species: 'dog'}}),
);

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App checkpoints={checkpoints} />);
console.log(app.innerHTML);
// -> '<span>[[],"0",[]]</span>'

```
