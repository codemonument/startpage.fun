# `usePersisterStatusListener`
The `usePersisterStatusListener` hook registers a listener function with the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) that will be called when its status changes.

```
usePersisterStatusListener[](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterstatuslistener/)(
  listener: StatusListener[](https://tinybase.org/api/persisters/type-aliases/listener/statuslistener/),
  listenerDeps?: DependencyList,
  persisterOrPersisterId?: PersisterOrPersisterId[](https://tinybase.org/api/ui-react/type-aliases/identity/persisterorpersisterid/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `listener`  | `StatusListener[](https://tinybase.org/api/persisters/type-aliases/listener/statuslistener/)`  | The function that will be called whenever the status of the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) changes.  |  
| `listenerDeps?`  | `DependencyList`  | An optional array of dependencies for the `listener` function, which, if any change, result in the re-registration of the listener. This parameter defaults to an empty array.  |  
| `persisterOrPersisterId?`  | `PersisterOrPersisterId[](https://tinybase.org/api/ui-react/type-aliases/identity/persisterorpersisterid/)`  | The [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) to be accessed: omit for the default context [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/), or provide an explicit reference.  |  
| returns  | `void`  | This has no return value.  |  
This hook is useful for situations where a component needs to register its own specific listener to do more than simply tracking the value (which is more easily done with the [`usePersisterStatus`](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterstatus/) hook).
Unlike the [`addStatusListener`](https://tinybase.org/api/persister-file/interfaces/persister/filepersister/methods/listener/addstatuslistener/) method, which returns a listener [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and requires you to remove it manually, the `usePersisterStatusListener` hook manages this lifecycle for you: when the listener changes (per its `listenerDeps` dependencies) or the component unmounts, the listener on the underlying [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) will be deleted.
## Example
This example uses the `usePersisterStatusListener` hook to create a listener that is scoped to a single component. When the component is unmounted, the listener is removed from the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {createSessionPersister} from 'tinybase/persisters/persister-browser';
import {Provider, usePersisterStatusListener} from 'tinybase/ui-react';

const App = ({persister}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) persister={persister}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => {
  usePersisterStatusListener[](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterstatuslistener/)((persister, status) =>
    console.log('Persister status changed: ' + status),
  );
  return <span>App</span>;
};

const persister = createSessionPersister[](https://tinybase.org/api/persister-browser/functions/creation/createsessionpersister/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)(), 'pets');
const app = document.createElement('div');
const root = createRoot(app);
root.render(<App persister={persister} />);

persister.load[](https://tinybase.org/api/persisters/interfaces/persister/persister/methods/load/load/)();
// -> 'Persister status changed: 1'
// ...
// -> 'Persister status changed: 0'

persister.save[](https://tinybase.org/api/persisters/interfaces/persister/persister/methods/save/save/)();
// -> 'Persister status changed: 2'
// ...
// -> 'Persister status changed: 0'

```
