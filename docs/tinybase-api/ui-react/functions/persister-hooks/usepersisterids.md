# `usePersisterIds`
The `usePersisterIds` hook is used to retrieve the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all the named [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) objects present in the current [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context.

```
usePersisterIds[](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterids/)(): Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)
```
  
| returns  | `Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)`  | A list of the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the context.  |  
| --- | --- | --- |  
## Example
This example adds two named [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) objects to a Provider context and an inner component accesses their [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {createSessionPersister} from 'tinybase/persisters/persister-browser';
import {
  Provider,
  useCreatePersister,
  useCreateStore,
  usePersisterIds,
} from 'tinybase/ui-react';

const App = () => {
  const store1 = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(createStore);
  const persister1 = useCreatePersister[](https://tinybase.org/api/ui-react/functions/persister-hooks/usecreatepersister/)(store1, (store1) =>
    createSessionPersister[](https://tinybase.org/api/persister-browser/functions/creation/createsessionpersister/)(store1, 'pets1'),
  );
  const store2 = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(createStore);
  const persister2 = useCreatePersister[](https://tinybase.org/api/ui-react/functions/persister-hooks/usecreatepersister/)(store2, (store2) =>
    createSessionPersister[](https://tinybase.org/api/persister-browser/functions/creation/createsessionpersister/)(store2, 'pets2'),
  );
  return (
    <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) persistersById={{persister1, persister2}}>
      <Pane />
    </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
  );
};
const Pane = () => <span>{JSON.stringify(usePersisterIds[](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterids/)())}</span>;

const app = document.createElement('div');
createRoot(app).render(<App />);

// ...
console.log(app.innerHTML);
// -> '<span>["persister1","persister2"]</span>'

```
