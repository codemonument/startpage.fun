# `useProvidePersister`
The `useProvidePersister` hook is used to add a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component, but imperatively from a component within it.

```
useProvidePersister[](https://tinybase.org/api/ui-react/functions/persister-hooks/useprovidepersister/)(
  persisterId: string,
  persister: AnyPersister[](https://tinybase.org/api/persisters/type-aliases/mergeable/anypersister/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `persisterId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object to be registered with the Provider.  |  
| `persister`  | `AnyPersister[](https://tinybase.org/api/persisters/type-aliases/mergeable/anypersister/)`  | The [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object to be registered.  |  
| returns  | `void`  | This has no return value.  |  
Normally you will register a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in a context by using the `persistersById` prop of the top-level [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component. This hook, however, lets you dynamically add a new [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object to the context, from within a component. This is useful for applications where the set of [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) objects is not known at the time of the first render of the root Provider.
A [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object added to the Provider context in this way will be available to other components within the context (using the [`usePersister`](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersister/) hook and so on). If you use the same [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as an existing [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object registration, the new one will take priority over one provided by the `persistersById` prop.
Note that other components that consume a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object registered like this should defend against it being undefined at first. On the first render, the other component will likely not yet have completed the registration. In the example below, we use the null-safe `usePersister('petPersister')?` to do this.
## Example
This example creates a Provider context. A child component registers a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object into it which is then consumable by a peer child component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {createSessionPersister} from 'tinybase/persisters/persister-browser';
import {
  Provider,
  useCreatePersister,
  useCreateStore,
  usePersister,
  useProvidePersister,
} from 'tinybase/ui-react';

const App = () => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
    <RegisterPersister />
    <ConsumePersister />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const RegisterPersister = () => {
  const store = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(() =>
    createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'brown'),
  );
  const persister = useCreatePersister[](https://tinybase.org/api/ui-react/functions/persister-hooks/usecreatepersister/)(store, (store) =>
    createSessionPersister[](https://tinybase.org/api/persister-browser/functions/creation/createsessionpersister/)(store, 'pets'),
  );
  useProvidePersister[](https://tinybase.org/api/ui-react/functions/persister-hooks/useprovidepersister/)('petPersister', persister);
  return null;
};
const ConsumePersister = () => (
  <span>{usePersister[](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersister/)('petPersister')?.getStatus[](https://tinybase.org/api/persisters/interfaces/persister/persister/methods/lifecycle/getstatus/)()}</span>
);

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App />);

// ...
console.log(app.innerHTML);
// -> '<span>0</span>'

```
