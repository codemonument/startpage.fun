# Persister hooks
## `useCreatePersister`
The [`useCreatePersister`](https://tinybase.org/api/ui-react/functions/persister-hooks/usecreatepersister/) hook is used to create a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) within a React application along with convenient memoization and callbacks. [Read more](https://tinybase.org/api/ui-react/functions/persister-hooks/usecreatepersister/).
## `usePersister`
The [`usePersister`](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersister/) hook is used to get a reference to a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersister/).
## `usePersisterIds`
The [`usePersisterIds`](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterids/) hook is used to retrieve the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all the named [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) objects present in the current [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterids/).
## `usePersisterOrPersisterById`
The [`usePersisterOrPersisterById`](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterorpersisterbyid/) hook is used to get a reference to a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context, _or_ have it passed directly to this hook. [Read more](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterorpersisterbyid/).
## `usePersisterStatus`
The [`usePersisterStatus`](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterstatus/) hook returns a the status of a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/), and registers a listener so that any changes to it will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterstatus/).
## `usePersisterStatusListener`
The [`usePersisterStatusListener`](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterstatuslistener/) hook registers a listener function with the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) that will be called when its status changes. [Read more](https://tinybase.org/api/ui-react/functions/persister-hooks/usepersisterstatuslistener/).
## `useProvidePersister`
The [`useProvidePersister`](https://tinybase.org/api/ui-react/functions/persister-hooks/useprovidepersister/) hook is used to add a [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component, but imperatively from a component within it. [Read more](https://tinybase.org/api/ui-react/functions/persister-hooks/useprovidepersister/).
