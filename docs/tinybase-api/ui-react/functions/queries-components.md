# Queries components
## `ResultSortedTableView`
The [`ResultSortedTableView`](https://tinybase.org/api/ui-react/functions/queries-components/resultsortedtableview/) component renders the contents of a single query's sorted [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) in a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-components/resultsortedtableview/).
## `ResultTableView`
The [`ResultTableView`](https://tinybase.org/api/ui-react/functions/queries-components/resulttableview/) component renders the contents of a single query's [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) in a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-components/resulttableview/).
## `ResultRowView`
The [`ResultRowView`](https://tinybase.org/api/ui-react/functions/queries-components/resultrowview/) component renders the contents of a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a given query's [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-components/resultrowview/).
## `ResultCellView`
The [`ResultCellView`](https://tinybase.org/api/ui-react/functions/queries-components/resultcellview/) component renders the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a given [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), in a given query's [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-components/resultcellview/).
