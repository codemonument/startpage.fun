# `useParamValueState`
The `useParamValueState` hook returns a parameter value and a function to set it, following the same pattern as React's useState hook.

```
useParamValueState[](https://tinybase.org/api/ui-react/functions/state-hooks/useparamvaluestate/)(
  queryId: string,
  paramId: string,
  queriesOrQueriesId?: QueriesOrQueriesId[](https://tinybase.org/api/ui-react/type-aliases/identity/queriesorqueriesid/),
): [ParamValue[](https://tinybase.org/api/queries/type-aliases/params/paramvalue/) | undefined, (paramValue: ParamValue[](https://tinybase.org/api/queries/type-aliases/params/paramvalue/)) => void]
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query.  |  
| `paramId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the parameter.  |  
| `queriesOrQueriesId?`  | `QueriesOrQueriesId[](https://tinybase.org/api/ui-react/type-aliases/identity/queriesorqueriesid/)`  | The [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object to be accessed: omit for the default context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, or provide an explicit reference.  |  
| returns  | `[ParamValue[](https://tinybase.org/api/queries/type-aliases/params/paramvalue/) | undefined, (paramValue: ParamValue[](https://tinybase.org/api/queries/type-aliases/params/paramvalue/)) => void]`  | An array containing the parameter value and a function to set it.  |  
This is a convenience hook that combines the useParamValue and [`useSetParamValueCallback`](https://tinybase.org/api/ui-react/functions/queries-hooks/usesetparamvaluecallback/) hooks. It's useful when you need both read and write access to a query parameter in a single component.
A [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component is used to wrap part of an application in a context, and it can contain a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object or a set of [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). The `useParamValueState` hook lets you indicate which [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object to use: omit the final parameter for the default context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, or provide an explicit reference.
## Example
This example creates a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object outside the application, which is used in the `useParamValueState` hook by reference. A button updates the parameter when clicked.

```
import {createQueries, createStore} from 'tinybase';
import React from 'react';
import {createRoot} from 'react-dom/client';
import {useParamValueState} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/store/functions/creation/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
});
const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)(
  'petsBySpecies',
  'pets',
  ({select, where, param}) => {
    select('species');
    where('species', param('species'));
  },
  {species: 'dog'},
);
const App = () => {
  const [species, setSpecies] = useParamValueState[](https://tinybase.org/api/ui-react/functions/state-hooks/useparamvaluestate/)(
    'petsBySpecies',
    'species',
    queries,
  );
  return (
    <div>
      Species: {species}
      <button onClick={() => setSpecies('cat')}>Change</button>
    </div>
  );
};

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App />);
console.log(app.innerHTML);
// -> '<div>Species: dog<button>Change</button></div>'

const _button = app.querySelector('button');
// -> _button MouseEvent('click', {bubbles: true})
console.log(app.innerHTML);
// -> '<div>Species: cat<button>Change</button></div>'

```
