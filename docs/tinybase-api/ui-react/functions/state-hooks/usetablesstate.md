# `useTablesState`
The `useTablesState` hook returns a [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) object and a function to set it, following the same pattern as React's useState hook.

```
useTablesState[](https://tinybase.org/api/ui-react/functions/state-hooks/usetablesstate/)(storeOrStoreId?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)): [Tables[](https://tinybase.org/api/store/type-aliases/store/tables/), (tables: Tables[](https://tinybase.org/api/store/type-aliases/store/tables/)) => void]
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `storeOrStoreId?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be accessed: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| returns  | `[Tables[](https://tinybase.org/api/store/type-aliases/store/tables/), (tables: Tables[](https://tinybase.org/api/store/type-aliases/store/tables/)) => void]`  | An array containing the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) object and a function to set it.  |  
This is a convenience hook that combines the useTables and [`useSetTablesCallback`](https://tinybase.org/api/ui-react/functions/store-hooks/usesettablescallback/) hooks. It's useful when you need both read and write access to all [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in a single component.
A [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component is used to wrap part of an application in a context, and it can contain a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) or a set of [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). The `useTablesState` hook lets you indicate which [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to use: omit the parameter for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) explicitly by reference.
## Example
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) outside the application, which is used in the `useTablesState` hook by reference. A button updates the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) when clicked.

```
import {createStore} from 'tinybase';
import React from 'react';
import {createRoot} from 'react-dom/client';
import {useTablesState} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/store/functions/creation/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({pets: {fido: {species: 'dog'}}});
const App = () => {
  const [tables, setTables] = useTablesState[](https://tinybase.org/api/ui-react/functions/state-hooks/usetablesstate/)(store);
  return (
    <div>
      {JSON.stringify(tables)}
      <button
        onClick={() => setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({...tables, species: {dog: {price: 5}}})}
      >
        Add
      </button>
    </div>
  );
};

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App />);
console.log(app.innerHTML);
// -> '<div>{"pets":{"fido":{"species":"dog"}}}<button>Add</button></div>'

const _button = app.querySelector('button');
// -> _button MouseEvent('click', {bubbles: true})
console.log(app.innerHTML);
// ->
`
<div>
  {"pets":{"fido":{"species":"dog"}},"species":{"dog":{"price":5}}}
  <button>Add</button>
</div>
`;

```
