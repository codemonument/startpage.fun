# `useSynchronizerOrSynchronizerById`
The `useSynchronizerOrSynchronizerById` hook is used to get a reference to a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object from within a [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component context, _or_ have it passed directly to this hook.

```
useSynchronizerOrSynchronizerById[](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizerorsynchronizerbyid/)(synchronizerOrSynchronizerId?: SynchronizerOrSynchronizerId[](https://tinybase.org/api/ui-react/type-aliases/identity/synchronizerorsynchronizerid/)): Synchronizer[](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `synchronizerOrSynchronizerId?`  | `SynchronizerOrSynchronizerId[](https://tinybase.org/api/ui-react/type-aliases/identity/synchronizerorsynchronizerid/)`  | Either an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for accessing a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object that was named with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in the Provider, or the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object itself.  |  
| returns  | `Synchronizer[](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) | undefined`  | A reference to the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object (or `undefined` if not within a Provider context, or if the requested [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object does not exist).  |  
This is mostly of use when you are developing a component that needs a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object and which might have been passed in explicitly to the component or is to be picked up from the context by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) (a common pattern for [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/)-based components).
This is unlikely to be used often. For most situations, you will want to use the [`useSynchronizer`](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizer/) hook.
## Example
This example creates a Provider context into which a default [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object is provided. A component within it then uses the `useSynchronizerOrSynchronizerById` hook to get a reference to the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object again, without the need to have it passed as a prop. Note however, that unlike the [`useSynchronizer`](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizer/) hook example, this component would also work if you were to pass the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object directly into it, making it more portable.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMergeableStore} from 'tinybase';
import {createLocalSynchronizer} from 'tinybase/synchronizers/synchronizer-local';
import {
  Provider,
  useSynchronizerOrSynchronizerById,
} from 'tinybase/ui-react';

const App = ({synchronizer}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) synchronizer={synchronizer}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = ({synchronizer}) => (
  <span>
    {useSynchronizerOrSynchronizerById[](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizerorsynchronizerbyid/)(synchronizer).getStatus[](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/methods/lifecycle/getstatus/)()}
  </span>
);

const synchronizer = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)());
const app = document.createElement('div');
const root = createRoot(app);
root.render(<App synchronizer={synchronizer} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```
