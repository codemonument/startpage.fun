# `useSynchronizerStatus`
The `useSynchronizerStatus` hook returns a the status of a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/), and registers a listener so that any changes to it will cause a re-render.

```
useSynchronizerStatus[](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizerstatus/)(synchronizerOrSynchronizerId?: SynchronizerOrSynchronizerId[](https://tinybase.org/api/ui-react/type-aliases/identity/synchronizerorsynchronizerid/)): Status[](https://tinybase.org/api/persisters/enumerations/lifecycle/status/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `synchronizerOrSynchronizerId?`  | `SynchronizerOrSynchronizerId[](https://tinybase.org/api/ui-react/type-aliases/identity/synchronizerorsynchronizerid/)`  | The [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) to be accessed: omit for the default context [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/), or provide an explicit reference.  |  
| returns  | `Status[](https://tinybase.org/api/persisters/enumerations/lifecycle/status/)`  | The status of the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/): 0 means idle, 1 means loading, and 2 means saving.  |  
A [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component is used to wrap part of an application in a context, and it can contain a default [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) or a set of [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). The `useSynchronizerStatus` hook lets you indicate which [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) to get data for: omit the optional parameter for the default context [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/), or provide a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) explicitly by reference.
When first rendered, this hook will create a listener so that changes to the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) status will cause a re-render. When the component containing this hook is unmounted, the listener will be automatically removed.
## Examples
This example creates a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) outside the application, which is used in the `useSynchronizerStatus` hook by reference. A change to the status of the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMergeableStore} from 'tinybase';
import {createLocalSynchronizer} from 'tinybase/synchronizers/synchronizer-local';
import {useSynchronizerStatus} from 'tinybase/ui-react';

const synchronizer = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)());
const App = () => <span>{useSynchronizerStatus[](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizerstatus/)(synchronizer)}</span>;

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```

This example creates a Provider context into which a default [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) is provided. A component within it then uses the `useSynchronizerStatus` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMergeableStore} from 'tinybase';
import {createLocalSynchronizer} from 'tinybase/synchronizers/synchronizer-local';
import {Provider, useSynchronizerStatus} from 'tinybase/ui-react';

const App = ({synchronizer}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) synchronizer={synchronizer}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => <span>{useSynchronizerStatus[](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizerstatus/)()}</span>;

const synchronizer = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)());
const app = document.createElement('div');
createRoot(app).render(<App synchronizer={synchronizer} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```

This example creates a Provider context into which a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) is provided, named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). A component within it then uses the `useSynchronizerStatus` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMergeableStore} from 'tinybase';
import {createLocalSynchronizer} from 'tinybase/synchronizers/synchronizer-local';
import {Provider, useSynchronizerStatus} from 'tinybase/ui-react';

const App = ({synchronizer}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) synchronizersById={{petSynchronizer: synchronizer}}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => <span>{useSynchronizerStatus[](https://tinybase.org/api/ui-react/functions/synchronizer-hooks/usesynchronizerstatus/)('petSynchronizer')}</span>;

const synchronizer = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)());
const app = document.createElement('div');
createRoot(app).render(<App synchronizer={synchronizer} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```
