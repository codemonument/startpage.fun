# `useQueriesIds`
The `useQueriesIds` hook is used to retrieve the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all the named [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) objects present in the current [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context.

```
useQueriesIds[](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeriesids/)(): Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)
```
  
| returns  | `Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)`  | A list of the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the context.  |  
| --- | --- | --- |  
## Example
This example adds two named [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) objects to a Provider context and an inner component accesses their [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {
  Provider,
  useCreateQueries,
  useCreateStore,
  useQueriesIds,
} from 'tinybase/ui-react';

const App = () => {
  const store1 = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(createStore);
  const queries1 = useCreateQueries[](https://tinybase.org/api/ui-react/functions/queries-hooks/usecreatequeries/)(store1, createQueries);
  const store2 = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(createStore);
  const queries2 = useCreateQueries[](https://tinybase.org/api/ui-react/functions/queries-hooks/usecreatequeries/)(store2, createQueries);
  return (
    <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queriesById={{queries1, queries2}}>
      <Pane />
    </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
  );
};
const Pane = () => <span>{JSON.stringify(useQueriesIds[](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeriesids/)())}</span>;

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<span>["queries1","queries2"]</span>'

```
