# `useQueries`
The `useQueries` hook is used to get a reference to a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context.

```
useQueries[](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeries/)(id?: string): Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `id?`  | `string`  | An optional [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for accessing a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that was named with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in the Provider.  |  
| returns  | `Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/) | undefined`  | A reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object (or `undefined` if not within a Provider context, or if the requested [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object does not exist).  |  
A [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component is used to wrap part of an application in a context. It can contain a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object (or a set of [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) that can be easily accessed without having to be passed down as props through every component.
The `useQueries` hook lets you either get a reference to the default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object (when called without a parameter), or one of the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) objects that are named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) (when called with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) parameter).
## Examples
This example creates a Provider context into which a default [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided. A component within it then uses the `useQueries` hook to get a reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object again, without the need to have it passed as a prop.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {Provider, useQueries} from 'tinybase/ui-react';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queries={queries}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => <span>{useQueries[](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeries/)().getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().table}</span>;

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)());
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```

This example creates a Provider context into which a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object is provided, named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). A component within it then uses the `useQueries` hook with that [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to get a reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object again, without the need to have it passed as a prop.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createQueries, createStore} from 'tinybase';
import {Provider, useQueries} from 'tinybase/ui-react';

const App = ({queries}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) queriesById={{petQueries: queries}}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <span>{useQueries[](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeries/)('petQueries').getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().table}</span>
);

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)());
const app = document.createElement('div');
createRoot(app).render(<App queries={queries} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```
