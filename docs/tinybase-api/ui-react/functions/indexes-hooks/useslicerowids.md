# `useSliceRowIds`
The `useSliceRowIds` hook gets the list of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a given [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/), and registers a listener so that any changes to that result will cause a re-render.

```
useSliceRowIds[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useslicerowids/)(
  indexId: string,
  sliceId: string,
  indexesOrIndexesId?: IndexesOrIndexesId[](https://tinybase.org/api/ui-react/type-aliases/identity/indexesorindexesid/),
): Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `indexId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).  |  
| `sliceId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).  |  
| `indexesOrIndexesId?`  | `IndexesOrIndexesId[](https://tinybase.org/api/ui-react/type-aliases/identity/indexesorindexesid/)`  | The [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object to be accessed: omit for the default context [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, or provide an explicit reference.  |  
| returns  | `Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)`  | The [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/), or an empty array.  |  
A [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component is used to wrap part of an application in a context, and it can contain a default [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object or a set of [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). The `useSliceRowIds` hook lets you indicate which [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object to get data for: omit the optional final parameter for the default context [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, or provide an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object explicitly by reference.
When first rendered, this hook will create a listener so that changes to the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) will cause a re-render. When the component containing this hook is unmounted, the listener will be automatically removed.
## Examples
This example creates an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object outside the application, which is used in the `useSliceRowIds` hook by reference. A change to the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createIndexes, createStore} from 'tinybase';
import {useSliceRowIds} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  cujo: {species: 'dog'},
});
const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species');
const App = () => (
  <span>
    {JSON.stringify(useSliceRowIds[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useslicerowids/)('bySpecies', 'dog', indexes))}
  </span>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<span>["fido","cujo"]</span>'

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'toto', {species: 'dog'});
console.log(app.innerHTML);
// -> '<span>["fido","cujo","toto"]</span>'

```

This example creates a Provider context into which a default [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object is provided. A component within it then uses the `useSliceRowIds` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createIndexes, createStore} from 'tinybase';
import {Provider, useSliceRowIds} from 'tinybase/ui-react';

const App = ({indexes}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) indexes={indexes}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <span>{JSON.stringify(useSliceRowIds[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useslicerowids/)('bySpecies', 'dog'))}</span>
);

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog'},
    felix: {species: 'cat'},
    cujo: {species: 'dog'},
  }),
).setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species');

const app = document.createElement('div');
createRoot(app).render(<App indexes={indexes} />);
console.log(app.innerHTML);
// -> '<span>["fido","cujo"]</span>'

```

    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <span>
    {JSON.stringify(useSliceRowIds[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useslicerowids/)('bySpecies', 'dog', 'petIndexes'))}
  </span>
);

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog'},
    felix: {species: 'cat'},
    cujo: {species: 'dog'},
