# `useSliceRowIdsListener`
The `useSliceRowIdsListener` hook registers a listener function with the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object that will be called whenever the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) change.

```
useSliceRowIdsListener[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useslicerowidslistener/)(
  indexId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  sliceId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: SliceRowIdsListener[](https://tinybase.org/api/indexes/type-aliases/listener/slicerowidslistener/),
  listenerDeps?: DependencyList,
  indexesOrIndexesId?: IndexesOrIndexesId[](https://tinybase.org/api/ui-react/type-aliases/identity/indexesorindexesid/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `indexId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) to listen to, or `null` as a wildcard.  |  
| `sliceId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `SliceRowIdsListener[](https://tinybase.org/api/indexes/type-aliases/listener/slicerowidslistener/)`  | The function that will be called whenever the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) change.  |  
| `listenerDeps?`  | `DependencyList`  | An optional array of dependencies for the `listener` function, which, if any change, result in the re-registration of the listener. This parameter defaults to an empty array.  |  
| `indexesOrIndexesId?`  | `IndexesOrIndexesId[](https://tinybase.org/api/ui-react/type-aliases/identity/indexesorindexesid/)`  | The [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object to register the listener with: omit for the default context [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object, or provide an explicit reference.  |  
| returns  | `void`  | This has no return value.  |  
This hook is useful for situations where a component needs to register its own specific listener to do more than simply tracking the value (which is more easily done with the [`useSliceRowIds`](https://tinybase.org/api/ui-react/functions/indexes-hooks/useslicerowids/) hook).
You can either listen to a single [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) (by specifying the [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first two parameters), or changes to any [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) (by providing `null` wildcards).
Both, either, or neither of the `indexId` and `sliceId` parameters can be wildcarded with `null`. You can listen to a specific [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in a specific [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), any [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in a specific [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), a specific [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in any [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), or any [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in any [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/).
Unlike the [`addSliceRowIdsListener`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/listener/addslicerowidslistener/) method, which returns a listener [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and requires you to remove it manually, the `useSliceRowIdsListener` hook manages this lifecycle for you: when the listener changes (per its `listenerDeps` dependencies) or the component unmounts, the listener on the underlying [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object will be deleted.
## Example
This example uses the `useSliceRowIdsListener` hook to create a listener that is scoped to a single component. When the component is unmounted, the listener is removed from the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createIndexes, createStore} from 'tinybase';
import {Provider, useSliceRowIdsListener} from 'tinybase/ui-react';

const App = ({indexes}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) indexes={indexes}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => {
  useSliceRowIdsListener[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useslicerowidslistener/)('bySpecies', 'dog', () =>
    console.log('Slice Row Ids changed'),
  );
  return <span>App</span>;
};

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
  cujo: {species: 'dog'},
});
const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(store);
indexes.setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species');

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App indexes={indexes} />);
console.log(indexes.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().sliceRowIds);
// -> 1

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'toto', {species: 'dog'});
// -> 'Slice Row Ids changed'

root.unmount();
console.log(indexes.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().sliceRowIds);
// -> 0

```
