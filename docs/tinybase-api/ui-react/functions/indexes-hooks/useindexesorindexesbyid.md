# `useIndexesOrIndexesById`
The `useIndexesOrIndexesById` hook is used to get a reference to an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object from within a [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component context, _or_ have it passed directly to this hook.

```
useIndexesOrIndexesById[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useindexesorindexesbyid/)(indexesOrIndexesId?: IndexesOrIndexesId[](https://tinybase.org/api/ui-react/type-aliases/identity/indexesorindexesid/)): Indexes[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `indexesOrIndexesId?`  | `IndexesOrIndexesId[](https://tinybase.org/api/ui-react/type-aliases/identity/indexesorindexesid/)`  | Either an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for accessing a [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object that was named with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in the Provider, or the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object itself.  |  
| returns  | `Indexes[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) | undefined`  | A reference to the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object (or `undefined` if not within a Provider context, or if the requested [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object does not exist).  |  
This is mostly of use when you are developing a component that needs an [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object and which might have been passed in explicitly to the component or is to be picked up from the context by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) (a common pattern for [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/)-based components).
This hook is unlikely to be used often. For most situations, you will want to use the [`useIndexes`](https://tinybase.org/api/ui-react/functions/indexes-hooks/useindexes/) hook.
## Example
This example creates a Provider context into which a default [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object is provided. A component within it then uses the `useIndexesOrIndexesById` hook to get a reference to the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object again, without the need to have it passed as a prop. Note however, that unlike the [`useIndexes`](https://tinybase.org/api/ui-react/functions/indexes-hooks/useindexes/) hook example, this component would also work if you were to pass the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object directly into it, making it more portable.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createIndexes, createStore} from 'tinybase';
import {Provider, useIndexesOrIndexesById} from 'tinybase/ui-react';

const App = ({indexes}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) indexes={indexes}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = ({indexes}) => (
  <span>
    {JSON.stringify(useIndexesOrIndexesById[](https://tinybase.org/api/ui-react/functions/indexes-hooks/useindexesorindexesbyid/)(indexes).getIndexIds[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/getter/getindexids/)())}
  </span>
);

const indexes = createIndexes[](https://tinybase.org/api/indexes/functions/creation/createindexes/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog'},
    felix: {species: 'cat'},
    cujo: {species: 'dog'},
  }),
).setIndexDefinition[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/methods/configuration/setindexdefinition/)('bySpecies', 'pets', 'species');

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App indexes={indexes} />);
console.log(app.innerHTML);
// -> '<span>["bySpecies"]</span>'

```
