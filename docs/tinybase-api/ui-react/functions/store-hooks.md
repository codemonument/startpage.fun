# Store hooks
## `useCreateMergeableStore`
The [`useCreateMergeableStore`](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatemergeablestore/) hook. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatemergeablestore/).
## `useCreateStore`
Essential
The [`useCreateStore`](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/) hook is used to create a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) within a React application with convenient memoization. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/).
## `useProvideStore`
The [`useProvideStore`](https://tinybase.org/api/ui-react/functions/store-hooks/useprovidestore/) hook is used to add a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) object by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component, but imperatively from a component within it. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/useprovidestore/).
## `useStore`
The [`useStore`](https://tinybase.org/api/ui-react/functions/store-hooks/usestore/) hook is used to get a reference to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usestore/).
## `useStoreIds`
The [`useStoreIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usestoreids/) hook is used to retrieve the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all the named [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects present in the current [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usestoreids/).
## `useStoreOrStoreById`
The [`useStoreOrStoreById`](https://tinybase.org/api/ui-react/functions/store-hooks/usestoreorstorebyid/) hook is used to get a reference to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context, _or_ have it passed directly to this hook. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usestoreorstorebyid/).
## `useStores`
The [`useStores`](https://tinybase.org/api/ui-react/functions/store-hooks/usestores/) hook is used to get a reference to all the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usestores/).
## `useDelTablesCallback`
The [`useDelTablesCallback`](https://tinybase.org/api/ui-react/functions/store-hooks/usedeltablescallback/) hook returns a callback that can be used to remove all of the tabular data in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usedeltablescallback/).
## `useHasTables`
The [`useHasTables`](https://tinybase.org/api/ui-react/functions/store-hooks/usehastables/) hook returns a boolean indicating whether any [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) objects exist in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usehastables/).
## `useHasTablesListener`
The [`useHasTablesListener`](https://tinybase.org/api/ui-react/functions/store-hooks/usehastableslistener/) hook registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called when [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) as a whole are added to or removed from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usehastableslistener/).
## `useSetTablesCallback`
The [`useSetTablesCallback`](https://tinybase.org/api/ui-react/functions/store-hooks/usesettablescallback/) hook returns a parameterized callback that can be used to set the tabular data of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usesettablescallback/).
## `useTables`
The [`useTables`](https://tinybase.org/api/ui-react/functions/store-hooks/usetables/) hook returns a [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) object containing the tabular data of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usetables/).
## `useTablesListener`
The [`useTablesListener`](https://tinybase.org/api/ui-react/functions/store-hooks/usetableslistener/) hook registers a listener function with a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called whenever tabular data in it changes. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usetableslistener/).
## `useTableIds`
The [`useTableIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usetableids/) hook returns the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of every [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usetableids/).
## `useTableIdsListener`
The [`useTableIdsListener`](https://tinybase.org/api/ui-react/functions/store-hooks/usetableidslistener/) hook registers a listener function with a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called whenever the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in it change. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usetableidslistener/).
## `useDelTableCallback`
The [`useDelTableCallback`](https://tinybase.org/api/ui-react/functions/store-hooks/usedeltablecallback/) hook returns a parameterized callback that can be used to remove a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) from a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usedeltablecallback/).
## `useHasTable`
The [`useHasTable`](https://tinybase.org/api/ui-react/functions/store-hooks/usehastable/) hook returns a boolean indicating whether a given [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) exists in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usehastable/).
## `useHasTableCell`
The [`useHasTableCell`](https://tinybase.org/api/ui-react/functions/store-hooks/usehastablecell/) hook returns a boolean indicating whether a given [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) exists anywhere in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), not just in a specific [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usehastablecell/).
## `useHasTableCellListener`
The [`useHasTableCellListener`](https://tinybase.org/api/ui-react/functions/store-hooks/usehastablecelllistener/) hook registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called when a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) is added to or removed from anywhere in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) as a whole. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usehastablecelllistener/).
## `useHasTableListener`
The [`useHasTableListener`](https://tinybase.org/api/ui-react/functions/store-hooks/usehastablelistener/) hook registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called when a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is added to or removed from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usehastablelistener/).
## `useSetTableCallback`
The [`useSetTableCallback`](https://tinybase.org/api/ui-react/functions/store-hooks/usesettablecallback/) hook returns a parameterized callback that can be used to set the data of a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usesettablecallback/).
## `useTable`
The [`useTable`](https://tinybase.org/api/ui-react/functions/store-hooks/usetable/) hook returns an object containing the data of a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/store-hooks/usetable/).
## `useTableCellIds`
The [`useTableCellIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usetablecellids/) hook returns the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of every [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) used across the whole [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and registers a listener so that any changes to that result will cause a re-render.
