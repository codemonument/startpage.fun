# `useWillFinishTransactionListener`
The `useWillFinishTransactionListener` hook registers a listener function with a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called just before other non-mutating listeners are called at the end of the transaction.

```
useWillFinishTransactionListener[](https://tinybase.org/api/ui-react/functions/store-hooks/usewillfinishtransactionlistener/)(
  listener: TransactionListener[](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/),
  listenerDeps?: DependencyList,
  storeOrStoreId?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `listener`  | `TransactionListener[](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/)`  | The function that will be called before the end of a transaction.  |  
| `listenerDeps?`  | `DependencyList`  | An optional array of dependencies for the `listener` function, which, if any change, result in the re-registration of the listener. This parameter defaults to an empty array.  |  
| `storeOrStoreId?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to register the listener with: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| returns  | `void`  | This has no return value.  |  
Unlike the addWillFinisTransactionListener method, which returns a listener [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and requires you to remove it manually, the `useWillFinishTransactionListener` hook manages this lifecycle for you: when the listener changes (per its `listenerDeps` dependencies) or the component unmounts, the listener on the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) will be deleted.
## Example
This example uses the `useWillFinishTransactionListener` hook to create a listener that is scoped to a single component. When the component is unmounted, the listener is removed from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {
  Provider,
  useWillFinishTransactionListener,
} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => {
  useWillFinishTransactionListener[](https://tinybase.org/api/ui-react/functions/store-hooks/usewillfinishtransactionlistener/)(() =>
    console.log('Will finish transaction'),
  );
  return <span>App</span>;
};

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const app = document.createElement('div');
const root = createRoot(app);
root.render(<App store={store} />);
console.log(store.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().transaction);
// -> 1

store.setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('open', false);
// -> 'Will finish transaction'

root.unmount();
console.log(store.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().transaction);
// -> 0

```
