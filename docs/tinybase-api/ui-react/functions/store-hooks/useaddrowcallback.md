# `useAddRowCallback`
The `useAddRowCallback` hook returns a parameterized callback that can be used to create a new [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
useAddRowCallback[](https://tinybase.org/api/ui-react/functions/store-hooks/useaddrowcallback/)<Parameter>(
  tableId: string | GetId[](https://tinybase.org/api/ui-react/type-aliases/identity/getid/)<Parameter>,
  getRow: (parameter: Parameter, store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)) => Row[](https://tinybase.org/api/store/type-aliases/store/row/),
  getRowDeps?: DependencyList,
  storeOrStoreId?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/),
  then?: (rowId: undefined | string, store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/), row: Row[](https://tinybase.org/api/store/type-aliases/store/row/)) => void,
  thenDeps?: DependencyList,
  reuseRowIds?: boolean,
): ParameterizedCallback[](https://tinybase.org/api/common/type-aliases/callback/parameterizedcallback/)<Parameter>
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableId`  | `string | GetId[](https://tinybase.org/api/ui-react/type-aliases/identity/getid/)<Parameter>`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or a [`GetId`](https://tinybase.org/api/ui-react/type-aliases/identity/getid/) function that will return it.  |  
| `getRow`  | `(parameter: Parameter, store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)) => Row[](https://tinybase.org/api/store/type-aliases/store/row/)`  | A function which returns the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) object that will be used to update the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), based on the parameter the callback will receive (and which is most likely a DOM event).  |  
| `getRowDeps?`  | `DependencyList`  | An optional array of dependencies for the `getRow` function, which, if any change, result in the regeneration of the callback. This parameter defaults to an empty array. Also use this to indicate the dependencies of a [`GetId`](https://tinybase.org/api/ui-react/type-aliases/identity/getid/) function if used as the tableId argument.  |  
| `storeOrStoreId?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be updated: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| `then?`  | `(rowId: undefined | string, store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/), row: Row[](https://tinybase.org/api/store/type-aliases/store/row/)) => void`  | A function which is called after the mutation, with the new [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) used in the update.  |  
| `thenDeps?`  | `DependencyList`  | An optional array of dependencies for the `then` function, which, if any change, result in the regeneration of the callback. This parameter defaults to an empty array.  |  
| `reuseRowIds?`  | `boolean`  | Whether [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) should be recycled from previously deleted [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects, defaulting to `true`.  |  
| returns  | `ParameterizedCallback[](https://tinybase.org/api/common/type-aliases/callback/parameterizedcallback/)<Parameter>`  | A parameterized callback for subsequent use.  |  
This hook is useful, for example, when creating an event handler that will mutate the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). In this case, the parameter will likely be the event, so that you can use data from it as part of the mutation.
The second parameter is a function which will produce the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) object that will then be used to update the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) in the callback.
If that function has any other dependencies, the changing of which should also cause the callback to be recreated, you can provide them in an array in the optional third parameter, just as you would for any React hook with dependencies.
For convenience, you can optionally provide a `then` function (with its own set of dependencies) which will be called just after the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) has been updated. This is a useful place to call the [`addCheckpoint`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/methods/setter/addcheckpoint/) method, for example, if you wish to add the mutation to your application's undo stack.
The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to which the callback will make the mutation (indicated by the hook's `storeOrStoreId` parameter) is always automatically used as a hook dependency for the callback.
The `reuseRowIds` parameter defaults to `true`, which means that if you delete a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) and then add another, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) will be re-used - unless you delete the entire [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), in which case all [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will reset. Otherwise, if you specify `reuseRowIds` to be `false`, then the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) will be a monotonically increasing string representation of an increasing integer, regardless of any you may have previously deleted.
## Example
This example uses the `useAddRowCallback` hook to create an event handler which updates the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) when the `span` element is clicked.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {useAddRowCallback, useTable} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'nemo', {species: 'fish'});
const App = () => {
  const handleClick = useAddRowCallback[](https://tinybase.org/api/ui-react/functions/store-hooks/useaddrowcallback/)(
    'pets',
    (e) => ({species: 'frog', bubbles: e.bubbles}),
    [],
    store,
    (rowId) => console.log(`Added row: ${rowId}`),
  );
  return (
    <span id="span" onClick={handleClick}>
      {JSON.stringify(useTable[](https://tinybase.org/api/ui-react/functions/store-hooks/usetable/)('pets', store))}
    </span>
  );
};

const app = document.createElement('div');
createRoot(app).render(<App />);
const span = app.querySelector('span');
console.log(span.innerHTML);
// -> '{"nemo":{"species":"fish"}}'

// User clicks the <span> element:
// -> span MouseEvent('click', {bubbles: true})
// -> 'Added row: 0'

console.log(span.innerHTML);
// -> '{"0":{"species":"frog","bubbles":true},"nemo":{"species":"fish"}}'

```
