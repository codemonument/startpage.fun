# `useProvideStore`
The `useProvideStore` hook is used to add a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) object by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component, but imperatively from a component within it.

```
useProvideStore[](https://tinybase.org/api/ui-react/functions/store-hooks/useprovidestore/)(
  storeId: string,
  store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `storeId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) object to be registered with the Provider.  |  
| `store`  | `Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) object to be registered.  |  
| returns  | `void`  | This has no return value.  |  
Normally you will register a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in a context by using the `storesById` prop of the top-level [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component. This hook, however, lets you dynamically add a new [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to the context, from within a descendent component. This is useful for applications where the set of Stores is not known at the time of the first render of the root Provider.
A [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) added to the Provider context in this way will be available to other components within the context (using the [`useStore`](https://tinybase.org/api/ui-react/functions/store-hooks/usestore/) hook and so on). If you use the same [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as an existing [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) registration, the new one will take priority over one provided by the `storesById` prop.
Note that other components that consume a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) registered like this should defend against it being undefined at first. On the first render, the other component will likely not yet have completed the registration. In the example below, we use the null-safe `useStore('petStore')?` to do this.
## Example
This example creates a Provider context. A child component registers a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) into it which is then consumable by a peer child component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {
  Provider,
  useCreateStore,
  useProvideStore,
  useStore,
} from 'tinybase/ui-react';

const App = () => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
    <RegisterStore />
    <ConsumeStore />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const RegisterStore = () => {
  const store = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(() =>
    createStore[](https://tinybase.org/api/store/functions/creation/createstore/)().setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'brown'),
  );
  useProvideStore[](https://tinybase.org/api/ui-react/functions/store-hooks/useprovidestore/)('petStore', store);
  return null;
};
const ConsumeStore = () => (
  <span>{JSON.stringify(useStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usestore/)('petStore')?.getTableIds[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettableids/)())}</span>
);

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App />);
console.log(app.innerHTML);
// -> '<span>["pets"]</span>'

```
