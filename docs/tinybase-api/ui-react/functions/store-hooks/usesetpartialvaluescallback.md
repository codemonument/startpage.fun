# `useSetPartialValuesCallback`
The `useSetPartialValuesCallback` hook returns a parameterized callback that can be used to set partial [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), leaving other [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) unaffected.

```
useSetPartialValuesCallback[](https://tinybase.org/api/ui-react/functions/store-hooks/usesetpartialvaluescallback/)<Parameter>(
  getPartialValues: (parameter: Parameter, store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)) => Values[](https://tinybase.org/api/store/type-aliases/store/values/),
  getPartialValuesDeps?: DependencyList,
  storeOrStoreId?: StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/),
  then?: (store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/), partialValues: Values[](https://tinybase.org/api/store/type-aliases/store/values/)) => void,
  thenDeps?: DependencyList,
): ParameterizedCallback[](https://tinybase.org/api/common/type-aliases/callback/parameterizedcallback/)<Parameter>
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `getPartialValues`  | `(parameter: Parameter, store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)) => Values[](https://tinybase.org/api/store/type-aliases/store/values/)`  | A function which returns the partial [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) object that will be used to update the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), based on the parameter the callback will receive (and which is most likely a DOM event).  |  
| `getPartialValuesDeps?`  | `DependencyList`  | An optional array of dependencies for the `getValues` function, which, if any change, result in the regeneration of the callback. This parameter defaults to an empty array.  |  
| `storeOrStoreId?`  | `StoreOrStoreId[](https://tinybase.org/api/ui-react/type-aliases/identity/storeorstoreid/)`  | The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to be updated: omit for the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or provide an explicit reference.  |  
| `then?`  | `(store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/), partialValues: Values[](https://tinybase.org/api/store/type-aliases/store/values/)) => void`  | A function which is called after the mutation, with a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) used in the update.  |  
| `thenDeps?`  | `DependencyList`  | An optional array of dependencies for the `then` function, which, if any change, result in the regeneration of the callback. This parameter defaults to an empty array.  |  
| returns  | `ParameterizedCallback[](https://tinybase.org/api/common/type-aliases/callback/parameterizedcallback/)<Parameter>`  | A parameterized callback for subsequent use.  |  
This hook is useful, for example, when creating an event handler that will mutate the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). In this case, the parameter will likely be the event, so that you can use data from it as part of the mutation.
The third parameter is a function which will produce the partial [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) object that will then be used to update the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) in the callback.
If that function has any other dependencies, the changing of which should also cause the callback to be recreated, you can provide them in an array in the optional fourth parameter, just as you would for any React hook with dependencies.
For convenience, you can optionally provide a `then` function (with its own set of dependencies) which will be called just after the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) has been updated. This is a useful place to call the [`addCheckpoint`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/methods/setter/addcheckpoint/) method, for example, if you wish to add the mutation to your application's undo stack.
The [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to which the callback will make the mutation (indicated by the hook's `storeOrStoreId` parameter) is always automatically used as a hook dependency for the callback.
## Example
This example uses the `useSetPartialValuesCallback` hook to create an event handler which updates the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) when the `span` element is clicked.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {useSetPartialValuesCallback, useValues} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({open: true});
const App = () => {
  const handleClick = useSetPartialValuesCallback[](https://tinybase.org/api/ui-react/functions/store-hooks/usesetpartialvaluescallback/)(
    (e) => ({bubbles: e.bubbles}),
    [],
    store,
    (store, partialValues) =>
      console.log(`Updated: ${JSON.stringify(partialValues)}`),
  );
  return (
    <span id="span" onClick={handleClick}>
      {JSON.stringify(useValues[](https://tinybase.org/api/ui-react/functions/store-hooks/usevalues/)(store))}
    </span>
  );
};

const app = document.createElement('div');
createRoot(app).render(<App />);
const span = app.querySelector('span');
console.log(span.innerHTML);
// -> '{"open":true}'

// User clicks the <span> element:
// -> span MouseEvent('click', {bubbles: true})
// -> 'Updated: {"bubbles":true}'

console.log(span.innerHTML);
// -> '{"open":true,"bubbles":true}'

```
