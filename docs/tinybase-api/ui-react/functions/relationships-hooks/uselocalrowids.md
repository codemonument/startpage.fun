# `useLocalRowIds`
The `useLocalRowIds` hook gets the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for a given remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), and registers a listener so that any changes to that result will cause a re-render.

```
useLocalRowIds[](https://tinybase.org/api/ui-react/functions/relationships-hooks/uselocalrowids/)(
  relationshipId: string,
  remoteRowId: string,
  relationshipsOrRelationshipsId?: RelationshipsOrRelationshipsId[](https://tinybase.org/api/ui-react/type-aliases/identity/relationshipsorrelationshipsid/),
): Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `relationshipId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).  |  
| `remoteRowId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/).  |  
| `relationshipsOrRelationshipsId?`  | `RelationshipsOrRelationshipsId[](https://tinybase.org/api/ui-react/type-aliases/identity/relationshipsorrelationshipsid/)`  | The [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object to be accessed: omit for the default context [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, or provide an explicit reference.  |  
| returns  | `Ids[](https://tinybase.org/api/common/type-aliases/identity/ids/)`  | The local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), or an empty array.  |  
A [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component is used to wrap part of an application in a context, and it can contain a default [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object or a set of [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). The `useLocalRowIds` hook lets you indicate which [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object to get data for: omit the optional final parameter for the default context [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, or provide a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object explicitly by reference.
When first rendered, this hook will create a listener so that changes to the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) will cause a re-render. When the component containing this hook is unmounted, the listener will be automatically removed.
## Examples
This example creates a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object outside the application, which is used in the `useLocalRowIds` hook by reference. A change to the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createRelationships, createStore} from 'tinybase';
import {useLocalRowIds} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {fido: {species: 'dog'}, cujo: {species: 'dog'}})
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {wolf: {price: 10}, dog: {price: 5}});
const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(store).setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)(
  'petSpecies',
  'pets',
  'species',
  'species',
);
const App = () => (
  <span>
    {JSON.stringify(useLocalRowIds[](https://tinybase.org/api/ui-react/functions/relationships-hooks/uselocalrowids/)('petSpecies', 'dog', relationships))}
  </span>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<span>["fido","cujo"]</span>'

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'toto', {species: 'dog'});
console.log(app.innerHTML);
// -> '<span>["fido","cujo","toto"]</span>'

```

This example creates a Provider context into which a default [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object is provided. A component within it then uses the `useLocalRowIds` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createRelationships, createStore} from 'tinybase';
import {Provider, useLocalRowIds} from 'tinybase/ui-react';

const App = ({relationships}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) relationships={relationships}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => (
  <span>{JSON.stringify(useLocalRowIds[](https://tinybase.org/api/ui-react/functions/relationships-hooks/uselocalrowids/)('petSpecies', 'dog'))}</span>
);

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
    .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {fido: {species: 'dog'}, cujo: {species: 'dog'}})
    .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {wolf: {price: 10}, dog: {price: 5}}),
).setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)('petSpecies', 'pets', 'species', 'species');

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App relationships={relationships} />);
console.log(app.innerHTML);
// -> '<span>["fido","cujo"]</span>'

```

This example creates a Provider context into which a default [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object is provided. A component within it then uses the `useLocalRowIds` hook.

```
import React from 'react';
import {createRoot} from 'react-dom/client';

const App = ({relationships}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) relationshipsById={{petRelationships: relationships}}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => (
  <span>
    {JSON.stringify(
      useLocalRowIds[](https://tinybase.org/api/ui-react/functions/relationships-hooks/uselocalrowids/)('petSpecies', 'dog', 'petRelationships'),
    )}
  </span>
);

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
    .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {fido: {species: 'dog'}, cujo: {species: 'dog'}})

).setRelationshipDefinition[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/configuration/setrelationshipdefinition/)('petSpecies', 'pets', 'species', 'species');

const app = document.createElement('div');
```
