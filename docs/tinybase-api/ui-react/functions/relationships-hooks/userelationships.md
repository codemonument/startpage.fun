# `useRelationships`
The `useRelationships` hook is used to get a reference to a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object from within a [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component context.

```
useRelationships[](https://tinybase.org/api/ui-react/functions/relationships-hooks/userelationships/)(id?: string): Relationships[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `id?`  | `string`  | An optional [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for accessing a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object that was named with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in the Provider.  |  
| returns  | `Relationships[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) | undefined`  | A reference to the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object (or `undefined` if not within a Provider context, or if the requested [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object does not exist).  |  
A [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component is used to wrap part of an application in a context. It can contain a default [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object (or a set of [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) that can be easily accessed without having to be passed down as props through every component.
The `useRelationships` hook lets you either get a reference to the default [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object (when called without a parameter), or one of the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) objects that are named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) (when called with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) parameter).
## Examples
This example creates a Provider context into which a default [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object is provided. A component within it then uses the `useRelationships` hook to get a reference to the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object again, without the need to have it passed as a prop.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createRelationships, createStore} from 'tinybase';
import {Provider, useRelationships} from 'tinybase/ui-react';

const App = ({relationships}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) relationships={relationships}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => (
  <span>{useRelationships[](https://tinybase.org/api/ui-react/functions/relationships-hooks/userelationships/)().getListenerStats[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/development/getlistenerstats/)().remoteRowId}</span>
);

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)());
const app = document.createElement('div');
const root = createRoot(app);
root.render(<App relationships={relationships} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```

This example creates a Provider context into which a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object is provided, named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). A component within it then uses the `useRelationships` hook with that [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to get a reference to the [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object again, without the need to have it passed as a prop.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createRelationships, createStore} from 'tinybase';
import {Provider, useRelationships} from 'tinybase/ui-react';

const App = ({relationships}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) relationshipsById={{petStore: relationships}}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => (
  <span>
    {useRelationships[](https://tinybase.org/api/ui-react/functions/relationships-hooks/userelationships/)('petStore').getListenerStats[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/methods/development/getlistenerstats/)().remoteRowId}
  </span>
);

const relationships = createRelationships[](https://tinybase.org/api/relationships/functions/creation/createrelationships/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)());
const app = document.createElement('div');
const root = createRoot(app);
root.render(<App relationships={relationships} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```
