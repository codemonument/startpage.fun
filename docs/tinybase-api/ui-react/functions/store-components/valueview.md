# `ValueView`
The `ValueView` component renders the value of a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/), and registers a listener so that any changes to that result will cause a re-render.

```
ValueView[](https://tinybase.org/api/ui-react/functions/store-components/valueview/)(props: ValueProps[](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `ValueProps[](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/)`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/), or nothing, if not present.  |  
The component's props identify which [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) to render based on [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (which is either the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or an explicit reference).
A [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) contains a string, number, or boolean, so the value is rendered directly without further decoration. You can create your own ValueView-like component to customize the way that a [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) is rendered: see the [`ValuesView`](https://tinybase.org/api/ui-react/functions/store-components/valuesview/) component for more details.
This component uses the [`useValue`](https://tinybase.org/api/ui-react/functions/store-hooks/usevalue/) hook under the covers, which means that any changes to the specified [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) will cause a re-render.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) outside the application, which is used in the `ValueView` component by reference. A change to the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {ValueView} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('open', true);
const App = () => (
  <span>
    <ValueView[](https://tinybase.org/api/ui-react/functions/store-components/valueview/) valueId="open" store={store} />
  </span>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<span>true</span>'

store.setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('open', false);
console.log(app.innerHTML);
// -> '<span>false</span>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `ValueView` component within it then renders the [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) (with its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for readability).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, ValueView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <span>
    <ValueView[](https://tinybase.org/api/ui-react/functions/store-components/valueview/) valueId="open" debugIds={true} />
  </span>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('open', true);
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<span>open:{true}</span>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `ValueView` component within it then attempts to render a non-existent [`Value`](https://tinybase.org/api/store/type-aliases/store/value/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, ValueView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <span>
    <ValueView[](https://tinybase.org/api/ui-react/functions/store-components/valueview/) valueId="website" />
  </span>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('open', true);
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<span></span>'

```
