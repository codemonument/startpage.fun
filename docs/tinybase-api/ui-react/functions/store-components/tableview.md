# `TableView`
The `TableView` component renders the contents of a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render.

```
TableView[](https://tinybase.org/api/ui-react/functions/store-components/tableview/)(props: TableProps[](https://tinybase.org/api/ui-react/type-aliases/props/tableprops/)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `TableProps[](https://tinybase.org/api/ui-react/type-aliases/props/tableprops/)`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), or nothing, if not present.  |  
The component's props identify which [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to render based on [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (which is either the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or by explicit reference).
This component renders a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) by iterating over its [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects. By default these are in turn rendered with the [`RowView`](https://tinybase.org/api/ui-react/functions/store-components/rowview/) component, but you can override this behavior by providing a `rowComponent` prop, a custom component of your own that will render a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) based on [`RowProps`](https://tinybase.org/api/ui-react/type-aliases/props/rowprops/). You can also pass additional props to your custom component with the `getRowComponentProps` callback prop.
You can create your own TableView-like component to customize the way that a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is rendered: see the [`TablesView`](https://tinybase.org/api/ui-react/functions/store-components/tablesview/) component for more details.
This component uses the [`useRowIds`](https://tinybase.org/api/ui-react/functions/store-hooks/userowids/) hook under the covers, which means that any changes to the structure of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) will cause a re-render.
Since v4.1.0, you can use the `customCellIds` prop if you want to render a prescribed set of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s Cells in a given order for each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) outside the application, which is used in the `TableView` component by reference. A change to the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {TableView} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {fido: {species: 'dog'}});
const App = () => (
  <div>
    <TableView[](https://tinybase.org/api/ui-react/functions/store-components/tableview/) tableId="pets" store={store} separator="/" />
  </div>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<div>dog</div>'

store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'felix', {species: 'cat'});
console.log(app.innerHTML);
// -> '<div>dog/cat</div>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `TableView` component within it then renders the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) for a custom set of [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) (and rendered with [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for readability).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, TableView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const customCellIds = ['species'];
const Pane = () => (
  <div>
    <TableView[](https://tinybase.org/api/ui-react/functions/store-components/tableview/)
      tableId="pets"
      customCellIds={customCellIds}
      debugIds={true}
    />
  </div>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {color: 'black', species: 'dog'},
  felix: {color: 'brown', species: 'cat'},
});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<div>pets:{fido:{species:{dog}}felix:{species:{cat}}}</div>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `TableView` component within it then renders the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) with a custom [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) component and a custom props callback.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, RowView, TableView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const getBoldProp = (rowId) => ({bold: rowId == 'fido'});
const Pane = () => (
  <div>
    <TableView[](https://tinybase.org/api/ui-react/functions/store-components/tableview/)
      tableId="pets"
      rowComponent={FormattedRowView}
      getRowComponentProps={getBoldProp}
    />
  </div>
);
const FormattedRowView = ({tableId, rowId, bold}) => (
  <span>
    {bold ? <b>{rowId}</b> : rowId}
    {': '}
    <RowView[](https://tinybase.org/api/ui-react/functions/store-components/rowview/) tableId={tableId} rowId={rowId} />
  </span>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog'},
  felix: {species: 'cat'},
});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<div><span><b>fido</b>: dog</span><span>felix: cat</span></div>'

```
