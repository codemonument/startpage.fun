# `TablesView`
The `TablesView` component renders the tabular contents of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render.

```
TablesView[](https://tinybase.org/api/ui-react/functions/store-components/tablesview/)(props: TablesProps[](https://tinybase.org/api/ui-react/type-aliases/props/tablesprops/)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `TablesProps[](https://tinybase.org/api/ui-react/type-aliases/props/tablesprops/)`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or nothing, if not present.  |  
The component's props can identify which [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to render - either the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or an explicit reference.
This component renders a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) by iterating over its [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) objects. By default these are in turn rendered with the [`TableView`](https://tinybase.org/api/ui-react/functions/store-components/tableview/) component, but you can override this behavior by providing a `tableComponent` prop, a custom component of your own that will render a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) based on [`TableProps`](https://tinybase.org/api/ui-react/type-aliases/props/tableprops/). You can also pass additional props to your custom component with the `getTableComponentProps` callback prop.
This component uses the [`useTableIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usetableids/) hook under the covers, which means that any changes to the structure of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) will cause a re-render.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) outside the application, which is used in the `TablesView` component by reference. A change to the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {TablesView} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({pets: {fido: {species: 'dog'}}});
const App = () => (
  <div>
    <TablesView[](https://tinybase.org/api/ui-react/functions/store-components/tablesview/) store={store} separator="/" />
  </div>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<div>dog</div>'

store.setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {dog: {price: 5}});
console.log(app.innerHTML);
// -> '<div>dog/5</div>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `TablesView` component within it then renders the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) (with [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for readability).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, TablesView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <div>
    <TablesView[](https://tinybase.org/api/ui-react/functions/store-components/tablesview/) debugIds={true} />
  </div>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog'}},
  species: {dog: {price: 5}},
});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<div>pets:{fido:{species:{dog}}}species:{dog:{price:{5}}}</div>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `TablesView` component within it then renders the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with a custom [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) component and a custom props callback.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, TableView, TablesView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const getBoldProp = (tableId) => ({bold: tableId == 'pets'});
const Pane = () => (
  <div>
    <TablesView[](https://tinybase.org/api/ui-react/functions/store-components/tablesview/)
      tableComponent={FormattedTableView}
      getTableComponentProps={getBoldProp}
    />
  </div>
);
const FormattedTableView = ({tableId, bold}) => (
  <span>
    {bold ? <b>{tableId}</b> : tableId}
    {': '}
    <TableView[](https://tinybase.org/api/ui-react/functions/store-components/tableview/) tableId={tableId} />
  </span>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({
  pets: {fido: {species: 'dog'}},
  species: {dog: {price: 5}},
});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<div><span><b>pets</b>: dog</span><span>species: 5</span></div>'

```
