# `ValuesView`
The `ValuesView` component renders the keyed value contents of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render.

```
ValuesView[](https://tinybase.org/api/ui-react/functions/store-components/valuesview/)(props: ValuesProps[](https://tinybase.org/api/ui-react/type-aliases/props/valuesprops/)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `ValuesProps[](https://tinybase.org/api/ui-react/type-aliases/props/valuesprops/)`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/), or nothing, if not present.  |  
The component's props can identify which [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) to render - either the default context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), a named context [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), or an explicit reference.
This component renders a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) by iterating over its [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) objects. By default these are in turn rendered with the [`ValueView`](https://tinybase.org/api/ui-react/functions/store-components/valueview/) component, but you can override this behavior by providing a `valueComponent` prop, a custom component of your own that will render a [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) based on [`ValueProps`](https://tinybase.org/api/ui-react/type-aliases/props/valueprops/). You can also pass additional props to your custom component with the `getValueComponentProps` callback prop.
This component uses the [`useValueIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usevalueids/) hook under the covers, which means that any changes to the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) will cause a re-render.
This component uses the [`useValueIds`](https://tinybase.org/api/ui-react/functions/store-hooks/usevalueids/) hook under the covers, which means that any changes to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/)'s [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) will cause a re-render.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) outside the application, which is used in the `ValuesView` component by reference. A change to the data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {ValuesView} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('open', true);
const App = () => (
  <div>
    <ValuesView[](https://tinybase.org/api/ui-react/functions/store-components/valuesview/) store={store} separator="/" />
  </div>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<div>true</div>'

store.setValue[](https://tinybase.org/api/the-essentials/setting-data/setvalue/)('employees', 3);
console.log(app.innerHTML);
// -> '<div>true/3</div>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `ValuesView` component within it then renders the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) (with [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for readability).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, ValuesView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <div>
    <ValuesView[](https://tinybase.org/api/ui-react/functions/store-components/valuesview/) debugIds={true} />
  </div>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({open: true, employees: 3});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<div>open:{true}employees:{3}</div>'

```

This example creates a Provider context into which a default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is provided. The `ValuesView` component within it then renders the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) with a custom [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) component and a custom props callback.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createStore} from 'tinybase';
import {Provider, ValueView, ValuesView} from 'tinybase/ui-react';

const App = ({store}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) store={store}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const getBoldProp = (valueId) => ({bold: valueId == 'open'});
const Pane = () => (
  <div>
    <ValuesView[](https://tinybase.org/api/ui-react/functions/store-components/valuesview/)
      valueComponent={FormattedValueView}
      getValueComponentProps={getBoldProp}
    />
  </div>
);
const FormattedValueView = ({valueId, bold}) => (
  <span>
    {bold ? <b>{valueId}</b> : valueId}
    {': '}
    <ValueView[](https://tinybase.org/api/ui-react/functions/store-components/valueview/) valueId={valueId} />
  </span>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/setvalues/)({open: true, employees: 3});
const app = document.createElement('div');
createRoot(app).render(<App store={store} />);
console.log(app.innerHTML);
// -> '<div><span><b>open</b>: true</span><span>employees: 3</span></div>'

```
