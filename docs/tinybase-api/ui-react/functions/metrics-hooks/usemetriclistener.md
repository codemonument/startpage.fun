# `useMetricListener`
The `useMetricListener` hook registers a listener function with the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object that will be called whenever the value of a specified [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) changes.

```
useMetricListener[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetriclistener/)(
  metricId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: MetricListener[](https://tinybase.org/api/metrics/type-aliases/listener/metriclistener/),
  listenerDeps?: DependencyList,
  metricsOrMetricsId?: MetricsOrMetricsId[](https://tinybase.org/api/ui-react/type-aliases/identity/metricsormetricsid/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `metricId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `MetricListener[](https://tinybase.org/api/metrics/type-aliases/listener/metriclistener/)`  | The function that will be called whenever the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) changes.  |  
| `listenerDeps?`  | `DependencyList`  | An optional array of dependencies for the `listener` function, which, if any change, result in the re-registration of the listener. This parameter defaults to an empty array.  |  
| `metricsOrMetricsId?`  | `MetricsOrMetricsId[](https://tinybase.org/api/ui-react/type-aliases/identity/metricsormetricsid/)`  | The [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object to register the listener with: omit for the default context [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, or provide an explicit reference.  |  
| returns  | `void`  | This has no return value.  |  
This hook is useful for situations where a component needs to register its own specific listener to do more than simply tracking the value (which is more easily done with the [`useMetric`](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetric/) hook).
You can either listen to a single [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) (by specifying the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first parameter), or changes to any [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) (by providing a `null` wildcard).
Unlike the [`addMetricListener`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/listener/addmetriclistener/) method, which returns a listener [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and requires you to remove it manually, the `useMetricListener` hook manages this lifecycle for you: when the listener changes (per its `listenerDeps` dependencies) or the component unmounts, the listener on the underlying [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, will be deleted.
## Example
This example uses the `useMetricListener` hook to create a listener that is scoped to a single component. When the component is unmounted, the listener is removed from the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {Provider, useMetricListener} from 'tinybase/ui-react';

const App = ({metrics}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) metrics={metrics}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => {
  useMetricListener[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetriclistener/)('highestPrice', () => console.log('Metric changed'));
  return <span>App</span>;
};

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});
const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App metrics={metrics} />);
console.log(metrics.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().metric);
// -> 1

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('species', 'horse', 'price', 20);
// -> 'Metric changed'

root.unmount();
console.log(metrics.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().metric);
// -> 0

```
