# `useMetricsOrMetricsById`
The `useMetricsOrMetricsById` hook is used to get a reference to a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object from within a [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component context, _or_ have it passed directly to this hook.

```
useMetricsOrMetricsById[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetricsormetricsbyid/)(metricsOrMetricsId?: MetricsOrMetricsId[](https://tinybase.org/api/ui-react/type-aliases/identity/metricsormetricsid/)): Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `metricsOrMetricsId?`  | `MetricsOrMetricsId[](https://tinybase.org/api/ui-react/type-aliases/identity/metricsormetricsid/)`  | Either an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for accessing a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object that was named with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in the Provider, or the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object itself.  |  
| returns  | `Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) | undefined`  | A reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object (or `undefined` if not within a Provider context, or if the requested [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object does not exist).  |  
This is mostly of use when you are developing a component that needs a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object and which might have been passed in explicitly to the component or is to be picked up from the context by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) (a common pattern for [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/)-based components).
This hook is unlikely to be used often. For most situations, you will want to use the [`useMetrics`](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetrics/) hook.
## Example
This example creates a Provider context into which a default [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object is provided. A component within it then uses the `useMetricsOrMetricsById` hook to get a reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object again, without the need to have it passed as a prop. Note however, that unlike the [`useMetrics`](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetrics/) hook example, this component would also work if you were to pass the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object directly into it, making it more portable.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {Provider, useMetricsOrMetricsById} from 'tinybase/ui-react';

const App = ({metrics}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) metrics={metrics}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = ({metrics}) => (
  <span>
    {JSON.stringify(useMetricsOrMetricsById[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetricsormetricsbyid/)(metrics).getMetricIds[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetricids/)())}
  </span>
);

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(
  createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    dog: {price: 5},
    cat: {price: 4},
    worm: {price: 1},
  }),
).setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App metrics={metrics} />);
console.log(app.innerHTML);
// -> '<span>["highestPrice"]</span>'

```
