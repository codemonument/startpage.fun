# `useCreateMetrics`
The `useCreateMetrics` hook is used to create a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object within a React application with convenient memoization.

```
useCreateMetrics[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usecreatemetrics/)(
  store: undefined | Store[](https://tinybase.org/api/the-essentials/creating-stores/store/),
  create: (store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)) => Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/),
  createDeps?: DependencyList,
): Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `store`  | `undefined | Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)`  | A reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) for which to create a new [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object.  |  
| `create`  | `(store: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)) => Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/)`  | A function for performing the creation steps of the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object for the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), plus any additional steps such as adding definitions or listeners, and returning it.  |  
| `createDeps?`  | `DependencyList`  | An optional array of dependencies for the `create` function, which, if any change, result in its rerun. This parameter defaults to an empty array.  |  
| returns  | `Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) | undefined`  | A reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object.  |  
It is possible to create a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object outside of the React app with the regular [`createMetrics`](https://tinybase.org/api/metrics/functions/creation/createmetrics/) function and pass it in, but you may prefer to create it within the app, perhaps inside the top-level component. To prevent a new [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object being created every time the app renders or re-renders, since v5.0 this hook performs the creation in an effect. As a result it will return `undefined` on the brief first render (or if the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) is not yet defined), which you should defend against.
If your `create` function contains other dependencies, the changing of which should also cause the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object to be recreated, you can provide them in an array in the optional second parameter, just as you would for any React hook with dependencies.
This hook ensures the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object is destroyed whenever a new one is created or the component is unmounted.
## Examples
This example creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object at the top level of a React application. Even though the App component is rendered twice, the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object creation only occurs once by default.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {useCreateMetrics, useCreateStore} from 'tinybase/ui-react';

const App = () => {
  const store = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(() =>
    createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {dog: {price: 5}, cat: {price: 4}}),
  );
  const metrics = useCreateMetrics[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usecreatemetrics/)(store, (store) => {
    console.log('Metrics created');
    return createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store).setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)(
      'speciesCount',
      'species',
    );
  });
  return <span>{metrics?.getMetric[](https://tinybase.org/api/ui-svelte/functions/getter/getmetric/)('speciesCount')}</span>;
};

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App />);
// -> 'Metrics created'

root.render(<App />);
// No second Metrics creation

console.log(app.innerHTML);
// -> '<span>2</span>'

```

This example creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object at the top level of a React application. The App component is rendered twice, each with a different top-level prop. The `useCreateMetrics` hook takes the tableToCount prop as a dependency, and so the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object is created again on the second render.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {useCreateMetrics, useCreateStore} from 'tinybase/ui-react';

const App = ({tableToCount}) => {
  const store = useCreateStore[](https://tinybase.org/api/ui-react/functions/store-hooks/usecreatestore/)(() =>
    createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
      .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {fido: {species: 'dog'}})
      .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {dog: {price: 5}, cat: {price: 4}}),
  );
  const metrics = useCreateMetrics[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usecreatemetrics/)(
    store,
    (store) => {
      console.log(`Count created for ${tableToCount} table`);
      return createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store).setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)(
        'tableCount',
        tableToCount,
      );
    },
    [tableToCount],
  );
  return <span>{metrics?.getMetric[](https://tinybase.org/api/ui-svelte/functions/getter/getmetric/)('tableCount')}</span>;
};

const app = document.createElement('div');
const root = createRoot(app);
root.render(<App tableToCount="pets" />);
// -> 'Count created for pets table'

console.log(app.innerHTML);
// -> '<span>1</span>'

root.render(<App tableToCount="species" />);
// -> 'Count created for species table'

console.log(app.innerHTML);
// -> '<span>2</span>'

```
