# `useMetrics`
The `useMetrics` hook is used to get a reference to a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object from within a [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component context.

```
useMetrics[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetrics/)(id?: string): Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `id?`  | `string`  | An optional [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for accessing a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object that was named with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in the Provider.  |  
| returns  | `Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) | undefined`  | A reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object (or `undefined` if not within a Provider context, or if the requested [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object does not exist).  |  
A [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component is used to wrap part of an application in a context. It can contain a default [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object (or a set of [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) objects named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) that can be easily accessed without having to be passed down as props through every component.
The `useMetrics` hook lets you either get a reference to the default [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object (when called without a parameter), or one of the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) objects that are named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) (when called with an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) parameter).
## Examples
This example creates a Provider context into which a default [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object is provided. A component within it then uses the `useMetrics` hook to get a reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object again, without the need to have it passed as a prop.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {Provider, useMetrics} from 'tinybase/ui-react';

const App = ({metrics}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) metrics={metrics}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => <span>{useMetrics[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetrics/)().getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().metric}</span>;

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)());
const app = document.createElement('div');
createRoot(app).render(<App metrics={metrics} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```

This example creates a Provider context into which a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object is provided, named by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). A component within it then uses the `useMetrics` hook with that [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to get a reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object again, without the need to have it passed as a prop.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {Provider, useMetrics} from 'tinybase/ui-react';

const App = ({metrics}) => (
  <Provider[](https://tinybase.org/api/the-essentials/using-react/provider/) metricsById={{petStore: metrics}}>
    <Pane />
  </Provider[](https://tinybase.org/api/the-essentials/using-react/provider/)>
);
const Pane = () => (
  <span>{useMetrics[](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetrics/)('petStore').getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().metric}</span>
);

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)());
const app = document.createElement('div');
createRoot(app).render(<App metrics={metrics} />);
console.log(app.innerHTML);
// -> '<span>0</span>'

```
