# `MetricView`
The `MetricView` component renders the current value of a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/), and registers a listener so that any changes to that result will cause a re-render.

```
MetricView[](https://tinybase.org/api/ui-react/functions/metrics-components/metricview/)(props: MetricProps[](https://tinybase.org/api/ui-react/type-aliases/props/metricprops/)): ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `props`  | `MetricProps[](https://tinybase.org/api/ui-react/type-aliases/props/metricprops/)`  | The props for this component.  |  
| returns  | `ComponentReturnType[](https://tinybase.org/api/ui-react/type-aliases/component/componentreturntype/)`  | A rendering of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/), or nothing, if not present.  |  
The component's props can identify which [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object to get data for: omit the optional final parameter for the default context [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, or by explicit reference.
This component uses the [`useMetric`](https://tinybase.org/api/ui-react/functions/metrics-hooks/usemetric/) hook under the covers, which means that any changes to the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) will cause a re-render.
## Examples
This example creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object outside the application, which is used in the `MetricView` component hook by reference. A change to the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) re-renders the component.

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {MetricView} from 'tinybase/ui-react';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});
const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');
const App = () => (
  <div>
    <MetricView[](https://tinybase.org/api/ui-react/functions/metrics-components/metricview/) metricId="highestPrice" metrics={metrics} />
  </div>
);

const app = document.createElement('div');
createRoot(app).render(<App />);
console.log(app.innerHTML);
// -> '<div>5</div>'

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('species', 'horse', 'price', 20);
console.log(app.innerHTML);
// -> '<div>20</div>'

```

This example creates a Provider context into which a default [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object is provided. The `MetricView` component within it then renders the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) (with its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for readability).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {MetricView, Provider} from 'tinybase/ui-react';

const App = ({metrics}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) metrics={metrics}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <div>
    <MetricView[](https://tinybase.org/api/ui-react/functions/metrics-components/metricview/) metricId="highestPrice" debugIds={true} />
  </div>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});
const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');

const app = document.createElement('div');
createRoot(app).render(<App metrics={metrics} />);
console.log(app.innerHTML);
// -> '<div>highestPrice:{5}</div>'

```

This example creates a Provider context into which a default [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object is provided. The `MetricView` component within it then attempts to render a non-existent [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).

```
import React from 'react';
import {createRoot} from 'react-dom/client';
import {createMetrics, createStore} from 'tinybase';
import {MetricView, Provider} from 'tinybase/ui-react';

const App = ({metrics}) => (
  <Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/) metrics={metrics}>
    <Pane />
  </Provider[](https://tinybase.org/api/ui-react/functions/context-components/provider/)>
);
const Pane = () => (
  <div>
    <MetricView[](https://tinybase.org/api/ui-react/functions/metrics-components/metricview/) metricId="lowestPrice" />
  </div>
);

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});
const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');

const app = document.createElement('div');
createRoot(app).render(<App metrics={metrics} />);
console.log(app.innerHTML);
// -> '<div></div>'

```
