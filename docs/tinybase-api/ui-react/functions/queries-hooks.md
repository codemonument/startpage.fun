# Queries hooks
## `useResultTable`
The [`useResultTable`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttable/) hook returns an object containing the entire data of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttable/).
## `useResultTableCellIds`
The [`useResultTableCellIds`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttablecellids/) hook returns the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of every [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) used across the whole [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to those [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttablecellids/).
## `useResultTableCellIdsListener`
The [`useResultTableCellIdsListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttablecellidslistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that appear anywhere in a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) change. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttablecellidslistener/).
## `useResultTableListener`
The [`useResultTableListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttablelistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever data in a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) changes. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresulttablelistener/).
## `useResultRowIds`
The [`useResultRowIds`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowids/) hook returns the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of every [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to those [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowids/).
## `useResultRowIdsListener`
The [`useResultRowIdsListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowidslistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) change. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowidslistener/).
## `useResultSortedRowIds`
The [`useResultSortedRowIds`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultsortedrowids/) hook returns the sorted (and optionally, paginated) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of every [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to those [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultsortedrowids/).
## `useResultSortedRowIdsListener`
The [`useResultSortedRowIdsListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultsortedrowidslistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever the sorted (and optionally, paginated) [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) change. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultsortedrowidslistener/).
## `useResultRow`
The [`useResultRow`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrow/) hook returns an object containing the data of a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to that [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrow/).
## `useResultRowCount`
The [`useResultRowCount`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowcount/) hook returns the count of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects in the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowcount/).
## `useResultRowCountListener`
The [`useResultRowCountListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowcountlistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever the count of [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) objects in a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) changes. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowcountlistener/).
## `useResultRowListener`
The [`useResultRowListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowlistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever data in a result [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) changes. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultrowlistener/).
## `useResultCellIds`
The [`useResultCellIds`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcellids/) hook returns the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of every [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a given [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to those [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcellids/).
## `useResultCellIdsListener`
The [`useResultCellIdsListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcellidslistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a result [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) change. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcellidslistener/).
## `useResultCell`
The [`useResultCell`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcell/) hook returns the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a given [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) of the given query, and registers a listener so that any changes to that value will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcell/).
## `useResultCellListener`
The [`useResultCellListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcelllistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever data in a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) changes. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useresultcelllistener/).
## `useParamValues`
The [`useParamValues`](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvalues/) hook returns an object containing all the parameter values currently set for a query. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvalues/).
## `useParamValuesListener`
The [`useParamValuesListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvalueslistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever the parameter values for a query change. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvalueslistener/).
## `useSetParamValuesCallback`
The [`useSetParamValuesCallback`](https://tinybase.org/api/ui-react/functions/queries-hooks/usesetparamvaluescallback/) hook returns a parameterized callback that can be used to set multiple parameter values for a query at once. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/usesetparamvaluescallback/).
## `useParamValue`
The [`useParamValue`](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvalue/) hook returns the current value of a single parameter in a query. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvalue/).
## `useParamValueListener`
The [`useParamValueListener`](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvaluelistener/) hook registers a listener function with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever a single parameter value for a query changes. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useparamvaluelistener/).
## `useSetParamValueCallback`
The [`useSetParamValueCallback`](https://tinybase.org/api/ui-react/functions/queries-hooks/usesetparamvaluecallback/) hook returns a parameterized callback that can be used to set a single parameter value for a query. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/usesetparamvaluecallback/).
## `useCreateQueries`
The [`useCreateQueries`](https://tinybase.org/api/ui-react/functions/queries-hooks/usecreatequeries/) hook is used to create a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object within a React application with convenient memoization. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/usecreatequeries/).
## `useProvideQueries`
The [`useProvideQueries`](https://tinybase.org/api/ui-react/functions/queries-hooks/useprovidequeries/) hook is used to add a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object by [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) to a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component, but imperatively from a component within it. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/useprovidequeries/).
## `useQueries`
The [`useQueries`](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeries/) hook is used to get a reference to a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeries/).
## `useQueriesIds`
The [`useQueriesIds`](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeriesids/) hook is used to retrieve the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all the named [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) objects present in the current [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeriesids/).
## `useQueriesOrQueriesById`
The [`useQueriesOrQueriesById`](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeriesorqueriesbyid/) hook is used to get a reference to a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object from within a [`Provider`](https://tinybase.org/api/ui-react/functions/context-components/provider/) component context, _or_ have it passed directly to this hook. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeriesorqueriesbyid/).
## `useQueryIds`
The [`useQueryIds`](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeryids/) hook gets an array of the Query [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) registered with a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-react/functions/queries-hooks/usequeryids/).
