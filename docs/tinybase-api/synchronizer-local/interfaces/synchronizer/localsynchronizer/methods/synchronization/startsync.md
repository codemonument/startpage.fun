# `startSync`
The `startSync` method is used to start the process of synchronization between this instance and another matching [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/).

```
startSync[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/synchronization/startsync/)(initialContent?: Content[](https://tinybase.org/api/store/type-aliases/store/content/)): Promise<LocalSynchronizer[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/)>
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `initialContent?`  | `Content[](https://tinybase.org/api/store/type-aliases/store/content/)`  | An optional [`Content`](https://tinybase.org/api/store/type-aliases/store/content/) object used when no content is available from another other peer [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) instances.  |  
| returns  | `Promise<LocalSynchronizer[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/)>`  | A Promise containing a reference to the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) object.  |  
The underlying implementation of a [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) is shared with the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) framework, and so this `startSync` method is equivalent to starting both auto-loading (listening to sync messages from other active [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) instances) and auto-saving (sending sync messages to it).
This method is asynchronous so you should you `await` calls to this method or handle the return type natively as a Promise.
## Examples
This example creates two empty [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) objects, creates a [`LocalSynchronizer`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/) for each, and starts synchronizing them. A change in one becomes evident in the other.

```
import {createMergeableStore} from 'tinybase';
import {createLocalSynchronizer} from 'tinybase/synchronizers/synchronizer-local';

const store1 = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)();
const store2 = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)();

const synchronizer1 = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(store1);
const synchronizer2 = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(store2);

await synchronizer1.startSync[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/synchronization/startsync/)();
await synchronizer2.startSync[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/synchronization/startsync/)();

store1.setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({pets: {fido: {species: 'dog'}}});
// ...
console.log(store2.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}}}

store2.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'felix', {species: 'cat'});
// ...
console.log(store1.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}, felix: {species: 'cat'}}}

await synchronizer1.destroy[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/destroy/)();
await synchronizer2.destroy[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/destroy/)();

```

This example creates two empty [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) objects, creates a [`LocalSynchronizer`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/) for each, and starts synchronizing them with default content. The default content from the first [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/)'s `startSync` method ends up populated in both [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) instances: by the time the second started, the first was available to synchronize with and its default was not needed.

```
import {createMergeableStore} from 'tinybase';
import {createLocalSynchronizer} from 'tinybase/synchronizers/synchronizer-local';

const store1 = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)();
const store2 = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)();

const synchronizer1 = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(store1);
const synchronizer2 = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(store2);

await synchronizer1.startSync[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/synchronization/startsync/)([{pets: {fido: {species: 'dog'}}}, {}]);
await synchronizer2.startSync[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/synchronization/startsync/)([{pets: {felix: {species: 'cat'}}}, {}]);

// ...

console.log(store1.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}}}
console.log(store2.getTables[](https://tinybase.org/api/store/interfaces/store/store/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}}}

await synchronizer1.destroy[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/destroy/)();
await synchronizer2.destroy[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/destroy/)();

```
