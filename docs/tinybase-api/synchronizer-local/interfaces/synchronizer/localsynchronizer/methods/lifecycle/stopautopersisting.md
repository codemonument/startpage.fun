# `stopAutoPersisting`
The stopAutoPersist method is a convenience method that stops both automatic loading and saving of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data.

```
stopAutoPersisting[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/stopautopersisting/)(stopSaveFirst?: boolean): Promise<LocalSynchronizer[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/)>
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `stopSaveFirst?`  | `boolean`  | Whether to stop saving before loading, defaulting to false.  |  
| returns  | `Promise<LocalSynchronizer[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/)>`  | A Promise containing a reference to the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) object.  |  
This simply runs the stopAutoLoad and [`stopAutoSave`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/stopautosave/) methods in sequence, and returns a Promise that resolves when both have completed.
If for some reason you want to stop saving _before_ you stop loading, pass true as the second parameter.
## Example
automatically loading and saving.

```
import {createStore} from 'tinybase';
import {createSessionPersister} from 'tinybase/persisters/persister-browser';

const persister = createSessionPersister[](https://tinybase.org/api/the-essentials/persisting-stores/createsessionpersister/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)(), 'pets');

await persister.startAutoPersisting[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/startautopersisting/)();
console.log(persister.isAutoSaving[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/isautosaving/)());
// -> true
console.log(persister.isAutoLoading[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/load/isautoloading/)());
// -> true

await persister.stopAutoPersisting[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/stopautopersisting/)();
console.log(persister.isAutoSaving[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/isautosaving/)());
// -> false
console.log(persister.isAutoLoading[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/load/isautoloading/)());
// -> false

persister.destroy[](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/lifecycle/destroy/)();

```
