# Save methods
## `isAutoSaving`
The [`isAutoSaving`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/isautosaving/) method lets you find out if the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) is currently automatically saving its content. [Read more](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/isautosaving/).
## `save`
The [`save`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/save/) method takes data from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with which the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) is associated and persists it into storage, once. [Read more](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/save/).
## `startAutoSave`
The [`save`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/save/) method takes data from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with which the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) is associated and persists it into storage, once, and then continuously. [Read more](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/startautosave/).
## `stopAutoSave`
The [`stopAutoSave`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/stopautosave/) method stops the automatic save of data to storage previously started with the [`startAutoSave`](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/startautosave/) method. [Read more](https://tinybase.org/api/synchronizer-local/interfaces/synchronizer/localsynchronizer/methods/save/stopautosave/).
