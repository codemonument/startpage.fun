# `JoinedAs`
The `JoinedAs` type describes an object returned from calling a [`Join`](https://tinybase.org/api/queries/type-aliases/definition/join/) function so that the joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) can be optionally aliased.

```
{as: (joinedTableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)) => void}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `as`  | `(joinedTableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)) => void`  | A function that lets you specify an alias for the joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
Note that if two [`Join`](https://tinybase.org/api/queries/type-aliases/definition/join/) clauses are both aliased to the same name (or if you create two joins to the same underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), both _without_ aliases), only the latter of two will be used in the query.
For the purposes of clarity, it's recommended to use an alias that does not collide with a real underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (whether included in the query or not).
## Example
This example shows a query that joins the same underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) twice, for different purposes. Both joins are aliased with the 'as' function to disambiguate them. Note that the selected Cells are also aliased.

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', buyerId: '1', sellerId: '2'},
    felix: {species: 'cat', buyerId: '2'},
    cujo: {species: 'dog', buyerId: '3', sellerId: '1'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('humans', {
    '1': {name: 'Alice'},
    '2': {name: 'Bob'},
    '3': {name: 'Carol'},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select('buyers', 'name').as('buyer');
  select('sellers', 'name').as('seller');
  // from pets
  join('humans', 'buyerId').as('buyers');
  join('humans', 'sellerId').as('sellers');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {buyer: 'Alice', seller: 'Bob'}}
// -> {felix: {buyer: 'Bob'}}
// -> {cujo: {buyer: 'Carol', seller: 'Alice'}}

```
