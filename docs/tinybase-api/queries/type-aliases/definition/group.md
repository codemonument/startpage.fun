# `Group`
The `Group` type describes a function that lets you specify that the values of a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in multiple ResultRows should be aggregated together.

```
(
  selectedCellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/),
  aggregate: "count" | "sum" | "avg" | "min" | "max" | Aggregate[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregate/),
  aggregateAdd?: AggregateAdd[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregateadd/),
  aggregateRemove?: AggregateRemove[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregateremove/),
  aggregateReplace?: AggregateReplace[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregatereplace/),
): GroupedAs[](https://tinybase.org/api/queries/type-aliases/definition/groupedas/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `selectedCellId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to aggregate. If the underlying [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) was selected 'as' a different [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), that should instead be used.  |  
| `aggregate`  | `"count" | "sum" | "avg" | "min" | "max" | Aggregate[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregate/)`  | Either a string representing one of a set of common aggregation techniques ('count', 'sum', 'avg', 'min', or 'max'), or a function that aggregates [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values from each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to create the aggregate's overall.  |  
| `aggregateAdd?`  | `AggregateAdd[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregateadd/)`  | A function that can be used to optimize a custom [`Aggregate`](https://tinybase.org/api/queries/type-aliases/aggregators/aggregate/) by providing a shortcut for when a single value is added to the input values - for example, when a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is added to the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `aggregateRemove?`  | `AggregateRemove[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregateremove/)`  | A function that can be used to optimize a custom [`Aggregate`](https://tinybase.org/api/queries/type-aliases/aggregators/aggregate/) by providing a shortcut for when a single value is removed from the input values - for example, when a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is removed from the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `aggregateReplace?`  | `AggregateReplace[](https://tinybase.org/api/queries/type-aliases/aggregators/aggregatereplace/)`  | A function that can be used to optimize a custom [`Aggregate`](https://tinybase.org/api/queries/type-aliases/aggregators/aggregate/) by providing a shortcut for when a single value in the input values is replaced with another - for example, when a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is updated.  |  
| returns  | `GroupedAs[](https://tinybase.org/api/queries/type-aliases/definition/groupedas/)`  | A [`GroupedAs`](https://tinybase.org/api/queries/type-aliases/definition/groupedas/) object so that the grouped [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) can be optionally aliased.  |  
The `Group` function is provided to the third `query` parameter of the [`setQueryDefinition`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/) method. When called, it should refer to a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) (or aliased [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) specified in one of the [`Select`](https://tinybase.org/api/queries/type-aliases/definition/select/) functions, and indicate how the values should be aggregated.
This is applied after any joins or where-based filtering.
If you provide a `Group` for every [`Select`](https://tinybase.org/api/queries/type-aliases/definition/select/), the result will be a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) with every [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) having been aggregated. If you provide a `Group` for only one, or some, of the [`Select`](https://tinybase.org/api/queries/type-aliases/definition/select/) clauses, the _others_ will be automatically used as dimensional values (analogous to the `group by` semantics in SQL), within which the aggregations of `Group` Cells will be performed.
You can join the same underlying [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) multiple times, but in that case you will need to use the 'as' function to distinguish them from each other.
The second parameter can be one of five predefined aggregates - 'count', 'sum', 'avg', 'min', and 'max' - or a custom function that produces your own aggregation of an array of [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values.
The final three parameters, `aggregateAdd`, `aggregateRemove`, `aggregateReplace` need only be provided when you are using your own custom `aggregate` function. These give you the opportunity to reduce your custom function's algorithmic complexity by providing shortcuts that can nudge an aggregation result when a single value is added, removed, or replaced in the input values.
## Examples
This example shows a query that calculates the average of all the values in a single selected [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) from a joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog'},
    felix: {species: 'cat'},
    cujo: {species: 'dog'},
    lowly: {species: 'worm'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    dog: {price: 5},
    cat: {price: 4},
    worm: {price: 1},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join, group}) => {
  select('species', 'price');
  // from pets
  join('species', 'species');
  group('price', 'avg').as('avgPrice');
});

console.log(queries.getResultTable[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresulttable/)('query'));
// -> {0: {avgPrice: 3.75}}
// 2 dogs at 5, 1 cat at 4, 1 worm at 1: a total of 15 for 4 pets

```

This example shows a query that calculates the average of a two [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values, aggregated by the two other dimensional 'group by' Cells.

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', owner: 'alice'},
    felix: {species: 'cat', owner: 'bob'},
    cujo: {species: 'dog', owner: 'bob'},
    lowly: {species: 'worm', owner: 'alice'},
    carnaby: {species: 'parrot', owner: 'bob'},
    polly: {species: 'parrot', owner: 'alice'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
    dog: {price: 5, legs: 4},
    cat: {price: 4, legs: 4},
    parrot: {price: 3, legs: 2},
    worm: {price: 1, legs: 0},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join, group}) => {
  select('pets', 'owner'); //    group by
  select('species', 'price'); // grouped
  // from pets
  join('species', 'species');
  group(
    'price',
    (cells) => Math.min(...cells.filter((cell) => cell > 2)),
    (current, add) => (add > 2 ? Math.min(current, add) : current),
    (current, remove) => (remove == current ? undefined : current),
    (current, add, remove) =>
      remove == current
        ? undefined
        : add > 2
          ? Math.min(current, add)
          : current,
  ).as('lowestPriceOver2');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {0: {owner: 'alice', lowestPriceOver2: 3}}
// -> {1: {owner: 'bob', lowestPriceOver2: 3}}
// Both have a parrot at 3. Alice's worm at 1 is excluded from aggregation.

```
