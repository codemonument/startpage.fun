# `Join`
The `Join` type describes a function that lets you specify a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or calculated value to join the main query [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to other [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/), by their [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).
Calling this function with two [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) parameters will indicate that the join to a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in an adjacent [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is made by finding its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) in a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) of the query's root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
(
  joinedTableId: string,
  on: string,
): JoinedAs[](https://tinybase.org/api/queries/type-aliases/definition/joinedas/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `joinedTableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to join to.  |  
| `on`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that contains the joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
| returns  | `JoinedAs[](https://tinybase.org/api/queries/type-aliases/definition/joinedas/)`  | A [`JoinedAs`](https://tinybase.org/api/queries/type-aliases/definition/joinedas/) object so that the joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) can be optionally aliased.  |  
## Since
v2.0.0
* * *
Calling this function with two parameters (where the second is a function) will indicate that the join to a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in an adjacent [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is made by calculating its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) from the Cells and the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query's root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
(
  joinedTableId: string,
  on: (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => undefined | string,
): JoinedAs[](https://tinybase.org/api/queries/type-aliases/definition/joinedas/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `joinedTableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to join to.  |  
| `on`  | `(getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => undefined | string`  | A callback that takes a [`GetCell`](https://tinybase.org/api/store/type-aliases/callback/getcell/) function and the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). These can be used to programmatically calculate the joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |

## Since
v2.0.0
The `Join` function is provided to the third `query` parameter of the [`setQueryDefinition`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/) method.
You can join zero, one, or many [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/). You can join the same underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) multiple times, but in that case you will need to use the 'as' function to distinguish them from each other.
By default, each join is made from the main query [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to the joined table, but it is also possible to connect via an intermediate join [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to a more distant join [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).
Because a `Join` clause is used to identify which unique [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) will be joined to each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) of the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), queries follow the 'left join' semantics you may be familiar with from SQL. This means that an unfiltered query will only ever return the same number of Rows as the main [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) being queried, and indeed the resulting table (assuming it has not been aggregated) will even preserve the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s original [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/).
## Examples
This example shows a query that joins a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) by using an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) present in the main query [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', ownerId: '1'},
    felix: {species: 'cat', ownerId: '2'},
    cujo: {species: 'dog', ownerId: '3'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('owners', {
    '1': {name: 'Alice'},
    '2': {name: 'Bob'},
    '3': {name: 'Carol'},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select('species');
  select('owners', 'name');
  // from pets
  join('owners', 'ownerId');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {species: 'dog', name: 'Alice'}}
// -> {felix: {species: 'cat', name: 'Bob'}}
// -> {cujo: {species: 'dog', name: 'Carol'}}

```

This example shows a query that joins the same underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) twice, and aliases them (and the selected [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/)). Note the left-join semantics: Felix the cat was bought, but the seller was unknown. The record still exists in the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', buyerId: '1', sellerId: '2'},
    felix: {species: 'cat', buyerId: '2'},
    cujo: {species: 'dog', buyerId: '3', sellerId: '1'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('humans', {
    '1': {name: 'Alice'},
    '2': {name: 'Bob'},
    '3': {name: 'Carol'},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select('buyers', 'name').as('buyer');
  select('sellers', 'name').as('seller');
  // from pets
  join('humans', 'buyerId').as('buyers');
  join('humans', 'sellerId').as('sellers');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {buyer: 'Alice', seller: 'Bob'}}
// -> {felix: {buyer: 'Bob'}}
// -> {cujo: {buyer: 'Carol', seller: 'Alice'}}

```

This example shows a query that calculates the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) based from multiple values in the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) rather than a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', color: 'brown'},
    felix: {species: 'cat', color: 'black'},
    cujo: {species: 'dog', color: 'black'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('colorSpecies', {
    'brown-dog': {price: 6},
    'black-dog': {price: 5},
    'brown-cat': {price: 4},
    'black-cat': {price: 3},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select('colorSpecies', 'price');
  // from pets
  join(
    'colorSpecies',
    (getCell) => `${getCell[](https://tinybase.org/api/the-essentials/getting-data/getcell/)('color')}-${getCell[](https://tinybase.org/api/the-essentials/getting-data/getcell/)('species')}`,
  );
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {price: 6}}
// -> {felix: {price: 3}}
// -> {cujo: {price: 5}}

```

This example shows a query that joins two [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/), one through the intermediate other.

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', ownerId: '1'},
    felix: {species: 'cat', ownerId: '2'},
    cujo: {species: 'dog', ownerId: '3'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('owners', {
    '1': {name: 'Alice', state: 'CA'},
    '2': {name: 'Bob', state: 'CA'},
    '3': {name: 'Carol', state: 'WA'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('states', {
    CA: {name: 'California'},
    WA: {name: 'Washington'},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select(
    (getTableCell) =>
      `${getTableCell('species')} in ${getTableCell('states', 'name')}`,
  ).as('description');
  // from pets
  join('owners', 'ownerId');
  join('states', 'owners', 'state');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {description: 'dog in California'}}
// -> {felix: {description: 'cat in California'}}
// -> {cujo: {description: 'dog in Washington'}}

```
