# `SelectedAs`
The `SelectedAs` type describes an object returned from calling a [`Select`](https://tinybase.org/api/queries/type-aliases/definition/select/) function so that the selected [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) can be optionally aliased.

```
{as: (selectedCellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)) => void}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `as`  | `(selectedCellId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)) => void`  | A function that lets you specify an alias for the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
If you are using a callback in the [`Select`](https://tinybase.org/api/queries/type-aliases/definition/select/) cause, it is highly recommended to use the 'as' function, since otherwise a machine-generated column name will be used.
Note that if two [`Select`](https://tinybase.org/api/queries/type-aliases/definition/select/) clauses are both aliased to the same name (or if two columns with the same underlying name are selected, both _without_ aliases), only the latter of two will be used in the query.
## Example
This example shows a query that selects two Cells, one from a joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). Both are aliased with the 'as' function:

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', ownerId: '1'},
    felix: {species: 'cat', ownerId: '2'},
    cujo: {species: 'dog', ownerId: '3'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('owners', {
    '1': {name: 'Alice'},
    '2': {name: 'Bob'},
    '3': {name: 'Carol'},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select('species').as('petSpecies');
  select('owners', 'name').as('ownerName');
  // from pets
  join('owners', 'ownerId');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {petSpecies: 'dog', ownerName: 'Alice'}}
// -> {felix: {petSpecies: 'cat', ownerName: 'Bob'}}
// -> {cujo: {petSpecies: 'dog', ownerName: 'Carol'}}

```
