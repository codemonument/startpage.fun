# `Select`
The `Select` type describes a function that lets you specify a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or calculated value for including into the query's result.
Calling this function with one [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) parameter will indicate that the query should select the value of the specified [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) from the query's root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
(cellId: string): SelectedAs[](https://tinybase.org/api/queries/type-aliases/definition/selectedas/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `cellId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to fetch the value for.  |  
| returns  | `SelectedAs[](https://tinybase.org/api/queries/type-aliases/definition/selectedas/)`  | A [`SelectedAs`](https://tinybase.org/api/queries/type-aliases/definition/selectedas/) object so that the selected [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) can be optionally aliased.  |  
## Since
v2.0.0
* * *
Calling this function with two parameters will indicate that the query should select the value of the specified [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) from a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that has been joined in the query.

```
(
  joinedTableId: string,
  joinedCellId: string,
): SelectedAs[](https://tinybase.org/api/queries/type-aliases/definition/selectedas/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `joinedTableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to fetch the value from. If the underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) was joined 'as' a different [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), that should instead be used.  |  
| `joinedCellId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) to fetch the value for.  |  
| returns  | `SelectedAs[](https://tinybase.org/api/queries/type-aliases/definition/selectedas/)`  | A [`SelectedAs`](https://tinybase.org/api/queries/type-aliases/definition/selectedas/) object so that the selected [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) can be optionally aliased.  |  
## Since
v2.0.0
* * *
Calling this function with one callback parameter will indicate that the query should select a calculated value, based on one or more [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values in the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) or a joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), or on the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).

```
(getCell: (getTableCell: GetTableCell[](https://tinybase.org/api/queries/type-aliases/callback/gettablecell/), rowId: string) => ResultCellOrUndefined[](https://tinybase.org/api/queries/type-aliases/result/resultcellorundefined/)): SelectedAs[](https://tinybase.org/api/queries/type-aliases/definition/selectedas/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `getCell`  | `(getTableCell: GetTableCell[](https://tinybase.org/api/queries/type-aliases/callback/gettablecell/), rowId: string) => ResultCellOrUndefined[](https://tinybase.org/api/queries/type-aliases/result/resultcellorundefined/)`  | A callback that takes a [`GetTableCell`](https://tinybase.org/api/queries/type-aliases/callback/gettablecell/) function and the main [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)'s [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). These can be used to programmatically create a calculated value from multiple [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values and the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
| returns  | `SelectedAs[](https://tinybase.org/api/queries/type-aliases/definition/selectedas/)`  | A [`SelectedAs`](https://tinybase.org/api/queries/type-aliases/definition/selectedas/) object so that the selected [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) can be optionally aliased.  |  
## Since
v2.0.0
The `Select` function is provided to the third `query` parameter of the [`setQueryDefinition`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/) method. A query definition must call the `Select` function at least once, otherwise it will be meaningless and return no data.
## Examples
This example shows a query that selects two Cells from the main query [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown', legs: 4},
  felix: {species: 'cat', color: 'black', legs: 4},
  cujo: {species: 'dog', color: 'black', legs: 4},
});

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select}) => {
  select('species');
  select('color');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {species: 'dog', color: 'brown'}}
// -> {felix: {species: 'cat', color: 'black'}}
// -> {cujo: {species: 'dog', color: 'black'}}

```

This example shows a query that selects two Cells, one from a joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', ownerId: '1'},
    felix: {species: 'cat', ownerId: '2'},
    cujo: {species: 'dog', ownerId: '3'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('owners', {
    '1': {name: 'Alice'},
    '2': {name: 'Bob'},
    '3': {name: 'Carol'},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select('species');
  select('owners', 'name');
  // from pets
  join('owners', 'ownerId');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {species: 'dog', name: 'Alice'}}
// -> {felix: {species: 'cat', name: 'Bob'}}
// -> {cujo: {species: 'dog', name: 'Carol'}}

```

This example shows a query that calculates a value from two underlying Cells.

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
    fido: {species: 'dog', ownerId: '1'},
    felix: {species: 'cat', ownerId: '2'},
    cujo: {species: 'dog', ownerId: '3'},
  })
  .setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('owners', {
    '1': {name: 'Alice'},
    '2': {name: 'Bob'},
    '3': {name: 'Carol'},
  });

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('query', 'pets', ({select, join}) => {
  select(
    (getTableCell) =>
      `${getTableCell('species')} for ${getTableCell('owners', 'name')}`,
  ).as('description');
  join('owners', 'ownerId');
});

queries.forEachResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultrow/)('query', (rowId) => {
  console.log({[rowId]: queries.getResultRow[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultrow/)('query', rowId)});
});
// -> {fido: {description: 'dog for Alice'}}
// -> {felix: {description: 'cat for Bob'}}
// -> {cujo: {description: 'dog for Carol'}}

```
