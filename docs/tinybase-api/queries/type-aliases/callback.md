# Callback type aliases
## `GetTableCell`
The [`GetTableCell`](https://tinybase.org/api/queries/type-aliases/callback/gettablecell/) type describes a function that takes a [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and returns the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) value for a particular [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), optionally in a joined [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). [Read more](https://tinybase.org/api/queries/type-aliases/callback/gettablecell/).
## `ResultTableCallback`
The [`ResultTableCallback`](https://tinybase.org/api/queries/type-aliases/callback/resulttablecallback/) type describes a function that takes a [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/)'s [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and a callback to loop over each [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) within it. [Read more](https://tinybase.org/api/queries/type-aliases/callback/resulttablecallback/).
## `ResultRowCallback`
The [`ResultRowCallback`](https://tinybase.org/api/queries/type-aliases/callback/resultrowcallback/) type describes a function that takes a [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/)'s [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and a callback to loop over each [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/) within it. [Read more](https://tinybase.org/api/queries/type-aliases/callback/resultrowcallback/).
## `ResultCellCallback`
The [`ResultCellCallback`](https://tinybase.org/api/queries/type-aliases/callback/resultcellcallback/) type describes a function that takes a [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/)'s [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and its value. [Read more](https://tinybase.org/api/queries/type-aliases/callback/resultcellcallback/).
## `QueryCallback`
The [`QueryCallback`](https://tinybase.org/api/queries/type-aliases/callback/querycallback/) type describes a function that takes a query's [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). [Read more](https://tinybase.org/api/queries/type-aliases/callback/querycallback/).
