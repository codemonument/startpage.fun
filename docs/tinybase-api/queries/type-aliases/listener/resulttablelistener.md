# `ResultTableListener`
The `ResultTableListener` type describes a function that is used to listen to changes to a query's [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/).

```
(
  queries: Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/),
  tableId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/),
  getCellChange: GetResultCellChange[](https://tinybase.org/api/queries/type-aliases/listener/getresultcellchange/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queries`  | `Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/)`  | A reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that changed.  |  
| `tableId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) that changed, which is also the query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
| `getCellChange`  | `GetResultCellChange[](https://tinybase.org/api/queries/type-aliases/listener/getresultcellchange/)`  | A function that returns information about any [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/)'s changes.  |  
| returns  | `void`  | This has no return value.  |  
A `ResultTableListener` is provided when using the [`addResultTableListener`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addresulttablelistener/) method. See that method for specific examples.
When called, a `ResultTableListener` is given a reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) that changed (which is the same as the query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)), and a [`GetResultCellChange`](https://tinybase.org/api/queries/type-aliases/listener/getresultcellchange/) function that can be used to query [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/) values before and after the change.
You can create new query definitions within the body of this listener, though obviously be aware of the possible cascading effects of doing so.
