# `addParamValueListener`
The `addParamValueListener` method registers a listener function with the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever a specific param value of a query changes.

```
addParamValueListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addparamvaluelistener/)(
  queryId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  paramId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: ParamValueListener[](https://tinybase.org/api/queries/type-aliases/listener/paramvaluelistener/),
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query to listen to, or `null` as a wildcard.  |  
| `paramId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the param to listen to, or `null` as a wildcard.  |  
| `listener`  | `ParamValueListener[](https://tinybase.org/api/queries/type-aliases/listener/paramvaluelistener/)`  | The function that will be called whenever the specific param value of the query changes.  |  
| returns  | `string`  |   |  
You can either listen to a single query (by specifying a query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first parameter) or changes to any query (by providing a `null` wildcard). Additionally, you can either listen to a specific param (by specifying a param [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the second parameter) or changes to any param (by providing a `null` wildcard).
The provided listener is a [`ParamValueListener`](https://tinybase.org/api/queries/type-aliases/listener/paramvaluelistener/) function, and will be called with a reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query whose param value changed, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the param whose value changed, and the new value of the param.
## Example
This example registers two listeners that respond to changes to a specific param value of a specific query, or any param value of any query respectively.

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  // store data
});

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)(
  'petsByColor',
  'pets',
  () => {
    // query definition
  },
  {color: 'white'},
);

const listenerId1 = queries.addParamValueListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addparamvaluelistener/)(
  'petsByColor',
  'color',
  (queries, queryId, paramId, value) => {
    console.log(`Specific param for specific query changed: "${value}"`);
  },
);
const listenerId2 = queries.addParamValueListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addparamvaluelistener/)(
  null,
  null,
  (queries, queryId, paramId, value) => {
    console.log(`Param "${paramId}" for "${queryId}" changed: "${value}"`);
  },
);

queries.setParamValue[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setparamvalue/)('petsByColor', 'color', 'black');
// -> 'Specific param for specific query changed: "black"'
// -> 'Param "color" for "petsByColor" changed: "black"'
queries.setParamValue[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setparamvalue/)('petsByColor', 'color', 'brown');
// -> 'Specific param for specific query changed: "brown"'
// -> 'Param "color" for "petsByColor" changed: "brown"'

queries.delListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/dellistener/)(listenerId1);
queries.delListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/dellistener/)(listenerId2);

```
