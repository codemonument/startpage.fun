# `addResultRowListener`
The `addResultRowListener` method registers a listener function with the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object that will be called whenever data in a [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) changes.

```
addResultRowListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addresultrowlistener/)(
  queryId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  rowId: IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/),
  listener: ResultRowListener[](https://tinybase.org/api/queries/type-aliases/listener/resultrowlistener/),
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query to listen to, or `null` as a wildcard.  |  
| `rowId`  | `IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) to listen to, or `null` as a wildcard.  |  
| `listener`  | `ResultRowListener[](https://tinybase.org/api/queries/type-aliases/listener/resultrowlistener/)`  | The function that will be called whenever data in the matching [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) changes.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
The provided listener is a [`ResultRowListener`](https://tinybase.org/api/queries/type-aliases/listener/resultrowlistener/) function, and will be called with a reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) that changed (which is also the query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)), and a [`GetResultCellChange`](https://tinybase.org/api/queries/type-aliases/listener/getresultcellchange/) function in case you need to inspect any changes that occurred.
You can either listen to a single [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) (by specifying a query [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) as the method's first two parameters) or changes to any [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) (by providing `null` wildcards).
Both, either, or neither of the `queryId` and `rowId` parameters can be wildcarded with `null`. You can listen to a specific [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) in a specific query, any [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) in a specific query, a specific [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) in any query, or any [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) in any query.
## Examples
This example registers a listener that responds to any changes to a specific [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
  cujo: {species: 'dog', color: 'black'},
});

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)(
  'dogColors',
  'pets',
  ({select, where}) => {
    select('color');
    where('species', 'dog');
  },
);

const listenerId = queries.addResultRowListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addresultrowlistener/)(
  'dogColors',
  'fido',
  (queries, tableId, rowId, getCellChange) => {
    console.log('fido row in dogColors result table changed');
    console.log(getCellChange('dogColors', 'fido', 'color'));
  },
);

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
// -> 'fido row in dogColors result table changed'
// -> [true, 'brown', 'walnut']

store.delListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any changes to any [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
  cujo: {species: 'dog', color: 'black'},
});

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store)
  .setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('dogColors', 'pets', ({select, where}) => {
    select('color');
    where('species', 'dog');
  })
  .setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('catColors', 'pets', ({select, where}) => {
    select('color');
    where('species', 'cat');
  });

const listenerId = queries.addResultRowListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addresultrowlistener/)(
  null,
  null,
  (queries, tableId, rowId) => {
    console.log(`${rowId} row in ${tableId} result table changed`);
  },
);

store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'fido', 'color', 'walnut');
// -> 'fido row in dogColors result table changed'
store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('pets', 'felix', 'color', 'tortoiseshell');
// -> 'felix row in catColors result table changed'

store.delListener[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/dellistener/)(listenerId);

```
