# Getter methods
## `getStore`
The [`getStore`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getstore/) method returns a reference to the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that is backing this [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object. [Read more](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getstore/).
## `getTableId`
The [`getTableId`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/gettableid/) method returns the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that is backing a query. [Read more](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/gettableid/).
## `getParamValues`
The [`getParamValues`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getparamvalues/) method returns all the param values currently set for a parameterized query. [Read more](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getparamvalues/).
## `getParamValue`
The [`getParamValue`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getparamvalue/) method returns a single param value currently set for a parameterized query. [Read more](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getparamvalue/).
## `getQueryIds`
The [`getQueryIds`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getqueryids/) method returns an array of the query [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) registered with this [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object. [Read more](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/getqueryids/).
## `hasQuery`
The [`hasQuery`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/hasquery/) method returns a boolean indicating whether a given query exists in the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object. [Read more](https://tinybase.org/api/queries/interfaces/queries/queries/methods/getter/hasquery/).
