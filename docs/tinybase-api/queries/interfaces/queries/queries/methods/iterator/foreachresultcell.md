# `forEachResultCell`
The `forEachResultCell` method takes a function that it will then call for each [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/) in the [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) of a query.

```
forEachResultCell[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultcell/)(
  queryId: string,
  rowId: string,
  cellCallback: ResultCellCallback[](https://tinybase.org/api/queries/type-aliases/callback/resultcellcallback/),
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a query.  |  
| `rowId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) in the query's [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/).  |  
| `cellCallback`  | `ResultCellCallback[](https://tinybase.org/api/queries/type-aliases/callback/resultcellcallback/)`  | The function that should be called for every [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/) of the query's [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/).  |  
| returns  | `void`  | This has no return value.  |  
This method is useful for iterating over each [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/) of the [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/) of the query in a functional style. The `cellCallback` parameter is a [`ResultCellCallback`](https://tinybase.org/api/queries/type-aliases/callback/resultcellcallback/) function that will be called with the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) and value of each [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/).
## Example
This example iterates over each [`ResultCell`](https://tinybase.org/api/queries/type-aliases/result/resultcell/) in a query's [`ResultRow`](https://tinybase.org/api/queries/type-aliases/result/resultrow/).

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
  cujo: {species: 'dog', color: 'black'},
});

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store).setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)(
  'dogColors',
  'pets',
  ({select, where}) => {
    select('species');
    select('color');
    where('species', 'dog');
  },
);

queries.forEachResultCell[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/iterator/foreachresultcell/)('dogColors', 'fido', (cellId, cell) => {
  console.log(`${cellId}: ${cell}`);
});
// -> 'species: dog'
// -> 'color: brown'

```
