# `setQueryDefinition`
The `setQueryDefinition` method lets you set the definition of a query.

```
setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)(
  queryId: string,
  tableId: string,
  query: (keywords: {
    select: Select[](https://tinybase.org/api/queries/type-aliases/definition/select/);
    join: Join[](https://tinybase.org/api/queries/type-aliases/definition/join/);
    where: Where[](https://tinybase.org/api/queries/type-aliases/definition/where/);
    group: Group[](https://tinybase.org/api/queries/type-aliases/definition/group/);
    having: Having[](https://tinybase.org/api/queries/type-aliases/definition/having/);
    param: Param[](https://tinybase.org/api/queries/type-aliases/definition/param/);
  }) => void,
  paramValues?: ParamValues[](https://tinybase.org/api/queries/type-aliases/params/paramvalues/),
): Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query to define.  |  
| `tableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) the query will be based on.  |  
| `query`  | `(keywords: { select: Select[](https://tinybase.org/api/queries/type-aliases/definition/select/); join: Join[](https://tinybase.org/api/queries/type-aliases/definition/join/); where: Where[](https://tinybase.org/api/queries/type-aliases/definition/where/); group: Group[](https://tinybase.org/api/queries/type-aliases/definition/group/); having: Having[](https://tinybase.org/api/queries/type-aliases/definition/having/); param: Param[](https://tinybase.org/api/queries/type-aliases/definition/param/); }) => void`  | A callback which can take a `keywords` object and which uses the functions it contains to define the query.  |  
| `paramValues?`  | `ParamValues[](https://tinybase.org/api/queries/type-aliases/params/paramvalues/)`  |   |  
| returns  | `Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/)`  | A reference to the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object.  |  
Every query definition is identified by a unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and if you re-use an existing [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) with this method, the previous definition is overwritten.
A query provides a tabular result formed from each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) within a root [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). The definition must specify this [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (by its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) to be aggregated. Other [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) can be joined to that using [`Join`](https://tinybase.org/api/queries/type-aliases/definition/join/) clauses.
The third `query` parameter is a callback that you provide to define the query. That callback is provided with a `keywords` object that contains the functions you use to define the query, like `select`, `join`, and so on. You can see how that is used in the simple example below. The following six clause types are supported:
  * The [`Select`](https://tinybase.org/api/queries/type-aliases/definition/select/) type describes a function that lets you specify a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or calculated value for including into the query's result.
  * The [`Join`](https://tinybase.org/api/queries/type-aliases/definition/join/) type describes a function that lets you specify a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or calculated value to join the main query [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) to others, by [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).
  * The [`Where`](https://tinybase.org/api/queries/type-aliases/definition/where/) type describes a function that lets you specify conditions to filter results, based on the underlying Cells of the main or joined [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/).
  * The [`Group`](https://tinybase.org/api/queries/type-aliases/definition/group/) type describes a function that lets you specify that the values of a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in multiple ResultRows should be aggregated together.
  * The [`Having`](https://tinybase.org/api/queries/type-aliases/definition/having/) type describes a function that lets you specify conditions to filter results, based on the grouped Cells resulting from a [`Group`](https://tinybase.org/api/queries/type-aliases/definition/group/) clause.
  * The [`Param`](https://tinybase.org/api/queries/type-aliases/definition/param/) type (since v7.2) describes a function that lets you specify parameters for a parameterized query.


Full documentation and examples are provided in the sections for each of those clause types.
Additionally, you can use the [`getResultSortedRowIds`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresultsortedrowids/) method and [`addResultSortedRowIdsListener`](https://tinybase.org/api/queries/interfaces/queries/queries/methods/listener/addresultsortedrowidslistener/) method to sort and paginate the results.
## Example
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and defines a simple query to select just one column from the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), for each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) where the `species` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) matches as certain value.

```
import {createQueries, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('pets', {
  fido: {species: 'dog', color: 'brown'},
  felix: {species: 'cat', color: 'black'},
  cujo: {species: 'dog', color: 'black'},
});

const queries = createQueries[](https://tinybase.org/api/queries/functions/creation/createqueries/)(store);
queries.setQueryDefinition[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/configuration/setquerydefinition/)('dogColors', 'pets', ({select, where}) => {
  select('color');
  where('species', 'dog');
});

console.log(queries.getResultTable[](https://tinybase.org/api/queries/interfaces/queries/queries/methods/result/getresulttable/)('dogColors'));
// -> {fido: {color: 'brown'}, cujo: {color: 'black'}}

```
