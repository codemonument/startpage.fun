# `forEachTable`
The `forEachTable` method takes a function that it will then call for each [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
forEachTable[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/iterator/foreachtable/)(tableCallback: TableCallback[](https://tinybase.org/api/store/type-aliases/callback/tablecallback/)): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tableCallback`  | `TableCallback[](https://tinybase.org/api/store/type-aliases/callback/tablecallback/)`  | The function that should be called for every [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| returns  | `void`  | This has no return value.  |  
This method is useful for iterating over the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) structure of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) in a functional style. The `tableCallback` parameter is a [`TableCallback`](https://tinybase.org/api/store/type-aliases/callback/tablecallback/) function that will be called with the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of each [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and with a function that can then be used to iterate over each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), should you wish.
## Example
This example iterates over each [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and lists each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) within them.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({
  pets: {fido: {species: 'dog'}},
  species: {dog: {price: 5}},
});
store.forEachTable[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/iterator/foreachtable/)((tableId, forEachRow) => {
  console.log(tableId);
  forEachRow[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/iterator/foreachrow/)((rowId) => console.log(`- ${rowId}`));
});
// -> 'pets'
// -> '- fido'
// -> 'species'
// -> '- dog'

```
