# `addStartTransactionListener`
The `addStartTransactionListener` method registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called at the start of a transaction.

```
addStartTransactionListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addstarttransactionlistener/)(listener: TransactionListener[](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/)<MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)>): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `listener`  | `TransactionListener[](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/)<MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)>`  | The function that will be called at the start of a transaction.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
The provided [`TransactionListener`](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/) will receive a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and two booleans to indicate whether [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) data has been touched during the transaction. Since this is called at the start, they will both be `false`!
Note that a [`TransactionListener`](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/) added to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with this method can mutate the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and its changes will be treated as part of the transaction that is starting.
## Example
This example registers a listener that is called at start end of the transaction, just before its listeners will be called.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({
    pets: {fido: {species: 'dog', color: 'brown'}},
  })
  .setValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalues/)({open: true, employees: 3});
const listenerId = store.addStartTransactionListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addstarttransactionlistener/)(() => {
  console.log('Transaction started');
});

store.transaction[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/transaction/transaction/)(() =>
  store.setCell[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setcell/)('pets', 'fido', 'color', 'brown').setValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalue/)('employees', 3),
);
// -> 'Transaction started'

store.callListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/calllistener/)(listenerId);
// -> 'Transaction started'

store.delListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/dellistener/)(listenerId);

```
