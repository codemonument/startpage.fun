# `addDidFinishTransactionListener`
The `addDidFinishTransactionListener` method registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called just after other non-mutating listeners are called at the end of the transaction.

```
addDidFinishTransactionListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/adddidfinishtransactionlistener/)(listener: TransactionListener[](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/)<MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)>): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `listener`  | `TransactionListener[](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/)<MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)>`  | The function that will be called after the end of a transaction.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
This is useful if you need to know that a set of listeners have just been called at the end of a transaction, perhaps to batch _their_ consequences together.
The provided [`TransactionListener`](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/) will receive a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and two booleans to indicate whether [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) data has been touched during the transaction. The two flags is intended as a hint about whether non-mutating listeners might have been called at the end of the transaction.
Here, 'touched' means that [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) or [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) data has either been changed, or changed and then changed back to its original value during the transaction. The exception is a transaction that has been rolled back, for which the value of `cellsTouched` and `valuesTouched` in the listener will be `false` because all changes have been reverted.
Note that a [`TransactionListener`](https://tinybase.org/api/store/type-aliases/listener/transactionlistener/) added to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with this method _cannot_ mutate the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) itself, and attempts to do so will fail silently.
## Example
This example registers a listener that is called at the end of the transaction, just after its listeners have been called. The transactions shown here variously change, touch, and rollback cells, demonstrating how the `cellsTouched` and `valuesTouched` parameters in the listener work.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)()
  .setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({
    pets: {fido: {species: 'dog', color: 'brown'}},
  })
  .setValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalues/)({open: true, employees: 3});
const listenerId = store.addDidFinishTransactionListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/adddidfinishtransactionlistener/)((store) => {
  const [cellsTouched, valuesTouched] = store.getTransactionLog[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/transaction/gettransactionlog/)() ?? {};
  console.log(`Cells/Values touched: ${cellsTouched}/${valuesTouched}`);
});
const listenerId2 = store.addTablesListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addtableslistener/)(() =>
  console.log('Tables changed'),
);
const listenerId3 = store.addValuesListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addvalueslistener/)(() =>
  console.log('Values changed'),
);

store.transaction[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/transaction/transaction/)(() =>
  store.setCell[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setcell/)('pets', 'fido', 'color', 'brown').setValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalue/)('employees', 3),
);
// -> 'Cells/Values touched: false/false'

store.transaction[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/transaction/transaction/)(() => store.setCell[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setcell/)('pets', 'fido', 'color', 'walnut'));
// -> 'Tables changed'
// -> 'Cells/Values touched: true/false'

store.transaction[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/transaction/transaction/)(() => store.setValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalue/)('employees', 4));
// -> 'Values changed'
// -> 'Cells/Values touched: false/true'

store.transaction[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/transaction/transaction/)(() => {
  store
    .setRow[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setrow/)('pets', 'felix', {species: 'cat'})
    .delRow[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/deleter/delrow/)('pets', 'felix')
    .setValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalue/)('city', 'London')
    .delValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/deleter/delvalue/)('city');
});
// -> 'Cells/Values touched: true/true'
// But no Tables or Values listeners fired since there are no net changes.

store.transaction[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/transaction/transaction/)(
  () =>
    store
      .setRow[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setrow/)('pets', 'felix', {species: 'cat'})
      .setValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalue/)('city', 'London'),
  () => true,
);
// -> 'Cells/Values touched: false/false'
// Transaction was rolled back.

store.callListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/calllistener/)(listenerId);
// -> 'Cells/Values touched: false/false'
// It is meaningless to call this listener directly.

store
  .delListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/dellistener/)(listenerId)
  .delListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/dellistener/)(listenerId2)
  .delListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/dellistener/)(listenerId3);

```
