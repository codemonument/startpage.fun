# `addTableIdsListener`
The `addTableIdsListener` method registers a listener function with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) that will be called whenever the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) change.

```
addTableIdsListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addtableidslistener/)(
  listener: TableIdsListener[](https://tinybase.org/api/store/type-aliases/listener/tableidslistener/)<MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)>,
  mutator?: boolean,
): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `listener`  | `TableIdsListener[](https://tinybase.org/api/store/type-aliases/listener/tableidslistener/)<MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)>`  | The function that will be called whenever the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) change.  |  
| `mutator?`  | `boolean`  | An optional boolean that indicates that the listener mutates [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to call it explicitly, or to remove it.  |  
The provided listener is a [`TableIdsListener`](https://tinybase.org/api/store/type-aliases/listener/tableidslistener/) function, and will be called with a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).
By default, such a listener is only called when a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is added or removed. To listen to all changes in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), use the [`addTablesListener`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addtableslistener/) method.
Use the optional mutator parameter to indicate that there is code in the listener that will mutate [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) data. If set to `false` (or omitted), such mutations will be silently ignored. All relevant mutator listeners (with this flag set to `true`) are called _before_ any non-mutator listeners (since the latter may become relevant due to changes made in the former). The changes made by mutator listeners do not fire other mutating listeners, though they will fire non-mutator listeners.
## Examples
This example registers a listener that responds to any change to the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {fido: {species: 'dog'}}});
const listenerId = store.addTableIdsListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addtableidslistener/)((store) => {
  console.log('Table Ids changed');
  console.log(store.getTableIds[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/gettableids/)());
});

store.setTable[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settable/)('species', {dog: {price: 5}});
// -> 'Table Ids changed'
// -> ['pets', 'species']

store.delListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/dellistener/)(listenerId);

```

This example registers a listener that responds to any change to the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/), and which also mutates the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) itself.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {fido: {species: 'dog'}}});
const listenerId = store.addTableIdsListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/addtableidslistener/)(
  (store) => store.setCell[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setcell/)('meta', 'update', 'store', true),
  true, // mutator
);

store.setTable[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settable/)('species', {dog: {price: 5}});
console.log(store.getTable[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/gettable/)('meta'));
// -> {update: {store: true}}

store.delListener[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/listener/dellistener/)(listenerId);

```
