# `hasValue`
The `hasValue` method returns a boolean indicating whether a given [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) exists in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
hasValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/hasvalue/)(valueId: string): boolean
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `valueId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a possible [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| returns  | `boolean`  | Whether a [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) with that [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) exists in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
## Example
This example shows two simple [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) existence checks.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalues/)({open: true});
console.log(store.hasValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/hasvalue/)('open'));
// -> true
console.log(store.hasValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/hasvalue/)('employees'));
// -> false

```
