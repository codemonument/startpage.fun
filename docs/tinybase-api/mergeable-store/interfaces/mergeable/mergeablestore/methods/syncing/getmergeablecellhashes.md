# `getMergeableCellHashes`
The `getMergeableCellHashes` method returns hashes for [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) objects in a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).

```
getMergeableCellHashes[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/syncing/getmergeablecellhashes/)(otherTableRowHashes: RowHashes[](https://tinybase.org/api/mergeable-store/type-aliases/syncing/rowhashes/)): CellHashes[](https://tinybase.org/api/mergeable-store/type-aliases/syncing/cellhashes/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `otherTableRowHashes`  | `RowHashes[](https://tinybase.org/api/mergeable-store/type-aliases/syncing/rowhashes/)`  | The [`RowHashes`](https://tinybase.org/api/mergeable-store/type-aliases/syncing/rowhashes/) from the other [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) so that the differences can be efficiently identified.  |  
| returns  | `CellHashes[](https://tinybase.org/api/mergeable-store/type-aliases/syncing/cellhashes/)`  | A [`CellHashes`](https://tinybase.org/api/mergeable-store/type-aliases/syncing/cellhashes/) object with the hashes of each [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the relevant [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects of the [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).  |  
If two [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) have different hashes, that indicates that the content within them is different and should be synchronized.
The method is generally intended to be used internally within TinyBase itself and the return type is assumed to be opaque to applications that use it.
## Example
This example creates a [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/), sets some data, and then accesses the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) hashes for the differing [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/).

```
import {createMergeableStore} from 'tinybase';

const store1 = createMergeableStore[](https://tinybase.org/api/mergeable-store/functions/creation/createmergeablestore/)('store1');
store1.setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {fido: {color: 'brown', species: 'dog'}}});

const store2 = createMergeableStore[](https://tinybase.org/api/mergeable-store/functions/creation/createmergeablestore/)('store2');
store2.setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {fido: {color: 'black', species: 'dog'}}});

console.log(
  store1.getMergeableCellHashes[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/syncing/getmergeablecellhashes/)(
    store2.getMergeableRowDiff[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/syncing/getmergeablerowdiff/)(
      store1.getMergeableRowHashes[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/syncing/getmergeablerowhashes/)(
        store2.getMergeableTableDiff[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/syncing/getmergeabletablediff/)(store1.getMergeableTableHashes[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/syncing/getmergeabletablehashes/)())[1],
      ),
    )[1],
  ),
);
// -> {pets: {fido: {color: 923684530, species: 227729753}}}

```
