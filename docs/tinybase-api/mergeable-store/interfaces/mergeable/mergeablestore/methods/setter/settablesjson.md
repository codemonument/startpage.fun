# `setTablesJson`
The `setTablesJson` method takes a string serialization of all of the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and attempts to update them to that.

```
setTablesJson[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settablesjson/)(tablesJson: string): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tablesJson`  | `string`  | A string serialization of all of the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| returns  | `this`  | A reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
If the JSON cannot be parsed, this will fail silently. If it can be parsed, it will then be subject to the same validation rules as the [`setTables`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/) method (according to the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) type, and matching any [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) associated with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/)).
## Examples
This example sets the tabular contents of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) from a serialization.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
store.setTablesJson[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settablesjson/)('{"pets": {"fido": {"species": "dog"}}}');
console.log(store.getTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog'}}}

```

This example attempts to set the tabular contents of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) from an invalid serialization.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
store.setTablesJson[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settablesjson/)('{"pets": {"fido": {');
console.log(store.getTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/gettables/)());
// -> {}

```
