# `setSchema`
The `setSchema` method lets you specify the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) and [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) of the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
setSchema[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setschema/)(
  tablesSchema: TablesSchema[](https://tinybase.org/api/store/type-aliases/schema/tablesschema/),
  valuesSchema?: ValuesSchema[](https://tinybase.org/api/store/type-aliases/schema/valuesschema/),
): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `tablesSchema`  | `TablesSchema[](https://tinybase.org/api/store/type-aliases/schema/tablesschema/)`  | The [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) to be set for the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| `valuesSchema?`  | `ValuesSchema[](https://tinybase.org/api/store/type-aliases/schema/valuesschema/)`  | The [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) to be set for the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
| returns  | `this`  | A reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
Note that this may result in a change to data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), as defaults are applied or as invalid [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), or [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) objects are removed. These changes will fire any listeners to that data, as expected.
From v3.0 onwards, this method takes two arguments. The first is the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) object, the second the [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/). In previous versions (before the existence of the [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) data structure), only the first was present. For backwards compatibility the new second parameter is optional.
## Examples
This example sets the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) and [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) after it has been created.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setSchema[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setschema/)(
  {
    pets: {
      species: {type: 'string'},
      sold: {type: 'boolean', default: false},
    },
  },
  {open: {type: 'boolean', default: false}},
);
store.addRow[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/addrow/)('pets', {species: 'dog', color: 'brown', sold: 'maybe'});
store.setValue[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalue/)('open', 'maybe');

console.log(store.getTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/gettables/)());
// -> {pets: {0: {species: 'dog', sold: false}}}
console.log(store.getValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getvalues/)());
// -> {open: false}

```

This example sets just the [`TablesSchema`](https://tinybase.org/api/store/type-aliases/schema/tablesschema/) of a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) after it has been created.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setSchema[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setschema/)({
  pets: {
    species: {type: 'string'},
    sold: {type: 'boolean', default: false},
  },
});
store.addRow[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/addrow/)('pets', {species: 'dog', color: 'brown', sold: 'maybe'});

console.log(store.getTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/gettables/)());
// -> {pets: {0: {species: 'dog', sold: false}}}

```
