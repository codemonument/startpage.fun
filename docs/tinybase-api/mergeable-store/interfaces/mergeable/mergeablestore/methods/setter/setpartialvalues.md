# `setPartialValues`
The `setPartialValues` method takes an object and sets its [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), but leaving existing [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) unaffected.

```
setPartialValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setpartialvalues/)(partialValues: Values[](https://tinybase.org/api/store/type-aliases/store/values/)): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `partialValues`  | `Values[](https://tinybase.org/api/store/type-aliases/store/values/)`  | The [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) to be set.  |  
| returns  | `this`  | A reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).  |  
This method will cause listeners to be called for any [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) or [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) changes resulting from it.
Any part of the provided object that is invalid (either according to the [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) type, or because, when combined with the current [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) data, it does not match a [`ValuesSchema`](https://tinybase.org/api/store/type-aliases/schema/valuesschema/) associated with the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/)), will be ignored silently.
Assuming that at least some of the provided [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) object is valid, it will be merged with the data that was already present in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). If the object is completely invalid, no change will be made to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).
The method returns a reference to the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) so that subsequent operations can be chained in a fluent style.
## Examples
This example sets some of the keyed value data in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalues/)({open: true});
store.setPartialValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setpartialvalues/)({employees: 3});
console.log(store.getValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getvalues/)());
// -> {open: true, employees: 3}

```

This example attempts to set some of the data of an existing [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) with partly invalid, and then completely invalid, [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) objects.

```
import {createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalues/)({open: true});

store.setPartialValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setpartialvalues/)({employees: 3, bug: new Date(0)});
console.log(store.getValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getvalues/)());
// -> {open: true, employees: 3}

store.setPartialValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setpartialvalues/)(42);
console.log(store.getValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getvalues/)());
// -> {open: true, employees: 3}

```
