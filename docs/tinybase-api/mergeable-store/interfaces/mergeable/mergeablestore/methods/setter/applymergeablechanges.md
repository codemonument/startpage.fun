# `applyMergeableChanges`
The `applyMergeableChanges` method applies a set of mergeable changes or content to the [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).

```
applyMergeableChanges[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/applymergeablechanges/)(mergeableChanges: MergeableContent[](https://tinybase.org/api/mergeable-store/type-aliases/mergeable/mergeablecontent/) | MergeableChanges[](https://tinybase.org/api/mergeable-store/type-aliases/mergeable/mergeablechanges/)<false>): MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `mergeableChanges`  | `MergeableContent[](https://tinybase.org/api/mergeable-store/type-aliases/mergeable/mergeablecontent/) | MergeableChanges[](https://tinybase.org/api/mergeable-store/type-aliases/mergeable/mergeablechanges/)<false>`  | The [`MergeableChanges`](https://tinybase.org/api/mergeable-store/type-aliases/mergeable/mergeablechanges/) or [`MergeableContent`](https://tinybase.org/api/mergeable-store/type-aliases/mergeable/mergeablecontent/) to apply to the [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).  |  
| returns  | `MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)`  | A reference to the [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).  |  
The method is generally intended to be used internally within TinyBase itself and the return type is assumed to be opaque to applications that use it.
## Example
This example applies a [`MergeableChanges`](https://tinybase.org/api/mergeable-store/type-aliases/mergeable/mergeablechanges/) object that sets a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) and removes a [`Value`](https://tinybase.org/api/store/type-aliases/store/value/).

```
import {createMergeableStore} from 'tinybase';

const store = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)('store1')
  .setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {fido: {species: 'dog', color: 'brown'}}})
  .setValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/setvalues/)({open: true});

store.applyMergeableChanges[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/applymergeablechanges/)([
  [{pets: [{fido: [{color: ['black', 'Nn1JUF----2FnHIC']}]}]}],
  [{open: [undefined, 'Nn1JUF----3FnHIC']}],
  1,
]);
console.log(store.getTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/gettables/)());
// -> {pets: {fido: {species: 'dog', color: 'black'}}}
console.log(store.getValues[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getvalues/)());
// -> {}

```
