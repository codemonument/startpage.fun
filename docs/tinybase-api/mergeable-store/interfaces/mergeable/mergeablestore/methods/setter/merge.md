# `merge`
The `merge` method is a convenience method that applies the mergeable content from two MergeableStores to each other in order to bring them to the same state.

```
merge[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/merge/)(mergeableStore: MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)): MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `mergeableStore`  | `MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)`  | A reference to the other [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) to merge with this one.  |  
| returns  | `MergeableStore[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/)`  | A reference to this [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/).  |  
This method is symmetrical: applying `store1` to `store2` will have exactly the same effect as applying `store2` to `store1`.
## Example
This example merges two [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) objects together. Note how the final part of the timestamps on each [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) give you a clue that the data comes from changes made to different [`MergeableStore`](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/) objects.

```
import {createMergeableStore} from 'tinybase';

const store1 = createMergeableStore[](https://tinybase.org/api/mergeable-store/functions/creation/createmergeablestore/)('store1');
store1.setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {fido: {species: 'dog', color: 'brown'}}});

const store2 = createMergeableStore[](https://tinybase.org/api/mergeable-store/functions/creation/createmergeablestore/)('store2');
store2.setTables[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/settables/)({pets: {felix: {species: 'cat', color: 'tan'}}});

store1.merge[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/setter/merge/)(store2);

console.log(store1.getContent[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getcontent/)());
// ->
[
  {
    pets: {
      felix: {color: 'tan', species: 'cat'},
      fido: {color: 'brown', species: 'dog'},
    },
  },
  {},
];

console.log(store2.getContent[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getcontent/)());
// ->
[
  {
    pets: {
      felix: {color: 'tan', species: 'cat'},
      fido: {color: 'brown', species: 'dog'},
    },
  },
  {},
];
console.log(store2.getMergeableContent[](https://tinybase.org/api/mergeable-store/interfaces/mergeable/mergeablestore/methods/getter/getmergeablecontent/)());
// ->
[
  [
    {
      pets: [
        {
          felix: [
            {
              color: ['tan', 'Nn1JUF----0CnH-J', 2576658292],
              species: ['cat', 'Nn1JUF-----CnH-J', 3409607562],
            },
            '',

          ],

            3989065420,

        },

];
```
