# `getSynchronizerStats`
The `getSynchronizerStats` method provides a set of statistics about the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/), and is used for debugging purposes.

```
getSynchronizerStats[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/synchronization/getsynchronizerstats/)(): SynchronizerStats[](https://tinybase.org/api/synchronizers/type-aliases/development/synchronizerstats/)
```
  
| returns  | `SynchronizerStats[](https://tinybase.org/api/synchronizers/type-aliases/development/synchronizerstats/)`  | A [`SynchronizerStats`](https://tinybase.org/api/synchronizers/type-aliases/development/synchronizerstats/) object containing [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) send and receive statistics.  |  
| --- | --- | --- |  
The [`SynchronizerStats`](https://tinybase.org/api/synchronizers/type-aliases/development/synchronizerstats/) object contains a count of the number of times the [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) has sent and received messages.
The method is intended to be used during development to ensure your synchronization layer is acting as expected, for example.
## Example
This example gets the send and receive statistics of two active [`Synchronizer`](https://tinybase.org/api/synchronizers/interfaces/synchronizer/synchronizer/) instances.

```
import {createMergeableStore} from 'tinybase';
import {createLocalSynchronizer} from 'tinybase/synchronizers/synchronizer-local';

const store1 = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)();
const store2 = createMergeableStore[](https://tinybase.org/api/the-essentials/creating-stores/createmergeablestore/)();

const synchronizer1 = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(store1);
const synchronizer2 = createLocalSynchronizer[](https://tinybase.org/api/synchronizer-local/functions/creation/createlocalsynchronizer/)(store2);

await synchronizer1.startSync[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/synchronization/startsync/)();
await synchronizer2.startSync[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/synchronization/startsync/)();

store1.setTables[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settables/)({pets: {fido: {species: 'dog'}}});
// ...
store2.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('pets', 'felix', {species: 'cat'});
// ...

console.log(synchronizer1.getSynchronizerStats[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/synchronization/getsynchronizerstats/)());
// -> {receives: 4, sends: 5}
console.log(synchronizer2.getSynchronizerStats[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/synchronization/getsynchronizerstats/)());
// -> {receives: 5, sends: 4}

await synchronizer1.destroy[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/lifecycle/destroy/)();
await synchronizer2.destroy[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/lifecycle/destroy/)();

```
