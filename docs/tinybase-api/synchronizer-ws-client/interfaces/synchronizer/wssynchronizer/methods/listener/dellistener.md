# `delListener`
The `delListener` method removes a listener that was previously added to the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/).

```
delListener[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/listener/dellistener/)(listenerId: string): this
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `listenerId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the listener to remove.  |  
| returns  | `this`  | A reference to the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/).  |  
Use the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) returned by whichever method was used to add the listener. Note that the [`Persister`](https://tinybase.org/api/the-essentials/persisting-stores/persister/) may re-use this [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for future listeners added to it.
## Example
This example registers a listener and then removes it.

```
import {createStore} from 'tinybase';
import {createSessionPersister} from 'tinybase/persisters/persister-browser';

const persister = createSessionPersister[](https://tinybase.org/api/the-essentials/persisting-stores/createsessionpersister/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)(), 'pets');

const listenerId = persister.addStatusListener[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/listener/addstatuslistener/)((_persister, status) => {
  console.log(`Status changed to ${status}`);
});

await persister.load[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/load/load/)();
// -> `Status changed to 1`
// -> `Status changed to 0`

persister.delListener[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/listener/dellistener/)(listenerId);

await persister.load[](https://tinybase.org/api/synchronizer-ws-client/interfaces/synchronizer/wssynchronizer/methods/load/load/)();
// -> undefined
// The listener is not called.

```
