# Listener functions
## `onHasTables`
The [`onHasTables`](https://tinybase.org/api/ui-svelte/functions/listener/onhastables/) function registers a listener that is called whenever any [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) are added to or removed from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). The listener is tied to the component's `$effect` lifecycle and is removed when the component unmounts. [Read more](https://tinybase.org/api/ui-svelte/functions/listener/onhastables/).
## `onTables`
The [`onTables`](https://tinybase.org/api/ui-svelte/functions/listener/ontables/) function registers a listener that is called whenever tabular data in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) changes. [Read more](https://tinybase.org/api/ui-svelte/functions/listener/ontables/).
## `onTableIds`
The [`onTableIds`](https://tinybase.org/api/ui-svelte/functions/listener/ontableids/) function registers a listener that is called whenever the set of [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) changes. [Read more](https://tinybase.org/api/ui-svelte/functions/listener/ontableids/).
## `onHasTable`
The [`onHasTable`](https://tinybase.org/api/ui-svelte/functions/listener/onhastable/) function registers a listener that is called whenever a specified [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) is added to or removed from the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/api/ui-svelte/functions/listener/onhastable/).
## `onHasTableCell`
The [`onHasTableCell`](https://tinybase.org/api/ui-svelte/functions/listener/onhastablecell/) function registers a listener that is called whenever a specified [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) is added to or removed from across a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). [Read more](https://tinybase.org/api/ui-svelte/functions/listener/onhastablecell/).
## `onResultTable`
The [`onResultTable`](https://tinybase.org/api/ui-svelte/functions/listener/onresulttable/) function registers a listener that is called whenever the result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) of a query changes. [Read more](https://tinybase.org/api/ui-svelte/functions/listener/onresulttable/).
## `onResultTableCellIds`
The [`onResultTableCellIds`](https://tinybase.org/api/ui-svelte/functions/listener/onresulttablecellids/) function registers a listener that is called whenever the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) across a result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) change. [Read more](https://tinybase.org/api/ui-svelte/functions/listener/onresulttablecellids/).
## `onTable`

[Read more](https://tinybase.org/api/ui-svelte/functions/listener/ontable/).
## `onTableCellIds`
