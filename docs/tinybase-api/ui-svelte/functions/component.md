# Component functions
## `TablesView`
The [`TablesView`](https://tinybase.org/api/ui-svelte/functions/component/tablesview/) component renders the contents of all [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/tablesview/).
## `TableView`
The [`TableView`](https://tinybase.org/api/ui-svelte/functions/component/tableview/) component renders the contents of a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/tableview/).
## `ResultSortedTableView`
The [`ResultSortedTableView`](https://tinybase.org/api/ui-svelte/functions/component/resultsortedtableview/) component renders the contents of a single sorted Result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/resultsortedtableview/).
## `ResultTableView`
The [`ResultTableView`](https://tinybase.org/api/ui-svelte/functions/component/resulttableview/) component renders the contents of a single Result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/resulttableview/).
## `SortedTableView`
The [`SortedTableView`](https://tinybase.org/api/ui-svelte/functions/component/sortedtableview/) component renders the contents of a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a sorted order, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/sortedtableview/).
## `LinkedRowsView`
The [`LinkedRowsView`](https://tinybase.org/api/ui-svelte/functions/component/linkedrowsview/) component renders the Rows in a linked list [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/linkedrowsview/).
## `LocalRowsView`
The [`LocalRowsView`](https://tinybase.org/api/ui-svelte/functions/component/localrowsview/) component renders the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) for a given remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/localrowsview/).
## `RemoteRowView`
The [`RemoteRowView`](https://tinybase.org/api/ui-svelte/functions/component/remoterowview/) component renders the remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a given local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/remoterowview/).
## `ResultRowView`
The [`ResultRowView`](https://tinybase.org/api/ui-svelte/functions/component/resultrowview/) component renders the contents of a single Result [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a given Result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/resultrowview/).
## `RowView`
The [`RowView`](https://tinybase.org/api/ui-svelte/functions/component/rowview/) component renders the contents of a single [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a given [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/rowview/).
## `CellView`
The [`CellView`](https://tinybase.org/api/ui-svelte/functions/component/cellview/) component renders the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a given [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a given [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/cellview/).
## `ResultCellView`
The [`ResultCellView`](https://tinybase.org/api/ui-svelte/functions/component/resultcellview/) component renders the value of a single [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in a given Result [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in a given Result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) of a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/resultcellview/).
## `ValuesView`
The [`ValuesView`](https://tinybase.org/api/ui-svelte/functions/component/valuesview/) component renders all [`Values`](https://tinybase.org/api/store/type-aliases/store/values/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/valuesview/).
## `ValueView`
The [`ValueView`](https://tinybase.org/api/ui-svelte/functions/component/valueview/) component renders the value of a single [`Value`](https://tinybase.org/api/store/type-aliases/store/value/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/valueview/).
## `BackwardCheckpointsView`
The [`BackwardCheckpointsView`](https://tinybase.org/api/ui-svelte/functions/component/backwardcheckpointsview/) component renders the list of checkpoint [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) that represent backward checkpoints in a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/backwardcheckpointsview/).
## `CheckpointView`
The [`CheckpointView`](https://tinybase.org/api/ui-svelte/functions/component/checkpointview/) component renders the label of a checkpoint in a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/checkpointview/).

The [`CurrentCheckpointView`](https://tinybase.org/api/ui-svelte/functions/component/currentcheckpointview/) component renders the current checkpoint in a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, and registers a listener so that any changes to that result will cause a re-render. ## `IndexView`
The [`IndexView`](https://tinybase.org/api/ui-svelte/functions/component/indexview/) component renders the slices in a named [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/indexview/).
## `MetricView`
The [`MetricView`](https://tinybase.org/api/ui-svelte/functions/component/metricview/) component renders the value of a named [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) in a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/metricview/).
## `Provider`
The [`Provider`](https://tinybase.org/api/ui-svelte/functions/component/provider/) component wraps part of an application to make TinyBase objects available throughout its component subtree via Svelte context. [Read more](https://tinybase.org/api/ui-svelte/functions/component/provider/).
## `SliceView`
The [`SliceView`](https://tinybase.org/api/ui-svelte/functions/component/sliceview/) component renders the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a named [`Slice`](https://tinybase.org/api/indexes/type-aliases/concept/slice/) in an [`Index`](https://tinybase.org/api/indexes/type-aliases/concept/index/), and registers a listener so that any changes to that result will cause a re-render. [Read more](https://tinybase.org/api/ui-svelte/functions/component/sliceview/).
