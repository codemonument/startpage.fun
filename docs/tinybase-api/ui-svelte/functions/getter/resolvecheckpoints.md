# `resolveCheckpoints`
The `resolveCheckpoints` function is used to get a reference to a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object from a Provider context, or have it passed directly.

```
resolveCheckpoints[](https://tinybase.org/api/ui-svelte/functions/getter/resolvecheckpoints/)(checkpointsOrCheckpointsId?: MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<undefined | CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-svelte/type-aliases/identity/checkpointsorcheckpointsid/)>): () => Checkpoints[](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `checkpointsOrCheckpointsId?`  | `MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<undefined | CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-svelte/type-aliases/identity/checkpointsorcheckpointsid/)>`  | The [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), or a getter returning either.  |  
| returns  | `() => Checkpoints[](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) | undefined`  | A getter function returning the [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, or `undefined`.  |
