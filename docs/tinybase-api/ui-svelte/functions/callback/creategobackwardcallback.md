# `createGoBackwardCallback`
The `createGoBackwardCallback` function returns a callback function that, when called, moves the [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object backward to the previous checkpoint.

```
createGoBackwardCallback[](https://tinybase.org/api/ui-svelte/functions/callback/creategobackwardcallback/)(checkpointsOrCheckpointsId?: MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<undefined | CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-react/type-aliases/identity/checkpointsorcheckpointsid/)>): () => void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `checkpointsOrCheckpointsId?`  | `MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<undefined | CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-react/type-aliases/identity/checkpointsorcheckpointsid/)>`  | The [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object to use, or its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
| returns  | `() => void`  | A callback function.  |
