# `onResultCellIds`
The `onResultCellIds` function registers a listener that is called whenever the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) in a result [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) change.

```
onResultCellIds[](https://tinybase.org/api/ui-svelte/functions/listener/onresultcellids/)(
  queryId: MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)>,
  rowId: MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)>,
  listener: ResultCellIdsListener[](https://tinybase.org/api/queries/type-aliases/listener/resultcellidslistener/),
  queriesOrQueriesId?: MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<undefined | QueriesOrQueriesId[](https://tinybase.org/api/ui-react/type-aliases/identity/queriesorqueriesid/)>,
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)>`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query to listen to, or `null` to listen to any query.  |  
| `rowId`  | `MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<IdOrNull[](https://tinybase.org/api/common/type-aliases/identity/idornull/)>`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the result [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to listen to, or `null` to listen to any result [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).  |  
| `listener`  | `ResultCellIdsListener[](https://tinybase.org/api/queries/type-aliases/listener/resultcellidslistener/)`  | The function to call when [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) change.  |  
| `queriesOrQueriesId?`  | `MaybeGetter[](https://tinybase.org/api/ui-svelte/type-aliases/identity/maybegetter/)<undefined | QueriesOrQueriesId[](https://tinybase.org/api/ui-react/type-aliases/identity/queriesorqueriesid/)>`  | The [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object to use, or its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).  |  
| returns  | `void`  | This has no return value.  |
