# Getter functions
## `getIndexStoreTableId`
The [`getIndexStoreTableId`](https://tinybase.org/api/ui-svelte/functions/getter/getindexstoretableid/) function returns the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and table [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a given [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object and index [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). [Read more](https://tinybase.org/api/ui-svelte/functions/getter/getindexstoretableid/).
## `getRelationshipsStoreTableIds`
The [`getRelationshipsStoreTableIds`](https://tinybase.org/api/ui-svelte/functions/getter/getrelationshipsstoretableids/) function returns the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), local table [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and remote table [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a given [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object and relationship [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/). [Read more](https://tinybase.org/api/ui-svelte/functions/getter/getrelationshipsstoretableids/).
## `getStore`
The [`getStore`](https://tinybase.org/api/ui-svelte/functions/getter/getstore/) function returns the default [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) from the current Provider context (or a named [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) if an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) is provided). [Read more](https://tinybase.org/api/ui-svelte/functions/getter/getstore/).
## `getStoreIds`
The [`getStoreIds`](https://tinybase.org/api/ui-svelte/functions/getter/getstoreids/) function returns a reactive object with the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all Stores registered in the current Provider context. [Read more](https://tinybase.org/api/ui-svelte/functions/getter/getstoreids/).
## `resolveStore`
The [`resolveStore`](https://tinybase.org/api/ui-svelte/functions/getter/resolvestore/) function is used to get a reference to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) object from a Provider context, or have it passed directly. [Read more](https://tinybase.org/api/ui-svelte/functions/getter/resolvestore/).
## `getTables`
The [`getTables`](https://tinybase.org/api/ui-svelte/functions/getter/gettables/) function returns a reactive object reflecting the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to those [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) will update `current`. [Read more](https://tinybase.org/api/ui-svelte/functions/getter/gettables/).
## `hasTables`
The [`hasTables`](https://tinybase.org/api/ui-svelte/functions/getter/hastables/) function returns a reactive object indicating whether any [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) exist in the [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to that result will update `current`. [Read more](https://tinybase.org/api/ui-svelte/functions/getter/hastables/).
## `getTableIds`
The [`getTableIds`](https://tinybase.org/api/ui-svelte/functions/getter/gettableids/) function returns a reactive object reflecting the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), and registers a listener so that any changes to those [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) will update `current`. [Read more](https://tinybase.org/api/ui-svelte/functions/getter/gettableids/).
## `getResultTable`
The [`getResultTable`](https://tinybase.org/api/ui-svelte/functions/getter/getresulttable/) function returns a reactive object reflecting a result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, and registers a listener so that any changes to that result will update `current`. [Read more](https://tinybase.org/api/ui-svelte/functions/getter/getresulttable/).
## `getResultTableCellIds`
The [`getResultTableCellIds`](https://tinybase.org/api/ui-svelte/functions/getter/getresulttablecellids/) function returns a reactive object reflecting the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of all Cells used across a result [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), and registers a listener so that any changes will update `current`.
