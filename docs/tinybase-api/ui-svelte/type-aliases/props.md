# Props type aliases
## `ProviderProps`
[`ProviderProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/providerprops/) props are used with the [`Provider`](https://tinybase.org/api/the-essentials/using-react/provider/) component, so that [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/), [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/), [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/), [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/), [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/), Persisters, and Synchronizers can be passed into the context of a Svelte 5 application and used throughout. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/providerprops/).
## `TablesViewProps`
[`TablesViewProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/tablesviewprops/) props are used for components that refer to all the [`Tables`](https://tinybase.org/api/store/type-aliases/store/tables/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), such as the [`TablesView`](https://tinybase.org/api/ui-react/functions/store-components/tablesview/) component. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/tablesviewprops/).
## `TableViewProps`
[`TableViewProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/tableviewprops/) props are used for components that refer to a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), such as the [`TableView`](https://tinybase.org/api/ui-react/functions/store-components/tableview/) component. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/tableviewprops/).
## `ResultSortedTableViewProps`
[`ResultSortedTableViewProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/resultsortedtableviewprops/) props are used for components that refer to a single sorted query [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), such as the [`ResultSortedTableView`](https://tinybase.org/api/ui-react/functions/queries-components/resultsortedtableview/) component. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/resultsortedtableviewprops/).
## `ResultTableViewProps`
[`ResultTableViewProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/resulttableviewprops/) props are used for components that refer to a single query [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), such as the [`ResultTableView`](https://tinybase.org/api/ui-react/functions/queries-components/resulttableview/) component. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/resulttableviewprops/).
## `SortedTableViewProps`
[`SortedTableViewProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/sortedtableviewprops/) props are used for components that refer to a single sorted [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), such as the [`SortedTableView`](https://tinybase.org/api/ui-react/functions/store-components/sortedtableview/) component. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/sortedtableviewprops/).
## `LinkedRowsViewProps`
[`LinkedRowsViewProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/linkedrowsviewprops/) props are used for components that refer to a single [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) in a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and where you want to render a linked list of Rows starting from a first [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), such as the [`LinkedRowsView`](https://tinybase.org/api/ui-react/functions/relationships-components/linkedrowsview/) component. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/linkedrowsviewprops/).
## `LocalRowsViewProps`
[`LocalRowsViewProps`](https://tinybase.org/api/ui-svelte/type-aliases/props/localrowsviewprops/) props are used for components that refer to a single [`Relationship`](https://tinybase.org/api/relationships/type-aliases/concept/relationship/) in a [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/) object, and where you want to render local Rows based on a remote [`Row`](https://tinybase.org/api/store/type-aliases/store/row/), such as the [`LocalRowsView`](https://tinybase.org/api/ui-react/functions/relationships-components/localrowsview/) component. [Read more](https://tinybase.org/api/ui-svelte/type-aliases/props/localrowsviewprops/).
