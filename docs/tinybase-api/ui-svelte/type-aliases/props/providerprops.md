# `ProviderProps`
`ProviderProps` props are used with the [`Provider`](https://tinybase.org/api/ui-svelte/functions/component/provider/) component, so that [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/), [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/), [`Relationships`](https://tinybase.org/api/relationships/interfaces/relationships/relationships/), [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/), [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/), Persisters, and Synchronizers can be passed into the context of a Svelte 5 application and used throughout.

```
{
  store?: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/);
  storesById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Store[](https://tinybase.org/api/the-essentials/creating-stores/store/)};
  metrics?: Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/);
  metricsById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/)};
  indexes?: Indexes[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/);
  indexesById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Indexes[](https://tinybase.org/api/indexes/interfaces/indexes/indexes/)};
  relationships?: Relationships[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/);
  relationshipsById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Relationships[](https://tinybase.org/api/relationships/interfaces/relationships/relationships/)};
  queries?: Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/);
  queriesById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Queries[](https://tinybase.org/api/queries/interfaces/queries/queries/)};
  checkpoints?: Checkpoints[](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/);
  checkpointsById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Checkpoints[](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/)};
  persister?: AnyPersister[](https://tinybase.org/api/persisters/type-aliases/mergeable/anypersister/);
  persistersById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: AnyPersister[](https://tinybase.org/api/persisters/type-aliases/mergeable/anypersister/)};
  synchronizer?: Synchronizer[](https://tinybase.org/api/the-essentials/synchronizing-stores/synchronizer/);
  synchronizersById?: {[id: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]: Synchronizer[](https://tinybase.org/api/the-essentials/synchronizing-stores/synchronizer/)};
  children: Snippet;
}
```
