# `ResultSortedTableViewProps`
`ResultSortedTableViewProps` props are used for components that refer to a single sorted query [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/), such as the [`ResultSortedTableView`](https://tinybase.org/api/ui-svelte/functions/component/resultsortedtableview/) component.

```
{
  queryId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  cellId?: Id[](https://tinybase.org/api/common/type-aliases/identity/id/);
  descending?: boolean;
  offset?: number;
  limit?: number;
  queries?: QueriesOrQueriesId[](https://tinybase.org/api/ui-svelte/type-aliases/identity/queriesorqueriesid/);
  separator?: Snippet<[]>;
  debugIds?: boolean;
  row?: Snippet<[rowId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]>;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `queryId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query in the [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object for which the sorted [`ResultTable`](https://tinybase.org/api/queries/type-aliases/result/resulttable/) will be rendered.  |  
| `cellId?`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) whose values are used for sorting. If omitted, the view will sort the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) itself.  |  
| `descending?`  | `boolean`  | Whether the sorting should be in descending order.  |  
| `offset?`  | `number`  | The number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to skip for pagination purposes.  |  
| `limit?`  | `number`  | The maximum number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) to return.  |  
| `queries?`  | `QueriesOrQueriesId[](https://tinybase.org/api/ui-svelte/type-aliases/identity/queriesorqueriesid/)`  | The [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object to be accessed: omit for the default context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Queries`](https://tinybase.org/api/queries/interfaces/queries/queries/) object, or provide an explicit reference.  |  
| `separator?`  | `Snippet<[]>`  | A component or string to separate each rendered [`Row`](https://tinybase.org/api/store/type-aliases/store/row/).  |  
| `debugIds?`  | `boolean`  | Whether the component should also render the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the query, and its descendent objects, to assist with debugging.  |  
| `row?`  | `Snippet<[rowId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]>`  | A snippet for rendering each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), to override the default [`ResultRowView`](https://tinybase.org/api/ui-react/functions/queries-components/resultrowview/) component.  |
