# `ForwardCheckpointsViewProps`
`ForwardCheckpointsViewProps` props are used for components that refer to a list of future checkpoints in a [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, such as the [`ForwardCheckpointsView`](https://tinybase.org/api/ui-svelte/functions/component/forwardcheckpointsview/) component.

```
{
  checkpoints?: CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-svelte/type-aliases/identity/checkpointsorcheckpointsid/);
  separator?: Snippet<[]>;
  debugIds?: boolean;
  checkpoint?: Snippet<[checkpointId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]>;
}
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `checkpoints?`  | `CheckpointsOrCheckpointsId[](https://tinybase.org/api/ui-svelte/type-aliases/identity/checkpointsorcheckpointsid/)`  | The [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object to be accessed: omit for the default context [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, provide an [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for a named context [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object, or provide an explicit reference.  |  
| `separator?`  | `Snippet<[]>`  | A component or string to separate each rendered checkpoint.  |  
| `debugIds?`  | `boolean`  | Whether the component should also render the [`Ids`](https://tinybase.org/api/common/type-aliases/identity/ids/) of the checkpoints to assist with debugging.  |  
| `checkpoint?`  | `Snippet<[checkpointId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/)]>`  | A snippet for rendering each checkpoint in the [`Checkpoints`](https://tinybase.org/api/checkpoints/interfaces/checkpoints/checkpoints/) object.  |
