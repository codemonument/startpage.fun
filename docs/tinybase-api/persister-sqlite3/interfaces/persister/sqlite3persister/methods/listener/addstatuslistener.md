# `addStatusListener`
The `addStatusListener` method registers a listener function with the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) that will be called whenever it starts or stops loading or saving.

```
addStatusListener[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/listener/addstatuslistener/)(listener: StatusListener[](https://tinybase.org/api/persisters/type-aliases/listener/statuslistener/)<Sqlite3Persister[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/)>): string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `listener`  | `StatusListener[](https://tinybase.org/api/persisters/type-aliases/listener/statuslistener/)<Sqlite3Persister[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/)>`  | The function that will be called whenever the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) starts or stops loading or saving.  |  
| returns  | `string`  | A unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) for the listener that can later be used to remove it.  |  
The provided listener is a [`StatusListener`](https://tinybase.org/api/persisters/type-aliases/listener/statuslistener/) function, and will be called with a reference to the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) and the new [`Status`](https://tinybase.org/api/persisters/enumerations/lifecycle/status/): 0 means now idle, 1 means now loading, and 2 means now saving.
## Example
This example registers a listener that responds to changes in the state of the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/).

```
import {createStore} from 'tinybase';
import {createSessionPersister} from 'tinybase/persisters/persister-browser';

const persister = createSessionPersister[](https://tinybase.org/api/the-essentials/persisting-stores/createsessionpersister/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)(), 'pets');

const listenerId = persister.addStatusListener[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/listener/addstatuslistener/)((persister, status) => {
  console.log(
    `${persister.getStorageName[](https://tinybase.org/api/persister-browser/interfaces/persister/localpersister/methods/getter/getstoragename/)()} persister status changed to ${status}`,
  );
});

await persister.load[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/load/load/)();
// -> 'pets persister status changed to 1'
// -> 'pets persister status changed to 0'
await persister.save[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/save/save/)();
// -> 'pets persister status changed to 2'
// -> 'pets persister status changed to 0'

persister.delListener[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/listener/dellistener/)(listenerId);

```
