# `destroy`
The `destroy` method should be called when this [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) object is no longer used.

```
destroy[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/lifecycle/destroy/)(): Promise<Sqlite3Persister[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/)>
```
  
| returns  | `Promise<Sqlite3Persister[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/)>`  | A Promise containing a reference to the [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) object.  |  
| --- | --- | --- |  
This guarantees that all of the listeners that the object registered with the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) and storage are removed and it can be correctly garbage collected. It is equivalent to running the [`stopAutoLoad`](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/load/stopautoload/) method and the [`stopAutoSave`](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/save/stopautosave/) method in succession. This method is asynchronous.
## Example
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), associates a [`Persister`](https://tinybase.org/api/persisters/interfaces/persister/persister/) object with it (that registers a [`TablesListener`](https://tinybase.org/api/store/type-aliases/listener/tableslistener/) with the underlying [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/)), and then destroys it again, removing the listener.

```
import {createStore} from 'tinybase';
import {createSessionPersister} from 'tinybase/persisters/persister-browser';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)();
const persister = createSessionPersister[](https://tinybase.org/api/the-essentials/persisting-stores/createsessionpersister/)(store, 'pets');
await persister.startAutoSave[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/save/startautosave/)();

console.log(store.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().transaction);
// -> 1

await persister.destroy[](https://tinybase.org/api/persister-sqlite3/interfaces/persister/sqlite3persister/methods/lifecycle/destroy/)();

console.log(store.getListenerStats[](https://tinybase.org/api/store/interfaces/store/store/methods/development/getlistenerstats/)().transaction);
// -> 0

```
