# `MetricListener`
The `MetricListener` type describes a function that is used to listen to changes to a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).

```
(
  metrics: Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/),
  metricId: Id[](https://tinybase.org/api/common/type-aliases/identity/id/),
  newMetric: Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/) | undefined,
  oldMetric: Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/) | undefined,
): void
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `metrics`  | `Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/)`  | A reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object that changed.  |  
| `metricId`  | `Id[](https://tinybase.org/api/common/type-aliases/identity/id/)`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) that changed.  |  
| `newMetric`  | `Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/) | undefined`  | The new value of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) that changed.  |  
| `oldMetric`  | `Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/) | undefined`  | The old value of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) that changed.  |  
| returns  | `void`  | This has no return value.  |  
A `MetricListener` is provided when using the [`addMetricListener`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/listener/addmetriclistener/) method. See that method for specific examples.
When called, a `MetricListener` is given a reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) that changed, and the new and old values of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).
If this is the first time that a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) has had a value (such as when a table has gained its first row), the old value will be `undefined`. If a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) now no longer has a value, the new value will be `undefined`.
