# `MetricAggregateReplace`
The `MetricAggregateReplace` type describes a function that can be used to optimize a custom [`MetricAggregate`](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregate/) by providing a shortcut for when a single value in the input values is replaced with another.

```
(
  metric: Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/),
  add: number,
  remove: number,
  length: number,
): Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/) | undefined
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `metric`  | `Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/)`  | The current value of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).  |  
| `add`  | `number`  | The number being added to the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/)'s aggregation.  |  
| `remove`  | `number`  | The number being removed from the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/)'s aggregation.  |  
| `length`  | `number`  | The length of the array of numbers in the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/)'s aggregation.  |  
| returns  | `Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/) | undefined`  | The new value of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).  |  
Some aggregation functions do not need to recalculate the aggregation of the whole set when one value changes. For example, when replacing a number in a series, the new sum of the series is the previous sum, plus the new value, minus the old value.
If it is not possible to shortcut the aggregation based on just one value changing, return `undefined` and the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) will be completely recalculated.
When possible, if you are providing a custom [`MetricAggregate`](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregate/), seek an implementation of an `MetricAggregateReplace` function that can reduce the complexity cost of changing the input data set in place. See the [`setMetricDefinition`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/) method for more examples.
