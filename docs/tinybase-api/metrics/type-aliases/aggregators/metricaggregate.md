# `MetricAggregate`
The `MetricAggregate` type describes a custom function that takes an array of numbers and returns an aggregate that is used as a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).

```
(
  numbers: number[],
  length: number,
): Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `numbers`  | `number[]`  | The array of numbers in the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/)'s aggregation.  |  
| `length`  | `number`  | The length of the array of numbers in the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/)'s aggregation.  |  
| returns  | `Metric[](https://tinybase.org/api/metrics/type-aliases/metric/metric/)`  | The value of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).  |  
There are a number of common predefined aggregators, such as for counting, summing, and averaging values. This type is instead used for when you wish to use a more complex aggregation of your own devising. See the [`setMetricDefinition`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/) method for more examples.
