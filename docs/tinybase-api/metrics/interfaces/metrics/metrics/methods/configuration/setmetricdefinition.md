# `setMetricDefinition`
The `setMetricDefinition` method lets you set the definition of a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).

```
setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)(
  metricId: string,
  tableId: string,
  aggregate?: MetricAggregate[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregate/) | "sum" | "avg" | "min" | "max",
  getNumber?: string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => number,
  aggregateAdd?: MetricAggregateAdd[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregateadd/),
  aggregateRemove?: MetricAggregateRemove[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregateremove/),
  aggregateReplace?: MetricAggregateReplace[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregatereplace/),
): Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/)
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `metricId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) to define.  |  
| `tableId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) will be calculated from.  |  
| `aggregate?`  | `MetricAggregate[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregate/) | "sum" | "avg" | "min" | "max"`  | Either a string representing one of a set of common aggregation techniques ('sum', 'avg', 'min', or 'max'), or a function that aggregates numeric values from each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) to create the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/)'s overall value. Defaults to 'sum'.  |  
| `getNumber?`  | `string | (getCell: GetCell[](https://tinybase.org/api/store/type-aliases/callback/getcell/), rowId: string) => number`  | Either the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) containing, or a function that produces, the numeric value that will be aggregated in the way specified by the `aggregate` parameter. Defaults to a function that returns `1` (meaning that if the `aggregate` and `getNumber` parameters are both omitted, the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) will simply be a count of the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/)).  |  
| `aggregateAdd?`  | `MetricAggregateAdd[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregateadd/)`  | A function that can be used to optimize a custom [`MetricAggregate`](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregate/) by providing a shortcut for when a single value is added to the input values - for example, when a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is added to the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `aggregateRemove?`  | `MetricAggregateRemove[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregateremove/)`  | A function that can be used to optimize a custom [`MetricAggregate`](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregate/) by providing a shortcut for when a single value is removed from the input values - for example ,when a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is removed from the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).  |  
| `aggregateReplace?`  | `MetricAggregateReplace[](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregatereplace/)`  | A function that can be used to optimize a custom [`MetricAggregate`](https://tinybase.org/api/metrics/type-aliases/aggregators/metricaggregate/) by providing a shortcut for when a single value in the input values is replaced with another - for example, when a [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) is updated.  |  
| returns  | `Metrics[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/)`  | A reference to the [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object.  |  
Every [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) definition is identified by a unique [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/), and if you re-use an existing [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) with this method, the previous definition is overwritten.
A [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) is an aggregation of numeric values produced from each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) within a single [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). Therefore the definition must specify the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) (by its [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/)) to be aggregated.
Without the third `aggregate` parameter, the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) will simply be a count of the number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/). But often you will specify a more interesting aggregate - such as the four predefined aggregates, 'sum', 'avg', 'min', and 'max' - or a custom function that produces your own aggregation of an array of numbers.
The fourth `getNumber` parameter specifies which [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in each [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) contains the numerical values to be used in the aggregation. Alternatively, a custom function can be provided that produces your own numeric value from the local [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) as a whole.
The final three parameters, `aggregateAdd`, `aggregateRemove`, `aggregateReplace` need only be provided when you are using your own custom `aggregate` function. These give you the opportunity to reduce your custom function's algorithmic complexity by providing shortcuts that can nudge an aggregation result when a single value is added, removed, or replaced in the input values.
## Examples
This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, and defines a simple [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) to count the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createMetrics, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('speciesCount', 'species');

console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('speciesCount'));
// -> 3

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, and defines a standard [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) to get the highest value of each `price` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) in the [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects in the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/).

```
import {createMetrics, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('highestPrice', 'species', 'max', 'price');

console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('highestPrice'));
// -> 5

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, and defines a custom [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) to get the lowest value of each `price` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), greater than 2.

```
import {createMetrics, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)(
  'lowestPriceOver2',
  'species',
  (numbers) => Math.min(...numbers.filter((number) => number > 2)),
  'price',
);

console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('lowestPriceOver2'));
// -> 4

```

This example also creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, and defines a custom [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) to get the lowest value of each `price` [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/), greater than 2. However, it also reduces algorithmic complexity with two shortcut functions.

```
import {createMetrics, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)(
  'lowestPriceOver2',
  'species',
  (numbers) => Math.min(...numbers.filter((number) => number > 2)),
  'price',
  (metric, add) => (add > 2 ? Math.min(metric, add) : metric),
  (metric, remove) => (remove == metric ? undefined : metric),
  (metric, add, remove) =>
    remove == metric
      ? undefined
      : add > 2
        ? Math.min(metric, add)
        : metric,
);

console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('lowestPriceOver2'));
// -> 4
store.setRow[](https://tinybase.org/api/the-essentials/setting-data/setrow/)('species', 'fish', {price: 3});
console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('lowestPriceOver2'));
// -> 3

```

This example creates a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/), creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, and defines a custom [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) to get the average value of a discounted price.

```
import {createMetrics, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5, discount: 0.3},
  cat: {price: 4, discount: 0.2},
  worm: {price: 1, discount: 0.2},
});

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)(
  'averageDiscountedPrice',
  'species',
  'avg',
  (getCell) => getCell[](https://tinybase.org/api/the-essentials/getting-data/getcell/)('price') * (1 - getCell[](https://tinybase.org/api/the-essentials/getting-data/getcell/)('discount')),
);

console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('averageDiscountedPrice'));
// -> 2.5

```
