# `getTableId`
The `getTableId` method returns the [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) that is backing a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).

```
getTableId[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/gettableid/)(metricId: string): undefined | string
```
  
|   | Type  | Description  |  
| --- | --- | --- |  
| `metricId`  | `string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/).  |  
| returns  | `undefined | string`  | The [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) of the [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) backing the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/), or `undefined`.  |  
If the [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/) is invalid, the method returns `undefined`.
## Example
This example creates a [`Metrics`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/) object, a single [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) definition, and then queries it (and a non-existent definition) to get the underlying [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) [`Id`](https://tinybase.org/api/common/type-aliases/identity/id/).

```
import {createMetrics, createStore} from 'tinybase';

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)());
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)('speciesCount', 'species');

console.log(metrics.getTableId[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/gettableid/)('speciesCount'));
// -> 'species'
console.log(metrics.getTableId[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/gettableid/)('petsCount'));
// -> undefined

```
