# `Metrics`
A `Metrics` object lets you define, query, and listen to, aggregations of [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values within a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/) in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/).
This is useful for counting the number of [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects in a [`Table`](https://tinybase.org/api/store/type-aliases/store/table/), averaging [`Cell`](https://tinybase.org/api/store/type-aliases/store/cell/) values, or efficiently performing any arbitrary aggregations.
Create a `Metrics` object easily with the [`createMetrics`](https://tinybase.org/api/metrics/functions/creation/createmetrics/) function. From there, you can add new [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/) definitions (with the [`setMetricDefinition`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/) method), query their values (with the [`getMetric`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/) method), and add listeners for when they change (with the [`addMetricListener`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/listener/addmetriclistener/) method).
This module provides a number of predefined and self-explanatory aggregations ('sum', 'avg', 'min', and 'max'), and defaults to counting [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects when using the [`setMetricDefinition`](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/) method. However, far more complex aggregations can be configured with custom functions.
## Example
This example shows a very simple lifecycle of a `Metrics` object: from creation, to adding a definition, getting a [`Metric`](https://tinybase.org/api/metrics/type-aliases/metric/metric/), and then registering and removing a listener for it.

```
import {createMetrics, createStore} from 'tinybase';

const store = createStore[](https://tinybase.org/api/the-essentials/creating-stores/createstore/)().setTable[](https://tinybase.org/api/store/interfaces/store/store/methods/setter/settable/)('species', {
  dog: {price: 5},
  cat: {price: 4},
  worm: {price: 1},
});

const metrics = createMetrics[](https://tinybase.org/api/metrics/functions/creation/createmetrics/)(store);
metrics.setMetricDefinition[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/configuration/setmetricdefinition/)(
  'highestPrice', // metricId
  'species', //      tableId to aggregate
  'max', //          aggregation
  'price', //        cellId to aggregate
);

console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('highestPrice'));
// -> 5

const listenerId = metrics.addMetricListener[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/listener/addmetriclistener/)('highestPrice', () => {
  console.log(metrics.getMetric[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/getter/getmetric/)('highestPrice'));
});
store.setCell[](https://tinybase.org/api/the-essentials/setting-data/setcell/)('species', 'horse', 'price', 20);
// -> 20

metrics.delListener[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/listener/dellistener/)(listenerId);
metrics.destroy[](https://tinybase.org/api/metrics/interfaces/metrics/metrics/methods/lifecycle/destroy/)();

```
