# Using Indexes
These guides discuss how to define [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) that allow fast access to matching [`Row`](https://tinybase.org/api/store/type-aliases/store/row/) objects.
See also the [Countries](https://tinybase.org/demos/countries/) demo, the [Todo App](https://tinybase.org/demos/todo-app/) demos, and the [Word Frequencies](https://tinybase.org/demos/word-frequencies/) demo.
## An Intro To Indexes
This guide describes how the [`indexes`](https://tinybase.org/api/indexes/) module gives you the ability to create and track indexes based on the data in [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects, and which allow you to look up and display filtered data quickly. [Read more](https://tinybase.org/guides/using-indexes/an-intro-to-indexes/).
## Building A UI With Indexes
This guide covers how the [`ui-react`](https://tinybase.org/api/ui-react/) module supports the [`Indexes`](https://tinybase.org/api/indexes/interfaces/indexes/indexes/) object. [Read more](https://tinybase.org/guides/using-indexes/building-a-ui-with-indexes/).
## Advanced Index Definition
This guide describes how the [`indexes`](https://tinybase.org/api/indexes/) module let you create more complex types of indexes based on the data in [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects. [Read more](https://tinybase.org/guides/using-indexes/advanced-index-definition/).
