# The Basics
These guides cover the very basics of TinyBase.
We start with common ways to install the modules and then learn about how to interact with [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/) objects including creation, reading data, writing data, and listening for changes.
See also the [Hello World](https://tinybase.org/demos/hello-world/) demos, and the [Todo App](https://tinybase.org/demos/todo-app/) demos.
Let's get started!
## Getting Started
This guide gets you up and running quickly with TinyBase. [Read more](https://tinybase.org/guides/the-basics/getting-started/).
## Creating A Store
This guide shows you how to create a new [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/guides/the-basics/creating-a-store/).
## Writing To Stores
This guide shows you how to write data to a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/guides/the-basics/writing-to-stores/).
## Reading From Stores
This guide shows you how to read data from a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/guides/the-basics/reading-from-stores/).
## Listening To Stores
This guide shows you how to listen to changes in the data in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/guides/the-basics/listening-to-stores/).
## Transactions
This guide shows you how to wrap multiple changes to the data in a [`Store`](https://tinybase.org/api/the-essentials/creating-stores/store/). [Read more](https://tinybase.org/guides/the-basics/transactions/).
## Importing TinyBase
This guide provides an aside about importing TinyBase into your application. [Read more](https://tinybase.org/guides/the-basics/importing-tinybase/).
## TinyBase And TypeScript
This guide summarizes the two different levels of TypeScript coverage you can use with TinyBase. [Read more](https://tinybase.org/guides/the-basics/tinybase-and-typescript/).
## Architectural Options
This guide discusses some of the ways in which you can use TinyBase, and how you can architect it into the bigger picture of how your app is built. [Read more](https://tinybase.org/guides/the-basics/architectural-options/).
