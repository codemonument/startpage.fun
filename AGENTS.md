## Agent skills

### Issue tracker

Issues are tracked as beans in `.beans/` using the `beans` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage roles are represented with beans tags: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`; `wontfix` also means status `scrapped`. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context domain docs layout centered on root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
